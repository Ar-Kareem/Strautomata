To solve this Kalah game problem, we need to create a Python function `policy` that takes the current player's and opponent's board states as inputs and returns the best legal move for the current player. The function should consider the rules of Kalah, including the possibility of extra moves and captures, and prioritize moves that provide strategic advantages.

### Approach
1. **Legal Moves Identification**: Identify all legal moves by checking which of the player's houses (0 to 5) are non-empty.
2. **Move Simulation**: For each legal move, simulate the resulting board state, taking into account the rules for seed distribution, captures, and extra moves.
3. **Evaluation of Moves**: Evaluate each move based on several criteria:
   - Whether it results in an extra move.
   - Whether it results in a capture.
   - The amount of seeds captured.
   - The net gain in the player's store.

### Solution Code
```python
def policy(you: list[int], opponent: list[int]) -> int:
    legal_moves = [i for i in range(6) if you[i] > 0]
    
    def simulate_move(i):
        new_you = you.copy()
        new_opponent = opponent.copy()
        seeds = new_you[i]
        new_you[i] = 0
        
        current_type = 'you'
        current_index = i + 1
        seeds_remaining = seeds
        last_pos_type = None
        last_pos_index = -1
        prev_value = 0
        extra_move = False
        captured_seeds = 0
        capture_occurred = False
        
        while seeds_remaining > 0:
            if current_type == 'you':
                if current_index > 5:
                    current_type = 'store'
                    current_index = 6
                    continue
                prev_value = new_you[current_index]
                new_you[current_index] += 1
                seeds_remaining -= 1
                if seeds_remaining == 0:
                    last_pos_type = 'you'
                    last_pos_index = current_index
                    break
                if current_index < 5:
                    current_index += 1
                else:
                    current_type = 'store'
                    current_index = 6
            elif current_type == 'store':
                prev_value = new_you[6]
                new_you[6] += 1
                seeds_remaining -= 1
                if seeds_remaining == 0:
                    last_pos_type = 'store'
                    last_pos_index = 6
                    break
                current_type = 'opponent'
                current_index = 0
            elif current_type == 'opponent':
                prev_value = new_opponent[current_index]
                new_opponent[current_index] += 1
                seeds_remaining -= 1
                if seeds_remaining == 0:
                    last_pos_type = 'opponent'
                    last_pos_index = current_index
                    break
                if current_index < 5:
                    current_index += 1
                else:
                    current_type = 'you_again'
                    current_index = 0
            elif current_type == 'you_again':
                prev_value = new_you[current_index]
                new_you[current_index] += 1
                seeds_remaining -= 1
                if seeds_remaining == 0:
                    last_pos_type = 'you'
                    last_pos_index = current_index
                    break
                if current_index < 5:
                    current_index += 1
                else:
                    current_type = 'opponent_again'
                    current_index = 0
            elif current_type == 'opponent_again':
                prev_value = new_opponent[current_index]
                new_opponent[current_index] += 1
                seeds_remaining -= 1
                if seeds_remaining == 0:
                    last_pos_type = 'opponent'
                    last_pos_index = current_index
                    break
                if current_index < 5:
                    current_index += 1
                else:
                    current_type = 'you_again'
                    current_index = 0
            else:
                break  # invalid type
        
        if last_pos_type == 'store':
            extra_move = True
        elif last_pos_type == 'you':
            if prev_value == 0:
                opposite_house = 5 - last_pos_index
                if new_opponent[opposite_house] > 0:
                    captured_seeds = 1 + new_opponent[opposite_house]
                    new_you[6] += captured_seeds
                    new_you[last_pos_index] = 0
                    new_opponent[opposite_house] = 0
                    capture_occurred = True
        return new_you, new_opponent, extra_move, captured_seeds, capture_occurred
    
    best_move = legal_moves[0]
    best_score = (False, False, 0, -float('inf'))
    
    for i in legal_moves:
        _, _, extra_move, captured_seeds, capture_occurred = simulate_move(i)
        store_increase = you[6] + extra_move + captured_seeds + (0 if not capture_occurred else captured_seeds) - you[6]
        store_increase = (simulate_move(i)[0][6] - you[6])
        score = (extra_move, capture_occurred, captured_seeds, store_increase)
        if score > best_score:
            best_score = score
            best_move = i
    
    return best_move
```

### Explanation
1. **Legal Moves Identification**: The code identifies all non-empty houses in the player's side (0 to 5) to determine valid moves.
2. **Simulation Function**: The `simulate_move` function simulates each move, distributing seeds according to the rules, handling captures, and checking for extra moves.
3. **Evaluation**: Each move is evaluated based on the criteria of extra moves, captures, the amount captured, and the net gain in the player's store. The move with the highest score according to these criteria is chosen as the best move.

This approach ensures that the AI considers both immediate and potential future gains, prioritizing strategic moves that maximize the player's advantage in the Kalah game.
