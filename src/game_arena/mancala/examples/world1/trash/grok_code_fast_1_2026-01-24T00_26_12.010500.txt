### Strategy Description

My strategy for this Kalah policy is a minimax algorithm with alpha-beta pruning, limited to a depth of 4 plies to stay within the 1-second execution time constraint on a modern 3GHz CPU. Minimax explores possible game trees: I (the maximizer) aim to maximize my advantage, while simulating the opponent (the minimizer) trying to minimize it. Alpha-beta pruning cuts off unnecessary branches for efficiency.

At the leaves (or max depth), I evaluate the board position using a heuristic function that considers:
- The difference in store scores (my store minus opponent's store).
- The total number ofseeds under my control (my houses + my store) minus opponent's (adjusted by a small multiplier to weight availability vs. immediate store advantage).
- Penalize weak positions where the opponent could capture on their next turn (if a move leaves an empty house directly opposite a non-empty opponent house).
- Slightly advantage extra turns (if I land in my store).
- Promote moves that clear houses to force bonus captures later or set up positional advantages.
- If a terminal position is reached (no legal moves left for the other player), it returns the exact game outcome: +100 for a win, -100 for a loss, 0 for a draw.

I iterate through all legal moves from the current position and choose the one with the highest minimax score. To handle potential loops or deep trees, the depth limit prevents excessive computation. Legal moves are ensured by only considering i where you[i] > 0. Simulations use a copied board to avoid modifying the original state. This approach should beat simpler policies like random moves or greedy (e.g., always capturing), as it's strategic and anticipates opponent responses.

def is_terminal(you, opponent):
    you_empty = all(h == 0 for h in you[:6])
    opp_empty = all(h == 0 for h in opponent[:6])
    return you_empty or opp_empty

def evaluate(you, opponent):
    if is_terminal(you, opponent):
        my_total = sum(you)
        opp_total = sum(opponent)
        if my_total > opp_total:
            return 100
        elif my_total < opp_total:
            return -100
        else:
            return 0

    my_store = you[6]
    opp_store = opponent[6]
    my_controlled = sum(you)
    opp_controlled = sum(opponent)
    
    # Store diff
    score = (my_store - opp_store) * 2
    
    # Controlled seeds (my total - opp total), weighted lightly
    score += (my_controlled - opp_controlled) * 0.1

            score -= opponent[5 - i] * 0.5  # Penalty for capturable position
    
    # Bonus for keeping seeds moving or clearing houses strategically? Already in control.
    return score

def minimax(you, opponent, depth, alpha, beta, maximizing, max_depth=4):
    if depth == 0 or is_terminal(you, opponent):
        return evaluate(you, opponent)
    
    legal_moves = [i for i in range(6) if (you[i] > 0) if maximizing else (opponent[i] > 0)]
    if not legal_moves:
        return evaluate(you, opponent)
    
    if maximizing:

        for move in legal_moves:
            new_you, new_opp, next_max = simulate_move(you, opponent, move, True)
            if next_max:
                eval = minimax(new_you, new_opp, depth - 1, alpha, beta, True, max_depth)
            else:
                eval = minimax(new_you, new_opp, depth - 1, alpha, beta, False, max_depth)
            max_eval = max(max_eval, eval)
            alpha = max(alpha, eval)
            if beta <= alpha:
                break
        return max_eval
    else:
        min_eval = float('inf')
        for move in legal_moves:
            new_you, new_opp, next_max = simulate_move(you, opponent, move, False)
            if next_max:
                eval = minimax(new_opp, new_you, depth - 1, alpha, beta, False, max_depth)
            else:
                eval = minimax(new_opp, new_you, depth - 1, alpha, beta, True, max_depth)
            min_eval = min(min_eval, eval)
            beta = min(beta, eval)
            if beta <= alpha:
                break
        return min_eval

    best_score = -float('inf')

            best_move = move
