To solve this problem, we need to implement a policy function for the game Kalah that selects the best possible move given the current state of the board. The goal is to maximize the number of seeds in your store while minimizing the opponent's seeds. The solution involves simulating each possible move to evaluate its potential impact and selecting the move with the highest score based on the resulting state.

### Approach
1. **Simulate Moves**: For each legal move (each house with seeds), simulate the distribution of seeds and capture any opponent seeds if possible.
2. **Evaluate Moves**: Evaluate each move based on the resulting state to determine the best move. The evaluation function prioritizes moves that result in an extra turn (placing the last seed in your store) and maximizes the strategic value of the resulting state.
3. **Strategic Evaluation**: Use a heuristic to evaluate each move based on the difference between your store and the opponent's store, the number of seeds captured, and whether the move grants an extra turn.

### Solution Code
```python
def policy(you: list[int], opponent: list[int]) -> int:
    positions_order = list(range(6)) + [6] + list(range(6))
    my_store_count = you[6]
    possible_moves = [i for i in range(6) if you[i] > 0]
    
    if not possible_moves:
        return -1  # According to problem statement, this should never happen
    
    best_move = None
    max_eval = -(float('inf'))
    
    for move_i in possible_moves:
        s = you[move_i]
        new_you = you.copy()
        new_opponent = opponent.copy()
        new_you[move_i] = 0  # Remove all seeds from house i
        
        current_pos = move_i + 1  # Starting position index
        captured = 0
        last_pos = None
        
        # Simulate placing s seeds
        for _ in range(s):
            target_index = current_pos % 13
            pos = positions_order[target_index]
            
            if pos == 6:
                new_you[6] += 1
            elif pos < 6:
                new_you[pos] += 1
            else:
                opp_index = pos - 7
                new_opponent[opp_index] += 1
            
            current_pos += 1
            last_pos = pos
        
        # Check if last seed was in your store (extra move)
        is_extra_move = (last_pos == 6)
        
        # Check for capture
        captured_this_move = 0
        if last_pos < 6 and new_you[last_pos] == 1 and you[last_pos] == 0:
            opp_house = 5 - last_pos
            captured = new_opponent[opp_house]
            if captured > 0:
                captured_this_move = captured
                new_opponent[opp_house] = 0
                new_you[6] += captured
        
        # Calculate evaluation score
        sum_my_current = new_you[6] + sum(new_you[:6])
        sum_opponent = opponent[6] + sum(new_opponent[:6])
        delta = sum_my_current - sum_opponent
        bonus = 100 if is_extra_move else 0
        evaluation = delta + bonus
        
        if evaluation > max_eval or (evaluation == max_eval and best_move is None):
            max_eval = evaluation
            best_move = move_i
    
    return best_move
```

### Explanation
1. **Simulate Each Move**: For each possible move (house with seeds), simulate the distribution of seeds and capture any opponent seeds if applicable. The positions are simulated in order starting from the next house after the move index.
2. **Capture Handling**: If the last seed lands in your house and it was empty before the move, check if the corresponding opponent's house has seeds. If so, capture those seeds and add them to your store.
3. **Evaluation Function**: The evaluation score combines the difference between your store and the opponent's store, the number of seeds captured during the move, and a bonus for moves that allow an extra turn (placing the last seed in your store).
4. **Select Best Move**: Iterate over all possible moves, simulate each, and select the move with the highest evaluation score.

This approach ensures that the policy selects moves that maximize your store's seeds, minimize the opponent's seeds, and strategically take advantage of extra moves for potential future gains.
