```python
from copy import deepcopy

def policy(you, opponent):
    moves = []
    for i in range(6):
        if you[i] <= 0:
            continue
        
        # Simulate the move
        new_you = deepcopy(you)
        new_opponent = deepcopy(opponent)
        n = new_you[i]
        new_you[i] = 0
        current_step = 0
        last_pos = -1
        
        # Distribute seeds
        while n > 0:
            pos = ((i + 1 + current_step) % 13)  # Positions 0-5 (your houses), 6 (your store), 7-11 (opponent's houses)
            if pos < 6:
                new_you[pos] += 1
            elif pos == 6:
                new_you[6] += 1
            else:
                opp_idx = pos - 7
                new_opponent[opp_idx] += 1
            last_pos = pos
            n -= 1
            current_step += 1
        
        # Check for capture
        if last_pos < 6:
            was_empty = (you[last_pos] == 0)
            opp_idx = 5 - last_pos
            if was_empty and new_opponent[opp_idx] > 0:
                captured = new_opponent[opp_idx]
                new_opponent[opp_idx] = 0
                new_you[6] += captured
        
        # Determine if the move gives an extra turn
        in_store = (last_pos == 6)
        
        # Calculate the score based on capture, extra move, and store difference
        score = (-captured, -in_store, (new_you[6] - new_opponent[6]))
        moves.append((score, i))
    
    # Select the best move using lexicographical order of scores (minimize negative values)
    best_move = min(moves, key=lambda x: x[0])[1]
    return best_move
```

### Explanation
1. **Simulating Moves**: For each valid house (non-empty), the code simulates the distribution of seeds starting from the next house in the distribution order. This includes handling edge cases like reaching the end of the player's houses and wrapping around to the opponent's houses.
2. **Capture Check**: After distributing all seeds, the code checks if the last seed landed in a player's house that was empty before the move, and if the corresponding opponent's house has seeds. If both conditions are met, the opponent's seeds are captured.
3. **Extra Move Check**: If the last seed lands in the player's store, the move grants an extra turn.
4. **Scoring**: Each move is scored based on the number of captured seeds (prioritized highest), whether it results in an extra move, and the difference in store sizes. The score is a tuple that Python's `min` function uses to find the best move efficiently by leveraging lexicographical order.

This approach ensures that the policy selects the optimal move by considering immediate gains and future opportunities, adhering to the game's rules and constraints.
