### **Key Design Choices**:

1. **Winning Condition**: 
   - The game is 4x4, and the winning condition is assumed to require **four consecutive pieces** in any row, column, or diagonal. This simplifies checking for victories or threats.

2. **Immediate Win**: 
   - For each empty cell, simulate placing a `1`, and check if it results in a win. Return the first such cell.

3. **Blocking Opponent**:
   - Similarly, for each empty cell, simulate placing a `-1`, and if it would give the opponent a win, block by returning that cell.

4. **Preferred Move Order**:
   - If no immediate win or threat exists, fall back to a priority list of positions sorted by strategic value (center, corners, then edges). This helps optimize long-term game strategy.

5. **Performance Considerations**:
   - The code checks only 16 cells in the board for each step, making it computationally efficient enough for the 1-second time constraint.

6. **Edge Cases**:
   - The fallback (`for r,c in range(4)`) ensures that the function always returns a valid move even if the preferred move order excludes it.

---

### **Implementation Details**:
- `is_win`: A helper function checks for wins in all possible directions (rows, columns, two diagonals).
- `preferred_order`: Cells are checked in order of priority to maximize control of the board early.
- The policy avoids unnecessary full-board checks by first checking only preferred positions, which reduces redundant loops.

def policy(board: list[list[int]]) -> tuple[int, int]:
    def is_win(b, player):
        # Check rows for win
        for row in b:
            if row[0] == player and row[1] == player and row[2] == player and row[3] == player:
                return True
        # Check columns for win
        for c in range(4):
            if b[0][c] == player and b[1][c] == player and b[2][c] == player and b[3][c] == player:
                return True
        # Check main diagonals
        if b[0][0] == player and b[1][1] == player and b[2][2] == player and b[3][3] == player:
            return True
        if b[0][3] == player and b[1][2] == player and b[2][1] == player and b[3][0] == player:
            return True
        return False

    preferred_order = [
        (1, 1), (1, 2), (2, 1), (2, 2),  # Center positions
        (0, 0), (0, 3), (3, 0), (3, 3),  # Corners
        (0, 1), (0, 2), (1, 0), (1, 3), (2, 0), (2, 3), (3, 1), (3, 2)  # Remaining edge cells
    ]

    # Step 1: Check if any move leads to a win
    for r, c in preferred_order:
        if board[r][c] == 0:
            new_board = [row[:] for row in board]
            new_board[r][c] = 1
            if is_win(new_board, 1):
                return (r, c)

    # Step 2: Check if any move blocks the opponent's win
    for r, c in preferred_order:
        if board[r][c] == 0:
            new_board = [row[:] for row in board]
            new_board[r][c] = -1
            if is_win(new_board, -1):
                return (r, c)

    # Step 3: Choose best available move from preferred order
    for r, c in preferred_order:
        if board[r][c] == 0:
            return (r, c)

    # Fallback in case no squares are found (should not occur if board is playable)
    for r in range(4):
        for c in range(4):
            if board[r][c] == 0:
                return (r, c)
