We are solving a 4x4 Tic Tac Toe game. The board is a 4x4 grid with 0 for empty, 1 for our move, and -1 for opponent's move.
We need to return the next move (row, col) as a tuple.

Strategy:
1. First, check if we have an immediate winning move. If so, return that move.
2. Then, check if the opponent has an immediate winning move (i.e., we must block). If we find such a move, return that move to block.
3. If neither, we evaluate each empty cell using a heuristic and choose the move with the highest score.

Heuristic evaluation:
- For each empty cell, we consider the row, column, and diagonals that pass through it.
- For each line (without opponent pieces), we add (number of our pieces in the line) ** 2 to the score. The square is used to emphasize having more pieces in a line.

Implementation details:
- We'll write a helper function `check_win(board, player)` to check if the given player has won (returns True or False).
- We'll write a helper function `evaluate_move(board, i, j)` that returns the heuristic score for placing our piece at (i, j). This function will not modify the board.

We must be efficient: worst-case we evaluate 16 moves, and each move requires checking 4 rows, 4 columns, and up to 2 diagonals (so 10 lines) and for each line we iterate 4 times. This is acceptable.

Edge: if the board is full, we return (0,0) arbitrarily.

def check_win(board, player):
    # Check rows
    for i in range(4):
        if all(board[i][j] == player for j in range(4)):
            return True
    # Check columns
    for j in range(4):
        if all(board[i][j] == player for i in range(4)):
            return True
    # Check main diagonal
    if all(board[i][i] == player for i in range(4)):
        return True
    # Check anti-diagonal
    if all(board[i][3-i] == player for i in range(4)):
        return True
    return False

def evaluate_move(board, i, j):
    score = 0
    
    # Check row i
    count_our = 0
    count_opp = 0
    for k in range(4):
        if board[i][k] == 1:
            count_our += 1
        elif board[i][k] == -1:
            count_opp += 1
    if count_opp == 0:
        score += count_our ** 2
    
    # Check column j
    count_our = 0
    count_opp = 0
    for k in range(4):
        if board[k][j] == 1:
            count_our += 1
        elif board[k][j] == -1:
            count_opp += 1
    if count_opp == 0:
        score += count_our ** 2
    
    # Check main diagonal if (i, j) is on it
    if i == j:
        count_our = 0
        count_opp = 0
        for k in range(4):
            if board[k][k] == 1:
                count_our += 1
            elif board[k][k] == -1:
                count_opp += 1
        if count_opp == 0:
            score += count_our ** 2
    
    # Check anti-diagonal if (i, j) is on it
    if i + j == 3:
        count_our = 0
        count_opp = 0
        for k in range(4):
            if board[k][3-k] == 1:
                count_our += 1
            elif board[k][3-k] == -1:
                count_opp += 1
        if count_opp == 0:
            score += count_our ** 2
    
    return score

def policy(board):
    # Step 1: Check if we have a winning move
    for i in range(4):
        for j in range(4):
            if board[i][j] == 0:
                # Create a copy and place our piece
                new_board = [row[:] for row in board]
                new_board[i][j] = 1
                if check_win(new_board, 1):
                    return (i, j)
    
    # Step 2: Check if we must block an opponent's winning move
    for i in range(4):
        for j in range(4):
            if board[i][j] == 0:
                # Create a copy and simulate opponent's move
                new_board = [row[:] for row in board]
                new_board[i][j] = -1
                if check_win(new_board, -1):
                    return (i, j)
    
    # Step 3: Use heuristic to choose the best move
    best_score = -1
    best_moves = []
    for i in range(4):
        for j in range(4):
            if board[i][j] == 0:
                new_board = [row[:] for row in board]
                new_board[i][j] = 1
                score = evaluate_move(new_board, i, j)
                if score > best_score:
                    best_score = score
                    best_moves = [(i, j)]
                elif score == best_score:
                    best_moves.append((i, j))
    
    if best_moves:
        # Return the first move we found with the best score (from top-left to bottom-right)
        return best_moves[0]
    else:
        # If no empty cell (shouldn't happen in normal play), return (0,0)
        return (0, 0)
