Final check on `policy` and `minimax` flow.
`policy(board)`:
1. Initialize `best_score` and `best_move`.
2. Find all `empty_cells`.
3. ***Immediate Win Check:*** Iterate `empty_cells`. If placing `1` at `(r,c)` results in `check_win(board, 1)`, immediately return `(r,c)`. This finds direct winning moves without needing minimax. (This is generally a good first optimization).
4. For each `(r, c)` in `empty_cells`:
    a. Make move `board[r][c] = 1`.
    b. Call `score = minimax(board, -1, -math.inf, math.inf)` (opponent plays next).
    c. Undo move `board[r][c] = 0`.
    d. Update `best_score` and `best_move`.
    e. If `best_score == 1`, return `best_move` (we found a winning path).
5. Return `best_move`.

This order is good: check for immediate win, then use full minimax to find the best future guaranteed score. This guarantees finding a win if one exists, and otherwise finds the best possible outcome (draw, or delay loss).
