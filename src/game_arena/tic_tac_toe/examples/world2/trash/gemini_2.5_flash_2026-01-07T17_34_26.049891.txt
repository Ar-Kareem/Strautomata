**Game State:**
- `board`: 4x4 list of lists, `0` for empty, `1` for AI, `-1` for opponent.

**Goal:** Return `(row, col)` for the best move.

**Minimax Algorithm:**
1.  **Terminal State Check:**
    *   Win condition: Check if `1` (AI) or `-1` (opponent) has 4 in a row/column/diagonal.
    *   Tie condition: Check if the board is full.
    *   Evaluate the score:
        *   AI win: +1
        *   Opponent win: -1
        *   Tie: 0
    *   For a 4x4 board, a win is 4 identical pieces in a line (horizontal, vertical, or diagonal).

2.  **Minimizing/Maximizing Player:**
    *   If it's the AI's turn (maximizing player), try to maximize the score.
    *   If it's the opponent's turn (minimizing player), try to minimize the score.

3.  **Recursive Calls:** For each empty cell, simulate placing a piece and call Minimax on the new board state.

**Alpha-Beta Pruning:**
Optimize Minimax by cutting off branches that won't affect the final decision.
*   `alpha`: The best score the maximizing player can guarantee so far.
*   `beta`: The best score the minimizing player can guarantee so far.
*   If `beta <= alpha`, prune the current branch.

The function should return a tuple `(row, col)`.

My strategy will be to implement the Minimax algorithm with Alpha-Beta pruning, which is a standard approach for creating a perfect player in finite, two-player, zero-sum games like Tic Tac Toe.

**Algorithm Breakdown:**

1.  **`check_win(board)`:**
    *   This helper function will iterate through all possible 4-in-a-row winning lines:
        *   Horizontal (4 rows)
        *   Vertical (4 columns)
        *   Diagonals (2 main diagonals of length 4)
    *   If any player (1 or -1) has 4 in a line, it returns that player's ID. Otherwise, it returns `0` (no winner yet).

2.  **`is_board_full(board)`:**
    *   Checks if there are any `0` (empty) cells left on the board. Returns `True` if full, `False` otherwise.

3.  **`evaluate(board)`:**
    *   Uses `check_win` to determine if there's a winner. If the AI (`1`) wins, it returns `1`. If the opponent (`-1`) wins, it returns `-1`.
    *   If there's no winner but the board is full (`is_board_full`), it indicates a tie and returns `0`.
    *   If the game is still ongoing, it returns `None`.

4.  **`minimax(board, depth, is_maximizing_player, alpha, beta)`:**
    *   This is the core recursive function for the AI.
    *   **Base Case:** If `evaluate(board)` returns a non-`None` score, that score is returned immediately (game over).
    *   **Maximizing Player's Turn (`is_maximizing_player` is True, AI's turn in a sub-game):**
        *   Initializes `max_eval = -infinity`.
        *   Iterates through all empty cells. For each empty cell:
            *   Places the AI's piece.
            *   Recursively calls `minimax` for the next state (opponent's turn, `is_maximizing_player=False`).
            *   Updates `max_eval` with the maximum score found so far.
            *   Performs **Alpha-Beta Pruning**: Updates `alpha`. If `beta <= alpha`, the current branch can be pruned, as the minimizing player won't allow this path.
            *   Undoes the move (resets the cell to `EMPTY`) to explore other possibilities.
        *   Returns `max_eval`.
    *   **Minimizing Player's Turn (`is_maximizing_player` is False, Opponent's turn in a sub-game):**
        *   Similar logic to the maximizing player, but aims to minimize the score.
        *   Initializes `min_eval = +infinity`.
        *   Updates `min_eval` with the minimum score found.
        *   Performs **Alpha-Beta Pruning**: Updates `beta`. If `beta <= alpha`, prune.
        *   Undoes the move.
        *   Returns `min_eval`.

5.  **`policy(board)`:**
    *   This is the main function that receives the current board state.
    *   **Immediate Win/Block Check:** It first iterates through all empty cells to see if it can make a winning move immediately or if it needs to block an opponent's winning move. This is a crucial optimization to quickly capture obvious moves.
    *   **Minimax Search:** If no immediate win or block is found, it proceeds with the full Minimax search.
        *   Gathers all empty cells.
        *   **Move Ordering Heuristic:** It sorts the `empty_cells` to prioritize central moves (e.g., (1,1), (1,2), (2,1), (2,2)), then corners, then edges. This doesn't change the correctness of a perfect Minimax but can significantly speed up Alpha-Beta pruning by finding good moves earlier.
        *   For each potential move:
            *   Places the AI's piece on a temporary board.
            *   Calls `minimax`. Since the AI just made a move, the `minimax` call simulates the *opponent's* turn, so `is_maximizing_player` is set to `False`.
            *   Undoes the move.
            *   Keeps track of the move that yielded the `best_score`.
            *   If a score of `1` (guaranteed win for AI) is found, it immediately returns that move without searching further.
    *   Returns the `best_move` found.

The 4x4 board size is small enough for this Minimax with Alpha-Beta pruning to execute within the 1-second time limit, especially with early win/block checks and move ordering. Helper functions are nested within `policy` for self-containment.

import math

def policy(board: list[list[int]]) -> tuple[int, int]:
    BOARD_SIZE = 4
    EMPTY = 0
    AI_PLAYER = 1
    OPPONENT = -1

    def check_win(current_board):
        # Check rows
        for r in range(BOARD_SIZE):
            for c in range(BOARD_SIZE - 3): # Check for 4 consecutive starting at `c`
                if current_board[r][c] != EMPTY and \
                   current_board[r][c] == current_board[r][c+1] and \
                   current_board[r][c] == current_board[r][c+2] and \
                   current_board[r][c] == current_board[r][c+3]:
                    return current_board[r][c]

        # Check columns
        for c in range(BOARD_SIZE):
            for r in range(BOARD_SIZE - 3): # Check for 4 consecutive starting at `r`
                if current_board[r][c] != EMPTY and \
                   current_board[r][c] == current_board[r+1][c] and \
                   current_board[r][c] == current_board[r+2][c] and \
                   current_board[r][c] == current_board[r+3][c]:
                    return current_board[r][c]

        # Check diagonals (top-left to bottom-right)
        for r in range(BOARD_SIZE - 3):
            for c in range(BOARD_SIZE - 3):
                if current_board[r][c] != EMPTY and \
                   current_board[r][c] == current_board[r+1][c+1] and \
                   current_board[r][c] == current_board[r+2][c+2] and \
                   current_board[r][c] == current_board[r+3][c+3]:
                    return current_board[r][c]

        # Check anti-diagonals (top-right to bottom-left)
        for r in range(BOARD_SIZE - 3):
            for c in range(3, BOARD_SIZE): # Starts from column 3
                if current_board[r][c] != EMPTY and \
                   current_board[r][c] == current_board[r+1][c-1] and \
                   current_board[r][c] == current_board[r+2][c-2] and \
                   current_board[r][c] == current_board[r+3][c-3]:
                    return current_board[r][c]

        return EMPTY # No winner

    def is_board_full(current_board):
        for r in range(BOARD_SIZE):
            for c in range(BOARD_SIZE):
                if current_board[r][c] == EMPTY:
                    return False
        return True

    def evaluate(current_board):
        winner = check_win(current_board)
        if winner == AI_PLAYER:
            return 1 # AI wins
        elif winner == OPPONENT:
            return -1 # Opponent wins
        elif is_board_full(current_board):
            return 0 # Tie
        return None # Game not over

    def minimax(current_board, depth, is_maximizing_player, alpha, beta):
        score = evaluate(current_board)

        # Base case: if game is over, return the score
        if score is not None:
            return score

        if is_maximizing_player:
            # AI (maximizing player) wants to maximize its score
            max_eval = -math.inf
            for r in range(BOARD_SIZE):
                for c in range(BOARD_SIZE):
                    if current_board[r][c] == EMPTY:
                        current_board[r][c] = AI_PLAYER # Make the move
                        eval = minimax(current_board, depth + 1, False, alpha, beta)
                        current_board[r][c] = EMPTY # Undo the move
                        max_eval = max(max_eval, eval)
                        alpha = max(alpha, eval)
                        if beta <= alpha: # Alpha-Beta Pruning
                            return max_eval
            return max_eval
        else:
            # Opponent (minimizing player) wants to minimize AI's score
            min_eval = math.inf
            for r in range(BOARD_SIZE):
                for c in range(BOARD_SIZE):
                    if current_board[r][c] == EMPTY:
                        current_board[r][c] = OPPONENT # Make the move
                        eval = minimax(current_board, depth + 1, True, alpha, beta)
                        current_board[r][c] = EMPTY # Undo the move
                        min_eval = min(min_eval, eval)
                        beta = min(beta, eval)
                        if beta <= alpha: # Alpha-Beta Pruning
                            return min_eval
            return min_eval

    best_move = (-1, -1)
    best_score = -math.inf

    # Phase 1: Check for immediate winning move for self
    for r in range(BOARD_SIZE):
        for c in range(BOARD_SIZE):
            if board[r][c] == EMPTY:
                board[r][c] = AI_PLAYER
                if check_win(board) == AI_PLAYER:
                    board[r][c] = EMPTY # Undo move
                    return (r, c)
                board[r][c] = EMPTY # Undo move

    # Phase 2: Check for immediate blocking move for opponent
    # This prevents the opponent from winning on their next turn
    for r in range(BOARD_SIZE):
        for c in range(BOARD_SIZE):
            if board[r][c] == EMPTY:
                board[r][c] = OPPONENT
                if check_win(board) == OPPONENT:
                    board[r][c] = EMPTY # Undo move
                    return (r, c)
                board[r][c] = EMPTY # Undo move

    # Phase 3: If no immediate win/block, use Minimax to find the best strategic move
    empty_cells = []
    for r in range(BOARD_SIZE):
        for c in range(BOARD_SIZE):
            if board[r][c] == EMPTY:
                empty_cells.append((r, c))

    # Heuristic: Sort empty cells to prioritize central moves for faster pruning
    # Central cells for a 4x4 board are (1,1), (1,2), (2,1), (2,2).
    # Then corners, then other edges. This helps alpha-beta prune more effectively.
    def sort_key_for_moves(move):
        r, c = move
        if (1 <= r <= 2) and (1 <= c <= 2):
            return 0 # Most central
        elif (r == 0 or r == 3) and (c == 0 or c == 3):
            return 1 # Corners
        else:
            return 2 # Edges

    empty_cells.sort(key=sort_key_for_moves)

    for r, c in empty_cells:
        board[r][c] = AI_PLAYER # Make chosen move for evaluation
        # After AI's move, it's the opponent's turn, so minimax starts minimizing.
        score = minimax(board, 0, False, -math.inf, math.inf)
        board[r][c] = EMPTY # Undo the temporary move

        if score > best_score:
            best_score = score
            best_move = (r, c)
        
        # If a guaranteed winning path is found, no need to search further.
        # This is the highest possible score.
        if best_score == 1:
            return best_move

    # Return the best move found by minimax (or the only move if all lead to tie/loss)
    return best_move
