To solve the problem of generating the optimal next move for a 3x3 Tic Tac Toe game, we apply a strategy that prioritizes winning moves, blocks the opponent's winning moves, and falls back to a heuristic-based move selection when no immediate threats or opportunities exist.

The logic follows these steps:

1. **Check for a Winning Move**: For every empty cell, simulate placing `1` (my symbol) and determine if it results in a win. If so, return that move immediately.
  
2. **Block Opponent's Winning Move**: For every empty cell, simulate placing `-1` (opponent's symbol) and check if it leads to a win. If so, return that move to block the opponent.

3. **Fallback Move Prioritization**: If no winning or blocking move is found, the code selects an empty cell based on a priority list:
   - Center `(1,1)` is preferred first.
   - Then, the four corners in order: `(0,0)`, `(0,2)`, `(2,0)`, `(2,2)`.
   - Finally, the four edge cells: `(0,1)`, `(1,0)`, `(2,1)`, `(1,2)`.

This approach ensures the AI will always select an optimal move, minimizing the chance of losing and exploiting all available immediate winning opportunities.

The helper function `is_win` is used to evaluate whether placing a symbol leads to a winning condition. The function adheres to the time constraints and operates efficiently given the small size of a 3x3 board.

def policy(board: list[list[int]]) -> tuple[int, int]:
    def is_win(player):
        # Check rows, columns, and diagonals for a win
        for i in range(3):
            if all(board[i][j] == player for j in range(3)):
                return True
            if all(board[j][i] == player for j in range(3)):
                return True
        if all(board[i][i] == player for i in range(3)):
            return True
        if all(board[i][2 - i] == player for i in range(3)):
            return True
        return False

    # 1. Try to win
    for i in range(3):
        for j in range(3):
            if board[i][j] == 0:
                board[i][j] = 1
                if is_win(1):
                    board[i][j] = 0  # Undo move
                    return (i, j)
                board[i][j] = 0  # Undo move

    # 2. Try to block opponent's win
    for i in range(3):
        for j in range(3):
            if board[i][j] == 0:
                board[i][j] = -1
                if is_win(-1):
                    board[i][j] = 0  # Undo move
                    return (i, j)
                board[i][j] = 0  # Undo move

    # 3. Priority list: Center, then corners, then edges
    priority_moves = [(1, 1), (0, 0), (0, 2), (2, 0), (2, 2),
                      (0, 1), (1, 0), (2, 1), (1, 2)]
    for r, c in priority_moves:
        if board[r][c] == 0:
            return (r, c)

    # Fallback (should never reach here with 3x3 board)
    for i in range(3):
        for j in range(3):
            if board[i][j] == 0:
                return (i, j)
