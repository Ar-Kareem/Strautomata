The approach to solve the Tic Tac Toe policy is based on a stepwise prioritization of actions: win, block, and then choose a strategic position. Here's the breakdown:

1. **Check for Immediate Win**: Simulate placing our marker (`1`) in each empty cell and check if it results in a win. If so, choose that cell immediately.

2. **Block Opponent’s Win**: If no winning move exists, simulate the opponent’s move (`-1`) to detect potential wins for them and block by taking that cell.

3. **Follow Strategic Prioritization**: If no forced moves are available, choose the best available cell based on a fixed priority: center, then corners, then edges. This ensures consistent and strategic placement in the absence of immediate threats or opportunities.

The helper function `is_win` verifies whether the current board state contains a winning condition for the given player. The move selection prioritizes cells to ensure optimal play in all scenarios.

def policy(board: list[list[int]]) -> tuple[int, int]:
    def is_win(bo, player):
        # Check rows
        for row in bo:
            if all(cell == player for cell in row):
                return True
        # Check columns
        for col in range(3):
            if all(bo[row][col] == player for row in range(3)):
                return True
        # Check diagonals
        if all(bo[i][i] == player for i in range(3)):
            return True
        if all(bo[i][2 - i] == player for i in range(3)):
            return True
        return False

    priority_order = [(1, 1), (0, 0), (0, 2), (2, 0), (2, 2), (0, 1), (1, 0), (1, 2), (2, 1)]
    empty_cells = [(i, j) for i, j in priority_order if board[i][j] == 0]

    # Check for winning move
    for i, j in empty_cells:
        board[i][j] = 1
        if is_win(board, 1):
            board[i][j] = 0
            return (i, j)
        board[i][j] = 0

    # Check for blocking opponent's move
    for i, j in empty_cells:
        board[i][j] = -1
        if is_win(board, -1):
            board[i][j] = 0
            return (i, j)
        board[i][j] = 0

    # Default to first available strategic spot
    return empty_cells[0]
