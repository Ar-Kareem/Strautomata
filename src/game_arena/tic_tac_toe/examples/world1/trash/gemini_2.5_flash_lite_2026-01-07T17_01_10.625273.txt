def policy(board: list[list[int]]) -> tuple[int, int]:
    my_player = 1
    opponent = -1

    # 1. Win: Check if I can win in the next move
    winning_move = check_for_winning_move(board, my_player)
    if winning_move:
        return winning_move

    # 2. Block: Check if opponent can win in the next move and block it
    blocking_move = check_for_winning_move(board, opponent)
    if blocking_move:
        return blocking_move

    # 3. Fork: Create a situation where I have two winning opportunities
    empty_cells = get_empty_cells(board)
    for r, c in empty_cells:
        # Temporarily place my mark to check for a fork
        temp_board = copy.deepcopy(board)
        temp_board[r][c] = my_player
        
        # Count potential winning lines from this move
        if count_potential_wins(temp_board, my_player) >= 2:
            return (r, c)

    # 4. Block Opponent's Fork: Prevent opponent from creating two winning opportunities
    for r, c in empty_cells:
        # Temporarily place opponent's mark to check for opponent's fork
        temp_board = copy.deepcopy(board)
        temp_board[r][c] = opponent
        
        # Count potential winning lines opponent would have from this move
        if count_potential_wins(temp_board, opponent) >= 2:
            return (r, c)

    # 5. Center: Take the center if available
    if board[1][1] == 0:
        return (1, 1)

    # 6. Opposite Corner: If opponent is in a corner, take the opposite corner
    corners = [(0, 0), (0, 2), (2, 0), (2, 2)]
    for r_corner, c_corner in corners:
        if board[r_corner][c_corner] == opponent:
            # Find the opposite corner
            if r_corner == 0 and c_corner == 0: opposite = (2, 2)
            elif r_corner == 0 and c_corner == 2: opposite = (2, 0)
            elif r_corner == 2 and c_corner == 0: opposite = (0, 2)
            else: opposite = (0, 0)

                return opposite

    # 7. Empty Corner: Take any empty corner
    for r_corner, c_corner in corners:

            return (r_corner, c_corner)

    # 8. Empty Side: Take any empty side square

    # If somehow no move is found (e.g., board is full), return any empty cell if available
    if empty_cells:
        return empty_cells[0]

I will implement a standard Tic Tac Toe AI strategy based on prioritized moves:
1.  **Win:** If I can win on the next move, take it.
2.  **Block:** If the opponent can win on their next move, block it.
3.  **Fork:** Create a situation where I have two ways to win on my next turn.
4.  **Block Opponent's Fork:** Prevent the opponent from creating two ways to win on their next turn.
5.  **Center:** Take the center square if it's available.
6.  **Opposite Corner:** If the opponent is in a corner, take the opposite corner.
7.  **Empty Corner:** Take any available corner square.
8.  **Empty Side:** Take any available side square.

*   `get_empty_cells(board)`: Returns a list of `(row, col)` tuples for all empty cells.
*   `check_for_winning_move(board, player)`: Checks if a given `player` can win in the next move by looking at rows, columns, and diagonals. If a winning move exists, it returns the `(row, col)`; otherwise, `None`. This is used for steps 1 and 2.
*   `count_potential_wins(board, player)`: Counts how many lines (rows, columns, diagonals) a `player` would have two marks in, with one empty cell. This is used to detect forks (step 3) and opponent forks (step 4).
