```python
def check_win(board, player):
    # Check rows
    for row in board:
        if all(cell == player for cell in row):
            return True
    # Check columns
    for col_idx in range(3):
        if all(board[row_idx][col_idx] == player for row_idx in range(3)):
            return True
    # Check diagonals
    if all(board[i][i] == player for i in range(3)):
        return True
    if all(board[i][2 - i] == player for i in range(3)):
        return True
    return False

def count_potential_wins(board, player):
    # Counts how many ways 'player' could win in the *next* move
    empty_cells = []
    for r in range(3):
        for c in range(3):
            if board[r][c] == 0:
                empty_cells.append((r, c))

    potential_wins = 0
    for r_e, c_e in empty_cells:
        # Simulate placing player's mark
        board[r_e][c_e] = player
        if check_win(board, player):
            potential_wins += 1
        # Revert the move
        board[r_e][c_e] = 0
    return potential_wins

```

       - Simulate `board[1][2]=-1`: No win (C2 is `-1,0,0` not full)
       - Simulate `board[2][0]=-1`: C0 `(-1,-1,-1)`. Win. Potential count = 2.
       So placing at (1,0) makes _opponent_ have 2 winning lines immediately (Row 0 if (0,1) is taken by -1 AND Col 0 if (2,0) taken by -1).
       Actually, Row 0 is `(-1,0,-1)`. If (0,1) is `L`, then `(-1,L,-1)` is NOT a win.
       Col 0 is `(-1,-1,0)`. If (2,0) is `L`, then `(-1,-1,L)` IS a win.
       This is precisely what `check_win` does.

       Let's re-examine `count_potential_wins` with the actual win condition logic:
       `check_win(board, player)` scans rows/cols/diagonals.
       Example:
       -1  0 -1
       -1  1  0
       0   0  0
       `count_potential_wins(board, -1)`:
       Empty cells: (0,1), (1,2), (2,0), (2,1), (2,2)
       - Try (0,1) for -1:
         Board state:
         -1 -1 -1  <- WIN FOR -1 (row 0)
         -1  1  0
         0   0  0
         Count = 1
       - Try (1,2) for -1:
         Board state:
         -1 0 -1
         -1 1 -1  <- WIN FOR -1 (col 2 is (-1,0,-1)) No, C2 is currently (0,0,0). So if (1,2) is -1, C2 is (0,-1,0). No win.
         0  0 -1
         Count = 1 (remains 1)
       - Try (2,0) for -1:
         Board state:
         -1 0 -1
         -1 1  0
         -1 0  0  <- WIN FOR -1 (col 0)
         Count = 2!
       Thus, placing `-1` at `(1,0)` creates `2` winning lines for the opponent. So, my `policy` should return `(1,0)` to block this opponent's fork.
       This confirms my `count_potential_wins` and fork detection is probably correct.

7. Sides.

The order of checks is crucial for Tic Tac Toe strategy.
1. Win
2. Block
3. Center
4. My fork
5. Block opponent's fork
6. Empty Corner
7. Empty Side

This order seems standard and robust for a perfect Tic Tac Toe player.

def policy(board: list[list[int]]) -> tuple[int, int]:
    """
    Determines the best next move for a Tic Tac Toe game.

    Args:
        board: A 3x3 list of lists representing the Tic Tac Toe board.
               0: empty, 1: your piece, -1: opponent's piece.

    Returns:
        A tuple (row, col) indicating the chosen move.
    """

    # Helper function to check if a player has won on the current board.
    def check_win(current_board: list[list[int]], player: int) -> bool:
        # Check rows
        for row in current_board:
            if all(cell == player for cell in row):
                return True
        # Check columns
        for col_idx in range(3):
            if all(current_board[row_idx][col_idx] == player for row_idx in range(3)):
                return True
        # Check diagonals
        if all(current_board[i][i] == player for i in range(3)):
            return True
        if all(current_board[i][2 - i] == player for i in range(3)):
            return True
        return False

    # Helper function to count how many single moves would lead to a win for a player.
    # This is used for fork detection.
    def count_potential_wins(current_board: list[list[int]], player: int) -> int:
        potential_wins = 0
        temp_empty_cells = []
        for r in range(3):
            for c in range(3):
                if current_board[r][c] == 0:
                    temp_empty_cells.append((r, c))

        for r_e, c_e in temp_empty_cells:
            current_board[r_e][c_e] = player  # Temporarily place player's mark
            if check_win(current_board, player):
                potential_wins += 1
            current_board[r_e][c_e] = 0  # Revert the move
        return potential_wins

    empty_cells = []
    for r in range(3):
        for c in range(3):
            if board[r][c] == 0:
                empty_cells.append((r, c))

    # --- Strategy Steps ---

    # 1. Check for immediate winning move (for me)
    for r, c in empty_cells:
        board[r][c] = 1  # Simulate my move
        if check_win(board, 1):
            board[r][c] = 0  # Revert
            return (r, c)
        board[r][c] = 0  # Revert

    # 2. Check for immediate blocking move (opponent's winning move)
    for r, c in empty_cells:
        board[r][c] = -1  # Simulate opponent's move
        if check_win(board, -1):
            board[r][c] = 0  # Revert
            return (r, c)
        board[r][c] = 0  # Revert

    # 3. Take the center if available
    if board[1][1] == 0:
        return (1, 1)

    # 4. Check for creating a fork (two winning lines for me)
    my_fork_moves = []
    for r, c in empty_cells:
        board[r][c] = 1  # Simulate my move
        if count_potential_wins(board, 1) >= 2:
            my_fork_moves.append((r, c))
        board[r][c] = 0  # Revert

    if my_fork_moves:
        # If I can create a fork, take the first one found
        return my_fork_moves[0]

    # 5. Block an opponent's fork (prevent them from creating two winning lines)
    opponent_fork_moves = []
    for r, c in empty_cells:
        board[r][c] = -1  # Simulate opponent's move
        if count_potential_wins(board, -1) >= 2:
            opponent_fork_moves.append((r, c))
        board[r][c] = 0  # Revert

    if opponent_fork_moves:
        # If opponent can create a fork, block one of the cells that forms it.
        # Taking the first move that leads to an opponent's fork is sufficient.
        return opponent_fork_moves[0]

    # 6. Take an empty corner
    corners = [(0, 0), (0, 2), (2, 0), (2, 2)]
    for r, c in corners:
        if board[r][c] == 0:
            return (r, c)

    # 7. Take an empty side (edge)
    sides = [(0, 1), (1, 0), (1, 2), (2, 1)]
    for r, c in sides:
        if board[r][c] == 0:
            return (r, c)

    # This case should theoretically not be reached in a valid Tic Tac Toe game
    # as there should always be an empty cell until the game is over.
    # As a fallback, return the first available empty cell.
    if empty_cells:
        return empty_cells[0]
    
    # If no empty cells and no other condition met (game is likely over or draw)
    return (-1, -1) # Should not happen based on game rules
