To solve this problem, we need to create an AI policy function for a Tic Tac Toe game that plays optimally. The function will be evaluated on a 3x3 board where each cell can be 0 (empty), 1 (AI), or -1 (opponent). The goal is to return the best possible move as a tuple (row, column) that leads to a win, blocks the opponent's win, or ensures the best outcome in the long run using the Minimax algorithm.

### Approach
1. **Immediate Win Check**: Before diving into complex calculations, check if there is an immediate move that allows the AI to win. If such a move exists, take it immediately.
2. **Immediate Block Check**: Similarly, check if the opponent can win in their next move and block them if possible.
3. **Minimax Algorithm**: If neither an immediate win nor block is available, use the Minimax algorithm to evaluate all possible future moves and choose the optimal one. The Minimax algorithm will recursively simulate all possible moves and determine the best outcome assuming both players play optimally.

The Minimax algorithm is well-suited for games like Tic Tac Toe because it systematically explores all possible game states, ensuring optimal play by considering both the AI's moves and the opponent's responses.

def policy(board: list[list[int]]) -> tuple[int, int]:
    def check_win(b, player):
        # Check rows
        for row in b:
            if row[0] == row[1] == row[2] == player:
                return True
        # Check columns
        for col in range(3):
            if b[0][col] == b[1][col] == b[2][col] == player:
                return True
        # Check diagonals
        if b[0][0] == b[1][1] == b[2][2] == player:
            return True
        if b[0][2] == b[1][1] == b[2][0] == player:
            return True
        return False

    def is_game_over(b):
        if check_win(b, 1):
            return (True, 1)
        if check_win(b, -1):
            return (True, -1)
        # Check if board is full
        for row in b:
            if 0 in row:
                return (False, None)
        return (True, 0)  # Draw

    def minimax(b, is_maximizing):
        game_over, winner = is_game_over(b)
        if game_over:
            if winner == 1:
                return 1
            elif winner == -1:
                return -1
            else:
                return 0

        if is_maximizing:
            best = -float('inf')
            for r in range(3):
                for c in range(3):
                    if b[r][c] == 0:
                        new_b = [row[:] for row in b]
                        new_b[r][c] = 1
                        score = minimax(new_b, False)
                        best = max(best, score)
            return best
        else:
            best = float('inf')
            for r in range(3):
                for c in range(3):
                    if b[r][c] == 0:
                        new_b = [row[:] for row in b]
                        new_b[r][c] = -1
                        score = minimax(new_b, True)
                        best = min(best, score)
            return best

    # Check if any move leads to immediate win
    for r in range(3):
        for c in range(3):
            if board[r][c] == 0:
                new_b = [row[:] for row in board]
                new_b[r][c] = 1
                if check_win(new_b, 1):
                    return (r, c)

    # Check if any move blocks opponent's immediate win
    for r in range(3):
        for c in range(3):
            if board[r][c] == 0:
                new_b = [row[:] for row in board]
                new_b[r][c] = -1
                if check_win(new_b, -1):
                    return (r, c)

    # Otherwise, find the move with the highest score via minimax
    best_score = -float('inf')
    best_move = None
    for r in range(3):
        for c in range(3):
            if board[r][c] == 0:
                new_b = [row[:] for row in board]
                new_b[r][c] = 1
                score = minimax(new_b, False)
                if score > best_score:
                    best_score = score
                    best_move = (r, c)
    return best_move
