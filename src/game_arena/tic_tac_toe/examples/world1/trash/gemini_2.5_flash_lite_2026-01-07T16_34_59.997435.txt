I will implement a heuristic-based strategy, prioritizing moves that lead to a win, block the opponent's win, and strategically control the board. The order of priority for moves is crucial. A standard and effective order for Tic Tac Toe is:

1.  **Win:** If I can make a move that wins the game, I should take it.
2.  **Block:** If the opponent can make a move that wins the game in their next turn, I must block that move.
3.  **Center:** The center square `(1, 1)` is strategically the most valuable. If it's empty, take it.
4.  **Opposite Corner:** If the opponent has taken a corner, and the opposite corner is empty, take it. This is a good move to set up future forks.
5.  **Empty Corner:** If any corner square is empty, take it. Corners are generally better than side squares.
6.  **Empty Side:** If none of the above moves are possible, take any available side square.

To implement this strategy, I'll need a few helper functions:
*   `get_empty_cells(board)`: This function will return a list of all available `(row, col)` positions on the board.
*   `check_win(board, player)`: This function will check if a given `player` has won the game on the current `board`. It looks for three in a row, column, or diagonal.

The `policy` function will orchestrate these checks in the defined priority order. If a move is found at a certain priority level, it will be returned immediately.

# Helper functions for Tic Tac Toe AI policy

def get_empty_cells(board: list[list[int]]) -> list[tuple[int, int]]:
    """
    Identifies and returns all empty cells on the Tic Tac Toe board.

    Args:
        board: A 3x3 list of lists representing the game board (0: empty, 1: player 1, -1: player -1).

    Returns:
        A list of (row, col) tuples for all empty cells on the board.
    """
    empty = []
    for r in range(3):
        for c in range(3):
            if board[r][c] == 0:
                empty.append((r, c))
    return empty

def check_win(board: list[list[int]], player: int) -> bool:
    """
    Checks if a given player has won the Tic Tac Toe game on the current board.

    Args:
        board: A 3x3 list of lists representing the game board.
        player: The player to check for a win (1 for AI, -1 for opponent).

    Returns:
        True if the player has three in a row, column, or diagonal, False otherwise.
    """
    # Check rows
    for r in range(3):
        if all(board[r][c] == player for c in range(3)):
            return True
    # Check columns
    for c in range(3):
        if all(board[r][c] == player for r in range(3)):
            return True
    # Check diagonals
    # Top-left to bottom-right
    if all(board[i][i] == player for i in range(3)):
        return True
    # Top-right to bottom-left
    if all(board[i][2-i] == player for i in range(3)):
        return True
    return False

# Main policy function
def policy(board: list[list[int]]) -> tuple[int, int]:
    """
    Determines the next move for Tic Tac Toe using a prioritized heuristic strategy.

    The strategy follows these priorities:
    1. Make a winning move for the AI (player 1).
    2. Block the opponent's (player -1) winning move.
    3. Take the center square (1, 1) if available.
    4. If the opponent has taken a corner, take the opposite corner (if available).
    5. Take any available corner square.
    6. Take any available side square.

    Args:
        board: A 3x3 list of lists representing the game board.
               0: empty, 1: player 1 (you), -1: player -1 (opponent).

    Returns:
        A tuple (row, col) indicating the chosen move (0-2, 0-2).
    """
    empty_cells = get_empty_cells(board)

    # 1. Check for a winning move for myself (player 1)
    for r, c in empty_cells:
        board[r][c] = 1  # Simulate move
        if check_win(board, 1):
            board[r][c] = 0  # Undo simulation before returning
            return (r, c)
        board[r][c] = 0  # Undo simulation if it wasn't a winning move

    # 2. Check for opponent's winning move and block it
    for r, c in empty_cells:
        board[r][c] = -1  # Simulate opponent's move
        if check_win(board, -1):
            board[r][c] = 0  # Undo simulation before returning
            return (r, c)
        board[r][c] = 0  # Undo simulation if it wasn't an opponent's winning move

    # 3. Take the center square if available
    if board[1][1] == 0:
        return (1, 1)

    # 4. Take an opposite corner if the opponent occupies a corner and its opposite is free
    # This strategy is particularly effective in openings.
    opposite_corner_pairs = [
        ((0, 0), (2, 2)),  # Check pair (0,0) vs (2,2)
        ((0, 2), (2, 0))   # Check pair (0,2) vs (2,0)
    ]
    for (corner1_coords, corner2_coords) in opposite_corner_pairs:
        r1, c1 = corner1_coords
        r2, c2 = corner2_coords
        
        # Check if opponent occupies corner1 and corner2 is empty
        if board[r1][c1] == -1 and board[r2][c2] == 0:
            return (r2, c2)
        # Check if opponent occupies corner2 and corner1 is empty
        if board[r2][c2] == -1 and board[r1][c1] == 0:
            return (r1, c1)

    # 5. Take any available corner square
    corners = [(0, 0), (0, 2), (2, 0), (2, 2)]
    for r, c in corners:
        if board[r][c] == 0:
            return (r, c)

    # 6. Take any available side square
    sides = [(0, 1), (1, 0), (1, 2), (2, 1)]
    for r, c in sides:
        if board[r][c] == 0:
            return (r, c)

    # Fallback: If for some reason no move has been returned yet, and there are empty cells.
    # This should ideally not happen as all possibilities (corners, sides) are covered by the logic above.
    # This acts as a safety net. For example, if the board is full upon calling this function,
    # empty_cells would be empty, and the RuntimeError would be raised.
    if empty_cells:
        return empty_cells[0]
    else:
        # If empty_cells is empty, the board is full. The problem implies
        # this function is called when a move is possible.
        # Therefore, reaching here indicates an invalid game state for making a move.
        raise RuntimeError("Board is full, no moves possible.")
