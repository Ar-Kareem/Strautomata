To solve the Tic Tac Toe problem, we need an effective move selection strategy. The goal is to win if possible, block the opponent's win if necessary, and otherwise follow standard positional strategies (e.g., take the center, then a corner, then an edge). The solution works as follows:

1. **Check for immediate win**: If placing a move at any empty cell leads to a win, choose that move.
2. **Check for opponent's win**: If the opponent can win by placing in an empty cell, block it.
3. **Default strategy**: If there's no immediate win or block move, choose the center first, followed by a corner, and finally an edge.

The `is_win` helper function checks if a given player has won on a board. We simulate each possible move using a copy of the board to avoid altering the input.

def policy(board: list[list[int]]) -> tuple[int, int]:
    def is_win(b, player):
        # Check rows
        for row in range(3):
            if all(b[row][col] == player for col in range(3)):
                return True
        # Check columns
        for col in range(3):
            if all(b[row][col] == player for row in range(3)):
                return True
        # Check diagonals
        if all(b[i][i] == player for i in range(3)):
            return True
        if all(b[i][2 - i] == player for i in range(3)):
            return True
        return False

    # Check for a winning move
    for row in range(3):
        for col in range(3):
            if board[row][col] == 0:
                temp_board = [row_.copy() for row_ in board]
                temp_board[row][col] = 1
                if is_win(temp_board, 1):
                    return (row, col)

    # Check for opponent winning moves and block
    for row in range(3):
        for col in range(3):
            if board[row][col] == 0:
                temp_board = [row_.copy() for row_ in board]
                temp_board[row][col] = -1
                if is_win(temp_board, -1):
                    return (row, col)

    # Choose center if available
    if board[1][1] == 0:
        return (1, 1)

    # Check corners in order
    for row, col in [(0, 0), (0, 2), (2, 0), (2, 2)]:
        if board[row][col] == 0:
            return (row, col)

    # Choose edges in order
    for row, col in [(0, 1), (1, 0), (1, 2), (2, 1)]:
        if board[row][col] == 0:
            return (row, col)

    # Fallback (should not reach here as board must have at least one open cell)
    return (0, 0)
