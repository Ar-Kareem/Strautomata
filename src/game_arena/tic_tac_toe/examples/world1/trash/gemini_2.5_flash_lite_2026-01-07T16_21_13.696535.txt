4.  **Opposite Corner:** If the opponent has taken a corner, and the opposite corner is empty, take it. (This is often covered implicitly by prioritizing any corner move).
5.  **Empty Corner:** If there are any empty corner squares, take one.
6.  **Empty Side:** If there are any empty side squares (not corners or center), take one.

*   **Helper Function for Win/Block:** I'll create a helper function, say `find_win_or_block_move(board, player_id)`, that iterates through all rows, columns, and diagonals. For each line, it checks if `player_id` has two pieces and there's exactly one empty cell. If so, it returns the coordinates of that empty cell. This function can be used for both finding my winning moves (using `player_id=1`) and for finding opponent's winning moves to block (using `player_id=-1`).

*   **Main `policy` Function Logic:**
    1.  Call `find_win_or_block_move` for `player_id=1`. If a move is returned, that's my winning move.
    2.  If no winning move, call `find_win_or_block_move` for `player_id=-1`. If a move is returned, that's the opponent's potential win, so I must block it.
    3.  If neither of the above, check if the center `board[1][1]` is empty (`0`). If yes, return `(1, 1)`.
    4.  If the center is taken, check the corners `(0,0)`, `(0,2)`, `(2,0)`, `(2,2)`. Return the first empty one found.
    5.  If all corners are taken, check the side positions `(0,1)`, `(1,0)`, `(1,2)`, `(2,1)`. Return the first empty one found.
    6.  As a failsafe, if all else fails (e.g., board is full), return `(-1, -1)` to indicate no move is possible.

import numpy as np

def find_win_or_block_move(board: list[list[int]], player_id: int) -> tuple[int, int] | None:
    """
    Checks if the given player can win or needs to block in the next move.
    This involves finding a line (row, column, or diagonal) that contains
    two of the player's pieces and one empty cell.

    Args:
        board: The 3x3 Tic Tac Toe board.
        player_id: The ID of the player to check for (1 for me, -1 for opponent).

    Returns:
        A tuple (row, col) of the winning/blocking move, or None if not possible.
    """
    lines_indices = []
    # Rows
    for r in range(3):
        lines_indices.append([(r, 0), (r, 1), (r, 2)])
    # Columns
    for c in range(3):
        lines_indices.append([(0, c), (1, c), (2, c)])
    # Diagonals
    lines_indices.append([(0, 0), (1, 1), (2, 2)]) # Top-left to bottom-right
    lines_indices.append([(0, 2), (1, 1), (2, 0)]) # Top-right to bottom-left

    for line in lines_indices:
        player_pieces = 0
        empty_cells = 0
        empty_pos = None

        for r, c in line:
            if board[r][c] == player_id:
                player_pieces += 1
            elif board[r][c] == 0:
                empty_cells += 1
                empty_pos = (r, c)

        # If the player has exactly two pieces and there's one empty spot in the line,
        # this is a potential winning or blocking move.
        if player_pieces == 2 and empty_cells == 1:
            return empty_pos # Return the coordinates of the empty cell

    return None # No such winning or blocking move found in any line

def policy(board: list[list[int]]) -> tuple[int, int]:
    """
    Determines the next best move for the current player in a 3x3 Tic Tac Toe game.

    The strategy follows a priority order:
    1.  Win: If a move exists that wins the game for the current player, take it.
    2.  Block: If the opponent can win in their next move, block that move.
    3.  Center: Take the center cell if it's empty.
    4.  Corner: Take any empty corner cell.
    5.  Side: Take any empty side cell (edge).

    Args:
        board: A 3x3 list of lists representing the Tic Tac Toe board.
               Values are: 0 (empty), 1 (your piece), -1 (opponent's piece).

    Returns:
        A tuple of two integers (row, col) indicating the chosen move's coordinates.
        Coordinates are 0-indexed, ranging from 0 to 2.
        Returns (-1, -1) if no moves are possible (game is full or an error state).
    """

    # Priority 1: Check if player 1 (you) can win in the next move.
    my_win_move = find_win_or_block_move(board, 1)
    if my_win_move:
        return my_win_move

    # Priority 2: Check if the opponent (-1) can win, and block them.
    opponent_win_move = find_win_or_block_move(board, -1)
    if opponent_win_move:
        return opponent_win_move

    # Priority 3: If the center cell (1,1) is empty, take it.
    # This is generally the strategically strongest move.
    if board[1][1] == 0:
        return (1, 1)

    # Priority 4: If no immediate win or block, and center is taken, take an empty corner.
    # The order of checking corners doesn't critically affect the optimal strategy,
    # but defining an order ensures deterministic play.
    corners = [(0, 0), (0, 2), (2, 0), (2, 2)]
    for r, c in corners:
        if board[r][c] == 0:
            return (r, c)

    # Priority 5: If no win, block, center, or corner move is available, take an empty side cell.
    sides = [(0, 1), (1, 0), (1, 2), (2, 1)]
    for r, c in sides:
        if board[r][c] == 0:
            return (r, c)

    # Fallback: If the board is full and no moves are possible, return an indicator.
    # This case should ideally only be reached if the game is already over.
    # If this were to be reached with empty cells, it would indicate a logic error.
    # However, the previous loops should cover all empty cells if they exist.
    return (-1, -1) # Signal no valid move found.
