def policy(board: list[list[int]]) -> tuple[int, int]:
    # Define all winning lines
    lines = [
        [(0, 0), (0, 1), (0, 2)],  # row 0
        [(1, 0), (1, 1), (1, 2)],  # row 1
        [(2, 0), (2, 1), (2, 2)],  # row 2
        [(0, 0), (1, 0), (2, 0)],  # col 0
        [(0, 1), (1, 1), (2, 1)],  # col 1
        [(0, 2), (1, 2), (2, 2)],  # col 2
        [(0, 0), (1, 1), (2, 2)],  # diagonal
        [(0, 2), (1, 1), (2, 0)]   # other diagonal
    ]
    
    # Check if I can win immediately
    for i in range(3):
        for j in range(3):
            if board[i][j] == 0:
                # Create a temporary board with my move placed
                temp_board = [row[:] for row in board]
                temp_board[i][j] = 1
                # Check if I have a win after this move
                for line in lines:
                    if all(temp_board[x][y] == 1 for x, y in line):
                        return (i, j)
    
    # Check if I need to block the opponent from winning
    for line in lines:
        count_opponent = 0
        empty_cell = None
        for (i, j) in line:
            if board[i][j] == -1:
                count_opponent += 1
            elif board[i][j] == 0:
                empty_cell = (i, j)
        if count_opponent == 2 and empty_cell is not None:
            return empty_cell
    
    # If no immediate win or block, choose a move based on position priority
    # Priority order: center, then corners, then edges
    if board[1][1] == 0:
        return (1, 1)
    
    corners = [(0, 0), (0, 2), (2, 0), (2, 2)]
    for i, j in corners:
        if board[i][j] == 0:
            return (i, j)
    
    edges = [(0, 1), (1, 0), (1, 2), (2, 1)]
    for i, j in edges:
        if board[i][j] == 0:
            return (i, j)
    
    # If no move found (should not happen if board has empty cells), return default
    return (0, 0)

This policy function for Tic Tac Toe implements a simple but effective strategy:
1. **Immediate Win Check**: For each empty cell, it simulates placing its mark and checks if it wins. If so, it returns that move.
2. **Blocking Opponent**: If no immediate win, it checks for any winning line for the opponent with two marks and one empty cell. If found, it places a mark there to block.
3. **Position-Based Heuristic**: If neither winning nor blocking is possible, it selects a move based on priority: center first, then corners, then edges. This heuristic ensures good general play and often creates winning opportunities.

The approach is efficient for the 3x3 board, running well within the 1-second limit. It covers the key aspects of Tic Tac Toe strategy without overcomplicating the code.
