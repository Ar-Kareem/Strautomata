### Approach

2. **Block Opponent's Winning Move**: For each empty cell, simulate placing the opponent's symbol (-1) and check if this results in a win for the opponent. If so, block by returning that cell.
3. **Prioritize Center**: If the center (1,1) is empty, take it as it offers the most strategic advantage.
4. **Corners**: If the center is not available, check for empty corners and take one if available.
5. **Edges**: If neither the center nor corners are available, take an edge position.

This approach ensures that the player either wins immediately, blocks the opponent's win, or takes the most strategic positions available.

def policy(board: list[list[int]]) -> tuple[int, int]:
    def is_win(b, player):
        # Check rows
        for row in b:
            if all(cell == player for cell in row):
                return True
        # Check columns
        for col in range(3):
            if all(b[row][col] == player for row in range(3)):
                return True
        # Check diagonals
        if all(b[i][i] == player for i in range(3)):
            return True
        if all(b[i][2 - i] == player for i in range(3)):
            return True
        return False

    # Find all empty cells
    empty = [(i, j) for i in range(3) for j in range(3) if board[i][j] == 0]

    # Check for winning move
    for i, j in empty:
        board[i][j] = 1
        if is_win(board, 1):
            board[i][j] = 0
            return (i, j)
        board[i][j] = 0  # Undo the move

    # Check for blocking move
    for i, j in empty:
        board[i][j] = -1
        if is_win(board, -1):
            board[i][j] = 0
            return (i, j)
        board[i][j] = 0  # Undo the move

    # Prefer center
    if board[1][1] == 0:
        return (1, 1)

    # Check corners
    corners = [(0, 0), (0, 2), (2, 0), (2, 2)]
    for corner in corners:
        if board[corner[0]][corner[1]] == 0:
            return corner

    # Check edges
    edges = [(0, 1), (1, 0), (1, 2), (2, 1)]
    for edge in edges:
        if board[edge[0]][edge[1]] == 0:
            return edge

    # Fallback (should not reach here as there's at least one empty cell)
    return empty[0]
