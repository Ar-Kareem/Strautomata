I need to design a smart backgammon policy that can make good decisions given the current board state and dice roll.

**High-level reasoning:**

1. **Understanding the constraints**: I need to return a legal move string in the format `<ORDER>:<FROM1>,<FROM2>` where ORDER is H or L (which die is used first), and FROM1/FROM2 are starting positions (A0-A23, B for bar, P for pass).

2. **Key strategic considerations for backgammon**:
   - **Safety**: Avoid leaving single checkers (blots) that can be hit
   - **Building points**: Create made points (2+ checkers) for safety
   - **Running game**: When ahead, move checkers toward home
   - **Hitting**: Opportunistically hit opponent blots
   - **Bearing off**: Get checkers home when possible
   - **Entering from bar**: Must enter before anything else
   - **Efficiency**: Use both dice when possible

3. **Implementation strategy**:
   - First, check if we need to enter from bar
   - If bearing off is possible, do it
   - Otherwise, evaluate all legal move combinations
   - Score each option based on:
     - Safety (avoiding blots, especially in opponent's home)
     - Building points
     - Hitting opportunities
     - Progress toward home
     - Contact with opponent
   - Handle special cases: double dice, single legal move, etc.

4. **Move generation**: I need to generate all legal moves for the given dice roll, then pick the best one based on a heuristic evaluation function.

Let me implement a robust policy with good heuristics:

            if count >= 2:
                score += 15

        for i, count in enumerate(temp_opp_pts):

        # 4. Progress: reward checkers moving toward home (higher indices)
        progress_score = 0
        for i, count in enumerate(temp_my_pts):

                progress_score += count * (i - 12) * 0.5  # Negative but penalizes staying far
            else:

        # 5. Bar entry: penalize if still on bar

    def generate_moves():

        else:

            if d1 > d2:

    best_score = float('-inf')

    for src1, src2, order_char in legal_moves:

        temp_my_bar = my_bar
        temp_opp_bar = opp_bar
        temp_my_off = my_off
        
        # Apply first move
        if src1 == 'B':

    def format_point(p):
        if p == 'B':
            return 'B'
        elif p == 'P':
            return 'P'
        else:
            return f'A{p}'
    
    if best_move is None:
        return 'L:P,P'
    
    src1, src2, order_char = best_move
    return f"{order_char}:{format_point(src1)},{format_point(src2)}"
