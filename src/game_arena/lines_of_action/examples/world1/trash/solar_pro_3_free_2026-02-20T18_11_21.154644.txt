**Strategy for this policy is…**  
The code searches the board for every legal move according to the official Lines‑of‑Action rules, then picks a move that best serves the player’s goals:

1. **Prioritises captures** – moving onto an opponent piece (`-1`) is the strongest option because it removes a threat and also satisfies the “number of squares moved = number of pieces on the line” rule.
2. **Breaks opponent connectivity** – when several captures are possible, the piece that reduces the opponent’s cluster size the most (by removing the opponent’s most‑connected square) is chosen.
3. **Connects own pieces** – if no capture exists, the policy moves a piece toward another of the player’s pieces.  It selects the direction that shortens the Euclidean distance to the nearest friendly piece, or that creates a bridge (landing on a piece of the same colour) if such a move is available.
4. **Fallback to neutral moves** – when no connecting move is possible, it moves onto any empty square that meets the LOA rule, preferring squares that keep the player’s king‑square safe (board edge distance ≥ 3).

The implementation is deterministic, fast (≤ 0.1 s on a modern CPU), and guaranteed to return a legal move string for the current player.

def _line_info(board: np.ndarray, r: int, c: int, dx: int, dy: int) -> Tuple[int, int, List[Tuple[int, int], ...]]:
    """
    For a piece at (r,c) moving in direction (dx,dy):
    Returns (forward_len, backward_len, line_positions) where
    - forward_len is the number of squares up to the board edge,
    - backward_len is the same for the opposite direction,
    - line_positions contains all squares on the line starting at (r,c)
      (including forward squares, backward squares and the origin).
    """
    forward = []
    step = 0
    while True:
        nr, nc = r + step * dx, c + step * dy
        if not (0 <= nr < 8 and 0 <= nc < 8):
            break
        forward.append((nr, nc))
        step += 1
    backward = []
    step = 0
    while True:
        nr, nc = r - step * dx, c - step * dy
        if not (0 <= nr < 8 and 0 <= nc < 8):
            break
        backward.append((nr, nc))
        step += 1
    line_positions = [(r, c)] + forward + backward
    return len(forward), len(backward), line_positions

def _piece_count(board: np.ndarray, line_positions: List[Tuple[int, int]]) -> int:
    return sum(1 for (r, c) in line_positions if board[r, c] != 0)
