To solve this problem, we need to create a Python function that returns a legal move for the game Pentago. The move must involve placing a marble on an empty cell and then rotating one of the four quadrants of the board either clockwise or counter-clockwise.

### Approach
The approach involves the following steps:
1. **Identify Empty Cells**: Iterate through the 6x6 board to find any empty cell where both the current player and the opponent have no marbles (i.e., both values are 0).
2. **Select a Move**: Once an empty cell is found, select the first such cell in row-major order to place the player's marble.
3. **Choose Rotation Parameters**: Default to rotating quadrant 0 clockwise ('R').

This approach ensures that a valid move is always returned, even if it is not the optimal move. The code checks each cell in row-major order, making it straightforward and efficient.

### Solution Code
```python
def policy(you, opponent) -> str:
    # Iterate through each cell in row-major order to find an empty cell
    for row in range(6):
        for col in range(6):
            if you[row][col] == 0 and opponent[row][col] == 0:
                # Place the marble at the first found empty cell
                # Rotate quadrant 0 clockwise as default
                return f"{row + 1},{col + 1},0,R"
    # According to problem statement, this line is unreachable
    # but required by function syntax. Handle as needed.
    return "0,0,0,R"
```

### Explanation
1. **Empty Cell Identification**: The code iterates through each cell in the 6x6 grid, starting from the top-left corner (row 0, column 0) and moving rightwards and downwards. This ensures that the first empty cell encountered is selected.
2. **Move String Formation**: The selected cell's row and column are converted to 1-indexed format as required by the game rules. The default rotation chosen is quadrant 0 (top-left) rotated clockwise ('R').

This method guarantees a valid move by always selecting the first available empty cell and applying a standard rotation, ensuring compliance with the game's legal move requirements. The simplicity of the approach ensures it runs efficiently within the given time constraints.
