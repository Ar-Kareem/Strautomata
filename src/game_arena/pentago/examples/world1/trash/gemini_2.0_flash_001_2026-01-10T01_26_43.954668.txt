Let's outline a simple strategy for the Pentago AI. Since the primary goal is to return a valid move within the time limit, a simple and reliable approach is to:

1.  **Find an empty cell:** Iterate through the board and select the first available empty cell.
2.  **Choose a quadrant and direction:**  Iterate through quadrants and directions.

This approach guarantees a legal move.

```python
def policy(you, opponent) -> str:
    """
    Chooses a move for the Pentago game.

    Args:
        you: A 6x6 array representing your marbles (1) and empty spaces (0).
        opponent: A 6x6 array representing the opponent's marbles (1) and empty spaces (0).

    Returns:
        A string representing the move in the format "row,col,quad,dir".
    """

    # Find an empty cell
    for row in range(6):
        for col in range(6):
            if you[row][col] == 0 and opponent[row][col] == 0:
                # Convert to 1-indexed
                row_1indexed = row + 1
                col_1indexed = col + 1

                # Iterate through quadrants and directions
                for quad in range(4):
                    for direction in ['L', 'R']:
                        return f"{row_1indexed},{col_1indexed},{quad},{direction}"

    # Should never reach here, as we assume there is always a legal move.
    return "1,1,0,L"  # Default, but should never be used.
```
