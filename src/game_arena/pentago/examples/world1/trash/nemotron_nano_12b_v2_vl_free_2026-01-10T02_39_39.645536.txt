The strategy is to always place a marble in the first available empty cell (row-wise from top-left) and perform a fixed rotation of quadrant 0 in the clockwise direction. This ensures a valid move without considering the board state, meeting the minimum requirements for correctness.

```python
def policy(you, opponent) -> str:
    for r in range(6):
        for c in range(6):
            if you[r][c] == 0 and opponent[r][c] == 0:
                # Convert to 1-based and choose quadrant 0, direction 'R'
                return f"{r+1},{c+1},0,R"
    return "0,0,0,R"  # Fallback (should never be reached)
```
