Let's analyze the requirements, especially the emphasis on legality and time limit. A simple and reliable approach is to iterate through possible moves and return the first legal move found. We prioritize simplicity over strategic sophistication to guarantee legality and stay within the time constraint.

Here's the plan:

1.  Iterate through all possible cell placements (row 1..6, col 1..6).
2.  For each placement, check if the cell is empty in both 'you' and 'opponent' arrays.
3.  If the cell is empty, iterate through all possible quadrants (0..3) and directions ('L', 'R').
4.  Construct the move string and immediately return it.

This will guarantee a legal move is returned since the problem statement ensures at least one legal move exists. This also ensures that the move is generated efficiently and within the time limit.

```python
import numpy as np

def policy(you, opponent) -> str:
    """
    Chooses a legal move for the Pentago game.

    Args:
        you: A 6x6 array representing your marbles.
        opponent: A 6x6 array representing the opponent's marbles.

    Returns:
        A legal move string in the format "row,col,quad,dir".
    """

    you = np.array(you)
    opponent = np.array(opponent)

    for row in range(6):
        for col in range(6):
            if you[row, col] == 0 and opponent[row, col] == 0:
                for quad in range(4):
                    for direction in ['L', 'R']:
                        return f"{row + 1},{col + 1},{quad},{direction}"
```
