To solve this problem, we need to create a function that selects a legal move for a player in the game of Pentago. The function must return a valid move that places a marble in an empty cell and rotates a quadrant in either direction to maximize the player's chances of winning or at least ensuring a legal move.

### Approach
1. **Identify Empty Cells**: The first step is to find all empty cells on the board where the player can place their marble. This is done by iterating through each cell and checking if it is empty for both the player and the opponent.
2. **Random Move Selection**: Once an empty cell is found, a valid move is constructed by placing the marble in that cell and then selecting a random quadrant to rotate and a random direction (left or right) for the rotation. This ensures the move is legal and adheres to the problem constraints.

### Solution Code
```python
import numpy as np
import random

def policy(you, opponent) -> str:
    for row in range(6):
        for col in range(6):
            if you[row][col] == 0 and opponent[row][col] == 0:
                # Randomly select a quadrant and rotation direction
                quad = random.randint(0, 3)
                dir = 'L' if random.random() < 0.5 else 'R'
                return f"{row+1},{col+1},{quad},{dir}"
    return ""  # This line is theoretically unreachable as per problem constraints
```

### Explanation
- **Finding Empty Cells**: The function iterates through each cell in the 6x6 grid, checking if the cell is empty (i.e., both the player's and opponent's matrices have a 0 at that cell).
- **Random Quadrant and Direction Selection**: Once an empty cell is found, the function randomly selects a quadrant (0 to 3) and a direction (L or R) to rotate that quadrant. This randomness ensures a legal move is chosen efficiently within the problem constraints.

This approach ensures that the function always returns a valid move by leveraging a simple heuristic to find the first available empty cell and then randomly selecting a quadrant and rotation direction. This strategy ensures legality and provides a straightforward solution within the given constraints.
