To solve this problem, we need to generate a legal move for the game Pentago. The move consists of placing a marble on an empty cell followed by rotating a quadrant in either direction. The solution must ensure that the move is always legal and efficient.

### Approach
1. **Find an Empty Cell**: Iterate through the 6x6 board to find the first empty cell where the player can place their marble. This ensures the placement part of the move is valid.
2. **Determine Quadrant**: Calculate the quadrant of the empty cell where the marble will be placed. The board is divided into four quadrants, and the quadrant of a cell can be determined based on its row and column indices.
3. **Choose Rotation Direction**: Select a rotation direction (either 'L' for anticlockwise or 'R' for clockwise) for the chosen quadrant. For simplicity, we choose 'R' (clockwise) consistently.

### Solution Code
```python
def policy(you, opponent):
    # Iterate through each cell to find the first empty spot
    for r in range(6):
        for c in range(6):
            if you[r][c] == 0 and opponent[r][c] == 0:
                # Convert to 1-based indexing for row and column
                row = r + 1
                col = c + 1
                # Determine the quadrant of the chosen cell
                quad = (r // 3) * 2 + (c // 3)
                # Choose rotation direction as 'R' (could be 'L' as well)
                direction = 'R'
                return f"{row},{col},{quad},{direction}"
```

### Explanation
1. **Finding an Empty Cell**: The code iterates through each cell in row-major order (top-left to bottom-right) to find the first empty cell where the player can place their marble.
2. **Quadrant Calculation**: The quadrant of the chosen cell is determined by its row and column indices. Each quadrant is 3x3, so the quadrant index is calculated using integer division of the row and column by 3.
3. **Rotation Choice**: The code selects a direction ('L' or 'R') for rotating the quadrant. Here, we consistently choose 'R' (clockwise) for simplicity, but any valid direction would work.

This approach ensures that the generated move is always legal by placing a marble in an empty cell and rotating a valid quadrant, adhering to the game's rules efficiently.
