Let's start by outlining a basic strategy. Since the goal is to return a legal move string, let's implement a simple, valid deterministic policy.

1.  **Placement:** Find the first available empty cell (scan row by row, column by column).
2.  **Rotation:** Always rotate quadrant 0 to the left (`L`).

This approach guarantees a legal move. We can refine the strategy later with heuristics and game tree search.

```python
def policy(you, opponent) -> str:
    """Chooses a move for Pentago."""

    # 1. Placement: Find the first available empty cell.
    for r in range(6):
        for c in range(6):
            if you[r][c] == 0 and opponent[r][c] == 0:
                row = r + 1  # Convert to 1-indexed
                col = c + 1  # Convert to 1-indexed
                break
        else:
            continue  # Only executed if the inner loop did NOT break
        break  # Exit outer loop if placement available
    # 2. Rotation: Always rotate quadrant 0 to the left.
    quad = 0
    direction = "L"

    # Construct the move string.
    move = f"{row},{col},{quad},{direction}"
    return move
```
