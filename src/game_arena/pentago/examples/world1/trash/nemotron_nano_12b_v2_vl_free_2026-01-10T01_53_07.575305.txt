To address the challenge of implementing a move-selection policy for the game of Pentago, we need to define a function `policy(you, opponent)` that always returns a legal move. The function must choose a valid empty cell on the board and a valid quadrant and rotation direction (either clockwise or counter-clockwise) to place a marble and rotate the board.

---

### Strategy Overview

1. **Identify Empty Cells**: The function must first identify all empty cells on the board where the player can legally place a marble.
2. **Evaluate for Immediate Win**: For each empty cell and each possible quadrant and rotation direction, simulate the move. Specifically:
   - Place the marble in the chosen cell.
   - Rotate the specified quadrant in the specified direction.
   - If this move results in a 5-in-a-row for the current player, return that move immediately.
3. **Fall Back to Random Move**: If no winning move exists, return the first valid move found in row-major order (top-left to bottom-right), choosing quadrant `0` and direction `'R'` as default.

The function must always return a valid move, even if no immediate win is possible.

---

### Implementation Details

#### 1. `has_win(board)` Function

This function checks if the current player has a 5-in-a-row in any direction. It iterates over all possible starting positions and directions to detect a win condition.

#### 2. `rotate_quadrant(you_board, opponent_board, quad, direction)` Function

This function rotates a specific quadrant of the board either clockwise or counter-clockwise. It extracts the quadrant, performs the rotation using matrix transposition and row reversal, and then updates the marbles in the board accordingly.

    for r in range(6):
        for c in range(2):
            if all(board[r][c + i] == 1 for i in range(5)):
                return True
