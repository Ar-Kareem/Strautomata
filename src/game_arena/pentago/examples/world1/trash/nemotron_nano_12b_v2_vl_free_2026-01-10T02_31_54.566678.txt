To solve this problem, we need to create a move-selection policy for the game Pentago. The goal is to determine the optimal move for the player by checking if placing a marble and rotating a quadrant can result in a win. If such a move is found, it is returned immediately. If no winning move is found, the policy falls back to a simple heuristic approach.

### Approach
1. **Identify Empty Cells**: First, identify all empty cells on the board where the player can place a marble.
2. **Check for Winning Moves**: For each empty cell, simulate placing a marble and rotating each of the four quadrants in both possible directions (clockwise and anticlockwise). Check if any of these moves result in a 5-in-a-row for the player.
3. **Winning Condition Check**: After placing the marble and rotating a quadrant, check if the player has a 5-in-a-row either horizontally, vertically, or diagonally.
4. **Fallback Strategy**: If no winning move is found, place the marble in the first available empty cell and rotate the associated quadrant (determined by the cell's position) clockwise.

### Solution Code
```python
def policy(you, opponent):
    # Helper function to rotate a quadrant and check for win
    quad_coords = [(0, 0), (0, 3), (3, 0), (3, 3)]
    
    def rotate_quadrant(y_mat, o_mat, quad, dir_):
        START_R, START_C = quad_coords[quad]
        marbles = []
        # Collect marbles in the quadrant
        for r in range(START_R, START_R + 3):
            for c in range(START_C, START_C + 3):
                if y_mat[r][c] == 1:
                    marbles.append((r, c, 'Y'))
                elif o_mat[r][c] == 1:
                    marbles.append((r, c, 'O'))
        # Clear the quadrant
        for r in range(START_R, START_R + 3):
            for c in range(START_C, START_C + 3):
                y_mat[r][c] = 0
                o_mat[r][c] = 0
        # Rotate marbles
        for (old_r, old_c, owner) in marbles:
            i = old_r - START_R
            j = old_c - START_C
            if dir_ == 'L':
                new_i, new_j = 2 - j, i
            else:
                new_i, new_j = j, 2 - i
            new_r = START_R + new_i
            new_c = START_C + new_j
            if owner == 'Y':
                y_mat[new_r][new_c] = 1
            else:
                o_mat[new_r][new_c] = 1
        return y_mat, o_mat
    
    def has_win(board):
        # Check horizontal
        for r in range(6):
            for c in range(2):
                if board[r][c] == 1 and all(board[r][c + i] == 1 for i in range(5)):
                    return True
        # Check vertical
        for c in range(6):
            for r in range(2):
                if board[r][c] == 1 and all(board[r + i][c] == 1 for i in range(5)):
                    return True
        # Check diagonal down
        for r in range(2):
            for c in range(2):
                if all(board[r + i][c + i] == 1 for i in range(5)):
                    return True
        # Check diagonal up
        for r in range(2):
            for c in range(2, 6):
                if all(board[r + i][c - i] == 1 for i in range(5)):
                    return True
        return False
    
    # Find all empty cells
    empty = []
    for r in range(6):
        for c in range(6):
            if you[r][c] == 0 and opponent[r][c] == 0:
                empty.append((r, c))
    
    # Check for winning moves
    for (r, c) in empty:
        sim_y = [row.copy() for row in you]
        sim_o = [row.copy() for row in opponent]
        sim_y[r][c] = 1
        for quad in range(4):
            for dir_ in ['L', 'R']:
                rotated_y, rotated_o = rotate_quadrant(sim_y, sim_o, quad, dir_)
                if has_win(rotated_y):
                    return f"{r+1},{c+1},{quad},{dir_}"
    
    # Fallback: place in first empty cell and rotate its quadrant clockwise
    r, c = empty[0]
    quad = (r // 3) * 2 + (c // 3)
    return f"{r+1},{c+1},{quad},R"
```

### Explanation
1. **Empty Cells Identification**: The code first identifies all empty cells on the board where a marble can be placed.
2. **Winning Move Check**: For each empty cell, the code simulates placing a marble and then rotating each of the four quadrants in both directions. After each rotation, it checks if the player has a 5-in-a-row. If a winning move is found, it is returned immediately.
3. **Quadrant Rotation**: The rotation function handles the transformation of marbles within the specified quadrant, either clockwise or anticlockwise, and updates the board accordingly.
4. **Winning Condition Check**: The `has_win` function checks all possible horizontal, vertical, and diagonal lines to detect a 5-in-a-row.
5. **Fallback Strategy**: If no winning move is found, the code places the marble in the first empty cell and rotates the associated quadrant clockwise as a default strategy.

This approach ensures that the policy function efficiently checks for winning moves and falls back to a simple strategy when none are found, adhering to the constraints and requirements of the problem.
