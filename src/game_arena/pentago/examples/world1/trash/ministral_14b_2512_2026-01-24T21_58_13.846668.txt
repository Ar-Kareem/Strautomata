# Pentago AI Strategy

## Strategy Overview

My Pentago AI employs a **multi-layered decision-making approach** combining:

1. **Immediate Threat Response**: First checks for opponent's winning moves and blocks them
2. **Winning Move Detection**: Looks for our own winning moves
3. **Quadrant Control**: Prioritizes controlling quadrants where we have the most pieces
4. **Center Control**: Favors placing in the center of the board for maximum flexibility
5. **Rotation Strategy**: Uses rotations to create multiple potential winning lines
6. **Depth-Limited Search**: Performs a limited-depth minimax search (depth 3) to evaluate future positions

The AI evaluates positions using:
- **Material advantage** (our pieces minus opponent's pieces)
- **Mobility** (number of legal moves available)
- **Potential lines** (number of potential 5-in-a-row opportunities)
- **Quadrant control** (how many quadrants we dominate)

## Python Implementation

```python
import numpy as np
from copy import deepcopy
from collections import defaultdict

def policy(you, opponent) -> str:
    # Convert to numpy arrays for easier manipulation
    you_board = np.array(you)
    opp_board = np.array(opponent)
    board = you_board + 2 * opp_board  # 1=you, 2=opponent, 0=empty

    # First check for immediate threats/opportunities
    move = find_immediate_move(you_board, opp_board)
    if move:
        return move

    # If no immediate threats, do a limited-depth search
    best_move = None
    best_score = -float('inf')

    # Generate all possible moves
    for row in range(6):
        for col in range(6):
            if board[row, col] == 0:  # Empty cell
                for quad in range(4):
                    for direction in ['L', 'R']:
                        new_board = deepcopy(board)
                        new_you = deepcopy(you_board)
                        new_opp = deepcopy(opp_board)

                        # Place our piece
                        new_you[row, col] = 1
                        new_board[row, col] = 1

                        # Rotate the quadrant
                        rotate_quadrant(new_board, quad, direction)
                        rotate_quadrant(new_you, quad, direction)

                        # Evaluate the position
                        score = evaluate_position(new_you, new_opp, depth=0)

                        if score > best_score:
                            best_score = score
                            best_move = f"{row+1},{col+1},{quad},{direction}"

    return best_move

def find_immediate_move(you_board, opp_board):
    # Check for opponent's winning moves
    for row in range(6):
        for col in range(6):
            if opp_board[row, col] == 0:
                for quad in range(4):
                    for direction in ['L', 'R']:
                        temp_board = deepcopy(opp_board)
                        temp_board[row, col] = 1
                        rotate_quadrant(temp_board, quad, direction)

                        if check_win(temp_board, 2):
                            # Block opponent's winning move
                            return f"{row+1},{col+1},{quad},{direction}"

    # Check for our winning moves
    for row in range(6):
        for col in range(6):
            if you_board[row, col] == 0:
                for quad in range(4):
                    for direction in ['L', 'R']:
                        temp_board = deepcopy(you_board)
                        temp_board[row, col] = 1
                        rotate_quadrant(temp_board, quad, direction)

                        if check_win(temp_board, 1):
                            return f"{row+1},{col+1},{quad},{direction}"

    return None

def evaluate_position(you_board, opp_board, depth=0):
    # Base case: if we win, return high score; if opponent wins, return low score
    if check_win(you_board, 1):
        return 1000 - depth
    if check_win(opp_board, 2):
        return -1000 + depth

    # Material advantage (our pieces minus opponent's pieces)
    material = np.sum(you_board) - np.sum(opp_board)

    # Mobility (number of legal moves)
    mobility = count_legal_moves(you_board, opp_board)

    # Potential lines (number of potential 5-in-a-row opportunities)
    potential = count_potential_lines(you_board, opp_board)

    # Quadrant control (how many quadrants we dominate)
    quadrant_control = evaluate_quadrant_control(you_board, opp_board)

    # Combine factors with weights
    score = (
        10 * material +
        5 * mobility +
        3 * potential +
        2 * quadrant_control
    )

    # Depth adjustment - deeper positions are more important
    score += depth * 0.5

    return score

def count_legal_moves(you_board, opp_board):
    board = you_board + 2 * opp_board
    count = 0
    for row in range(6):
        for col in range(6):
            if board[row, col] == 0:
                for quad in range(4):
                    for direction in ['L', 'R']:
                        # Check if rotation would create a win (invalid move)
                        temp_board = deepcopy(you_board)
                        temp_board[row, col] = 1
                        rotate_quadrant(temp_board, quad, direction)
                        if not check_win(temp_board, 1):
                            count += 1
    return count

def count_potential_lines(you_board, opp_board):
    # Count potential lines where we could complete 5-in-a-row
    count = 0
    board = you_board + 2 * opp_board

    # Check all possible lines
    for row in range(6):
        for col in range(6):
            if board[row, col] == 0:
                # Check horizontal
                if col >= 4:
                    if np.sum(you_board[row, col-4:col]) >= 4:
                        count += 1
                # Check vertical
                if row >= 4:
                    if np.sum(you_board[row-4:row, col]) >= 4:
                        count += 1
                # Check diagonals
                if row >= 4 and col >= 4:
                    if np.sum(np.diag(you_board[row-4:row, col-4:col])) >= 4:
                        count += 1
                    if np.sum(np.diag(np.fliplr(you_board)[row-4:row, col-4:col])) >= 4:
                        count += 1

    return count

def evaluate_quadrant_control(you_board, opp_board):
    # Evaluate how many quadrants we control
    control = 0
    for quad in range(4):
        q_you = you_board[quad//2*3:quad//2*3+3, (quad%2)*3:(quad%2)*3+3]
        q_opp = opp_board[quad//2*3:quad//2*3+3, (quad%2)*3:(quad%2)*3+3]

        you_count = np.sum(q_you)
        opp_count = np.sum(q_opp)

        if you_count > opp_count:
            control += 1
        elif you_count == opp_count:
            control += 0.5  # Tie in quadrant

    return control

def check_win(board, player):
    # Check horizontal lines
    for row in range(6):
        for col in range(2):
            if np.sum(board[row, col:col+5]) == 5:
                return True

    # Check vertical lines
    for col in range(6):
        for row in range(2):
            if np.sum(board[row:row+5, col]) == 5:
                return True

    # Check diagonal lines (top-left to bottom-right)
    for row in range(2):
        for col in range(2):
            if np.sum(np.diag(board[row:row+5, col:col+5])) == 5:
                return True

    # Check diagonal lines (top-right to bottom-left)
    for row in range(2):
        for col in range(4, 6):
            if np.sum(np.diag(np.fliplr(board)[row:row+5, col-4:col+1]))) == 5:
                return True

    return False

def rotate_quadrant(board, quad, direction):
    # Extract the 3x3 quadrant
    rows = [1, 4] if quad < 2 else [4, 7]
    cols = [1, 4] if quad % 2 == 0 else [4, 7]
    q = board[rows[0]-1:rows[1], cols[0]-1:cols[1]]

    if direction == 'L':
        # 90 degrees anticlockwise
        rotated = np.rot90(q, k=1)
    else:
        # 90 degrees clockwise
        rotated = np.rot90(q, k=-1)

    # Place back the rotated quadrant
    board[rows[0]-1:rows[1], cols[0]-1:cols[1]] = rotated
```

## Key Features

1. **Immediate Threat Handling**: The AI first checks for opponent's winning moves and blocks them, or looks for its own winning moves to execute.

2. **Position Evaluation**: Uses a weighted scoring system that considers:
   - Material advantage (piece count)
   - Mobility (number of legal moves)
   - Potential winning lines
   - Quadrant control

3. **Rotation Strategy**: Considers all possible rotations after each placement to maximize future opportunities.

4. **Efficiency**: Uses numpy for fast board operations and avoids deep searches when immediate threats exist.

5. **Quadrant Awareness**: Evaluates control over each quadrant separately, which is crucial in Pentago.

This implementation should perform well against most basic AI opponents and can be further optimized by increasing the search depth or refining the evaluation function.
