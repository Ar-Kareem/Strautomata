To develop an effective AI for the game of **Pentago**, we must implement a policy that selects a legal move: placing a marble on an empty cell and then rotating a quadrant. The key challenge lies in evaluating potential moves that could lead to a win or provide a strong strategic advantage.

---

### ✅ Strategy Overview

1. **Immediate Win Detection**:  
   First, iterate over all empty cells and all possible rotations to see if placing a marble and rotating any quadrant results in a win. If such a move exists, return it immediately.

2. **Heuristic Evaluation (if no immediate win)**:
   If no immediate win is found, we evaluate all possible moves based on a simple heuristic:
   - **Quadrant AI Marble Density**: Prioritize quadrants where the AI has more marbles.
   - **Select the best empty cell** in the best quadrant.
   - **Rotate the same quadrant clockwise** (a reasonable default direction).

   This prioritizes moving in quadrants where the AI already has a strong presence and then rotates to potentially align marbles into a winning configuration.

3. **Fallback to First Valid Move**:
   If no cell is found in the best quadrant, the first empty cell in row-major order is selected and quadrant 0 is rotated clockwise as a fallback.

---

### 🧠 Implementation Details

- **Board Representation**:
  - `you` and `opponent` are 6x6 numpy arrays where `1` represents a marble and `0` represents an empty cell.
  - The AI assumes it plays as the player with marbles marked as `1`.

- **Win Detection**:
  - The `has_line` function checks for a 5-in-a-row in any direction (horizontal, vertical, and both diagonals) using numpy's `all` and `diag` functions.

- **Quadrant Rotation**:
  - The quadrant is rotated using `np.rot90` with a rotation factor of `-1` (clockwise) or `1` (counterclockwise).
  - After rotation, the updated quadrant is applied to both the AI's and opponent's boards.

- **Quadrant Selection**:
  - The quadrant with the most AI marbles is selected to maximize the potential for forming a winning line after rotation.

- **Placement Selection**:
  - The first empty cell in the best quadrant is selected for placement.
  - If no such cell is found in the best quadrant, the first empty cell overall is chosen.

                return True

### 📌 Summary

This AI policy aims to:
- **Win immediately** if possible.
- **Prioritize strong quadrants** with the most AI marbles.
- **Conduct a reasonable rotation** to maximize future potential.
- **Ensure legality** of all moves, as required.

While this heuristic may not be optimal in all situations, it provides a solid baseline for early-stage development and is efficient enough to run within the time constraints.
