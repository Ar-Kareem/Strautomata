To solve this problem, we need to create a policy function for the game Pentago that always returns a valid move. The function must decide the best move by first checking for immediate winning opportunities, then blocking potential opponent moves, and if neither is possible, using a heuristic to choose the most strategic move.

### Approach
1. **Immediate Win Check**: The function first checks all possible empty cells to see if placing a marble in any of them followed by a rotation could immediately result in a win. This is done by simulating each possible move and rotation, then checking if the resulting move leads to a win.
2. **Blocking Opponent's Win**: If no immediate win is found, the function checks if the opponent has a potential winning move. If such a move is found, the function blocks it by placing the marble in the same cell.
3. **Heuristic Move**: If neither an immediate win nor a blocking move is found, the function uses a heuristic to choose the best cell. The heuristic prioritizes cells that have the most marbles in the same quadrant, aiming to control that quadrant through rotations.

### Explanation
1. **Check for Immediate Wins**: The function first checks all empty cells to see if placing a marble and rotating any quadrant would result in a win. This involves simulating each move and rotation and checking if it creates a 5-in-a-row.
2. **Blocking Opponent's Wins**: If no immediate win is found, the function checks if the opponent can win on their next move. If an opponent's move that would lead to a win is found, the function blocks that move by placing its own marble in the same cell.
3. **Heuristic Move**: If neither an immediate win nor blocking move is found, the function uses a heuristic to choose the most strategic cell. It prioritizes cells with the most marbles in the same quadrant to maximize control over that quadrant and enable future rotations for potential wins.
