To solve this problem, we need to create a move-selection policy for the game Pentago. The goal is to always return a legal move string that places a marble in an empty cell and rotates a quadrant. The solution involves finding an empty cell, determining the appropriate quadrant for rotation, and specifying the direction of rotation.

### Approach
1. **Find an Empty Cell**: The first step is to find the first available empty cell on the board. This is done by iterating through each cell in row-major order (top-left to bottom-right) and checking if both the player's and opponent's matrices indicate an empty cell (both values are 0).
2. **Determine Quadrant**: Once an empty cell is found, determine which of the four quadrants the cell belongs to. Quadrants are divided as follows:
   - Quadrant 0: Rows 1-3, Columns 1-3
   - Quadrant 1: Rows 1-3, Columns 4-6
   - Quadrant 2: Rows 4-6, Columns 1-3
   - Quadrant 3: Rows 4-6, Columns 4-6
3. **Choose Rotation Direction**: After determining the quadrant, choose a rotation direction. Here, we default to rotating anticlockwise ('L'), but any valid direction can be chosen.

This approach ensures that the move is always legal by first finding an empty cell and then selecting a valid rotation path.

### Solution Code
```python
def policy(you, opponent):
    # Iterate through each row and column to find the first empty cell
    for r in range(6):
        for c in range(6):
            if you[r][c] == 0 and opponent[r][c] == 0:
                # Determine the quadrant of the found cell
                if r < 3:
                    if c < 3:
                        quad = 0
                    else:
                        quad = 1
                else:
                    if c < 3:
                        quad = 2
                    else:
                        quad = 3
                # Return the move string with the first empty cell, its quadrant, and a default left rotation
                return f"{r+1},{c+1},{quad},L"
    # According to problem constraints, this return is unreachable
    return "0,0,0,L"  # Default fallback (should never be used)
```

### Explanation
1. **Finding an Empty Cell**: The nested loops iterate through each cell in the 6x6 board. The first cell where both `you[r][c]` and `opponent[r][c]` are 0 (indicating an empty cell) is selected for placement.
2. **Quadrant Determination**: The quadrant of the selected cell is determined based on its row and column indices. This ensures that the quadrant to be rotated is the one containing the newly placed marble.
3. **Rotation Direction**: The code defaults to rotating the quadrant anticlockwise ('L'), ensuring the move is legal. This choice is arbitrary but ensures the move is valid and strategically places the marble in a new position within the selected quadrant.

This approach ensures that the policy always returns a legal move, adhering to the problem constraints while efficiently selecting the first valid move encountered in row-major order. The rotation step is applied to the quadrant containing the placed marble, potentially enhancing the player's position by dispersing their marbles.
