My strategy uses a probability-density approach:

1. **Enumerate all possible placements** for each remaining ship (lengths 5, 4, 3, 3, 2), both horizontally and vertically.
2. **Filter invalid placements** — any placement overlapping a known miss (`-1`) is discarded.
3. **Weight placements by hit coverage**: A placement containing `k` known hits gets weight `HIT_BONUS^k` (I use 100). This naturally implements:
   - **Hunt mode**: When no hits exist, all placements have weight 1, so the score is just a count — giving higher scores to central cells and cells that fit many ship lengths.
   - **Target mode**: When hits exist, placements crossing hits dominate. Placements that align with *multiple* hits (extending a line) dominate even more strongly (100² vs 100), which correctly extends along confirmed ship lines.
4. **Accumulate scores** on unknown cells (`0`) across all placements, then fire at the max-score unknown cell.

This unifies hunt and target phases elegantly, and auto-prioritizes line extension when we've started hitting a ship.

<code>
def policy(board: list[list[int]]) -> tuple[int, int]:
    N = 10
    ships = [5, 4, 3, 3, 2]
    HIT_BONUS = 100

    scores = [[0.0] * N for _ in range(N)]

    for ship_len in ships:
        # Horizontal placements
        for r in range(N):
            for c in range(N - ship_len + 1):
                valid = True
                hits = 0
                for i in range(ship_len):
                    v = board[r][c + i]
                    if v == -1:
                        valid = False
                        break
                    if v == 1:
                        hits += 1
                if not valid:
                    continue
                weight = HIT_BONUS ** hits if hits > 0 else 1
                for i in range(ship_len):
                    if board[r][c + i] == 0:
                        scores[r][c + i] += weight

        # Vertical placements
        for c in range(N):
            for r in range(N - ship_len + 1):
                valid = True
                hits = 0
                for i in range(ship_len):
                    v = board[r + i][c]
                    if v == -1:
                        valid = False
                        break
                    if v == 1:
                        hits += 1
                if not valid:
                    continue
                weight = HIT_BONUS ** hits if hits > 0 else 1
                for i in range(ship_len):
                    if board[r + i][c] == 0:
                        scores[r + i][c] += weight

    best_score = -1.0
    best_move = None
    for r in range(N):
        for c in range(N):
            if board[r][c] == 0 and scores[r][c] > best_score:
                best_score = scores[r][c]
                best_move = (r, c)

    if best_move is None:
        # Fallback: any unknown cell
        for r in range(N):
            for c in range(N):
                if board[r][c] == 0:
                    return (r, c)
        return (0, 0)

    return best_move
