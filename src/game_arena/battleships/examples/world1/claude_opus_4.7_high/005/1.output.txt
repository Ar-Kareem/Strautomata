My strategy combines hunt and target modes using a probability density approach:

1. **Probability Map**: For every possible placement of each remaining ship (lengths 5, 4, 3, 3, 2), in both orientations, check if it's consistent with the observed board (doesn't cross any known miss). Add weight to each unknown cell it covers.

2. **Target Mode Integration**: When a placement covers existing hits, apply an exponential weight multiplier (50^hits). This strongly biases the search toward extending lines of hits — naturally completing and sinking partially-hit ships.

3. **Hunt Mode Emergence**: When there are no open hits, the probability density automatically creates a parity-like checkerboard bias (because the smallest ship is length 2, and longer ships create centered density), which is optimal for hunting.

4. **Fallback**: Always return a legal unknown cell.

This unified approach smoothly handles both exploring for new ships and aggressively finishing off damaged ones without needing explicit state machine logic.

<code>
def policy(board: list[list[int]]) -> tuple[int, int]:
    N = 10
    ships = [5, 4, 3, 3, 2]
    scores = [[0.0] * N for _ in range(N)]

    for L in ships:
        # Horizontal placements
        for r in range(N):
            for c in range(N - L + 1):
                valid = True
                hits = 0
                for i in range(L):
                    v = board[r][c + i]
                    if v == -1:
                        valid = False
                        break
                    if v == 1:
                        hits += 1
                if not valid:
                    continue
                weight = (50.0 ** hits) if hits > 0 else 1.0
                for i in range(L):
                    if board[r][c + i] == 0:
                        scores[r][c + i] += weight

        # Vertical placements
        for c in range(N):
            for r in range(N - L + 1):
                valid = True
                hits = 0
                for i in range(L):
                    v = board[r + i][c]
                    if v == -1:
                        valid = False
                        break
                    if v == 1:
                        hits += 1
                if not valid:
                    continue
                weight = (50.0 ** hits) if hits > 0 else 1.0
                for i in range(L):
                    if board[r + i][c] == 0:
                        scores[r + i][c] += weight

    best = None
    best_score = -1.0
    for r in range(N):
        for c in range(N):
            if board[r][c] == 0 and scores[r][c] > best_score:
                best_score = scores[r][c]
                best = (r, c)

    if best is not None and best_score > 0:
        return best

    # Fallback: any legal cell
    for r in range(N):
        for c in range(N):
            if board[r][c] == 0:
                return (r, c)
    return (0, 0)
