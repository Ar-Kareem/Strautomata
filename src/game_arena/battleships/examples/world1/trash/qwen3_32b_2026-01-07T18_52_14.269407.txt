To solve the problem, we need to develop a targeting policy for a Battleship-like game that efficiently identifies and sinks the opponent's ships on a 10x10 grid. The policy must analyze the current state of the board (with hits, misses, and unshot cells) and return the best cell to target next.

### Approach
The strategy combines two main phases: **Targeting** and **Hunting**.

1. **Targeting Phase**: 
   - When there are existing hits on the board, prioritize firing adjacent cells. If a hit is located at a cell, its neighboring cells (up, down, left, right) are likely part of the same ship. This helps in sinking the ship faster by focusing on adjacent cells.

2. **Hunting Phase**:
   - When there are no further adjacent cells to hits, calculate the probability of each unshot cell being part of a ship. This is done by considering all possible ship placements for each unshot cell (accounting for different ship lengths and orientations). The cell with the highest probability (most possible valid ship placements) is chosen.

### Solution Code
```python
def policy(board: list[list[int]]) -> tuple[int, int]:
    # Target phase: check for adjacent cells to existing hits
    candidates = set()
    for r in range(10):
        for c in range(10):
            if board[r][c] == 1:  # Hit detected
                # Check all four neighboring directions
                for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < 10 and 0 <= nc < 10:
                        if board[nr][nc] == 0:
                            candidates.add((nr, nc))
    if candidates:
        # Return the first candidate in sorted order (row-major)
        sorted_candidates = sorted(candidates)
        return sorted_candidates[0]
    
    # Hunt phase: evaluate all unshot cells
    ship_lengths = [5, 4, 3, 3, 2]
    max_score = -1
    best_cells = []
    for r in range(10):
        for c in range(10):
            if board[r][c] == 0:  # Unshot cell
                score = 0
                for length in ship_lengths:
                    # Check horizontal possibilities
                    min_start_col = max(0, c - (length - 1))
                    max_start_col = min(c, 10 - length)
                    for start_col in range(min_start_col, max_start_col + 1):
                        valid = True
                        for k in range(start_col, start_col + length):
                            if board[r][k] == -1:
                                valid = False
                                break
                        if valid:
                            score += 1
                    # Check vertical possibilities
                    min_start_row = max(0, r - (length - 1))
                    max_start_row = min(r, 10 - length)
                    for start_row in range(min_start_row, max_start_row + 1):
                        valid = True
                        for k in range(start_row, start_row + length):
                            if board[k][c] == -1:
                                valid = False
                                break
                        if valid:
                            score += 1
                # Update best cells
                if score > max_score:
                    max_score = score
                    best_cells = [(r, c)]
                elif score == max_score:
                    best_cells.append((r, c))
    # Choose the best cell
    if best_cells:
        best_cells.sort()
        return best_cells[0]
    else:
        return (0, 0)
```

### Explanation
- **Targeting Phase**: If there are any hits on the board, we explore their adjacent cells to find unshot locations that could extend the hit ship.
- **Hunting Phase**: When no adjacent hits exist, we calculate for each unshot cell how many valid ship placements (considering all possible ship lengths and orientations) include it. This probability-based approach ensures we target the most likely cells to contain ships, maximizing efficiency in sinking all opponent ships.

This approach balances deterministic targeting when hits are found and uses a probabilistic strategy to optimize shot placement in the absence of immediate hits, leading to an efficient and effective solution.
