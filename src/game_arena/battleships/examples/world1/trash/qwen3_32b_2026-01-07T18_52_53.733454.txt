The solution implements a probability-based targeting strategy for the Battleship game. It calculates for each unshot cell the number of valid ship placements (considering existing hits and misses) and selects the cell with the highest probability of containing a ship segment.

The approach combines:
1. **Probability Grid Calculation**: For each unshot cell, it evaluates how many possible ship placements (for remaining ship lengths) could include that cell without conflicting with known misses.
2. **Efficient Search**: By checking horizontal and vertical placements for each ship length, it balances between exploring new areas (hunt mode) and exploiting previous hits (target mode).

The algorithm prioritizes cells adjacent to hits, as they are more likely to belong to the same ship. It handles all ship orientations and lengths while avoiding already fired cells and known misses.

def policy(board: list[list[int]]) -> tuple[int, int]:
    probability = [[0]*10 for _ in range(10)]
    
    # Calculate probability for each unshot cell
    for i in range(10):
        for j in range(10):
            if board[i][j] == 0:  # Only consider unshot cells
                # List of ship lengths to consider
                for ship_length in [5, 4, 3, 3, 2]:
                    # Check horizontal placements
                    s_min = max(0, j - (ship_length - 1))
                    s_max = min(10 - ship_length, j)
                    count_h = 0
                    for s in range(s_min, s_max + 1):
                        valid = True
                        for c in range(s, s + ship_length):
                            if board[i][c] == -1:
                                valid = False
                                break
                        if valid:
                            count_h += 1
                    
                    # Check vertical placements
                    v_min = max(0, i - (ship_length - 1))
                    v_max = min(10 - ship_length, i)
                    count_v = 0
                    for s in range(v_min, v_max + 1):
                        valid = True
                        for r in range(s, s + ship_length):
                            if board[r][j] == -1:
                                valid = False
                                break
                        if valid:
                            count_v += 1
                    
                    # Update probability grid
                    probability[i][j] += count_h + count_v
    
    # Find cell with highest probability (row-major tie-break)
    max_prob = -1
    best_row, best_col = 0, 0
    for i in range(10):
        for j in range(10):
            if board[i][j] == 0 and probability[i][j] > max_prob:
                max_prob = probability[i][j]
                best_row, best_col = i, j
            elif board[i][j] == 0 and probability[i][j] == max_prob:
                # Tie-break by row then column index
                if i < best_row or (i == best_row and j < best_col):
                    best_row, best_col = i, j
    
    return (best_row, best_col)
