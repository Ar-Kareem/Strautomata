# Strategy

This Go policy uses a combination of strategic approaches:
1. **Prioritize center中书地 control** - Initial moves will target the center and star points (4-4 and 3-3 points)
2. **Balanced offense/defense** - Looks for capture opportunities when opponent groups have few liberties while maintaining雞 own group safety
3. **Shape awareness** - Prefers good Go shape moves like knights moves, stretching)
4. **Territory building** - As game progresses, focuses more on securing territory
5. **Emergency response** - Immediately answers threats to own groups with 1 liberty

The implementation uses:
- Fast board state checking with bitboard representation internally
- Simple heuristic evaluation prioritizing:
  - Immediate capture opportunities
  - Liberty counting for own groups
  - Strategic point occupation
- Progressive strategy that shifts from opening to midgame Territory建設計 

The policy maintains basic memory to:
- Track game phase
- Remember opponent's last move for response patterns
- Avoid重复 bad moves
