### Strategy Overview

For this Amazons policy on a 6x6 board, I'll implement a **rule-based heuristic approach** that prioritizes:
1. **Capturing opponent amazons** (if possible) to reduce their mobility.
2. **Controlling the center** by moving toward the center squares (2,2) and (3,3) to maximize influence.
3. **Avoiding self-blocking** by ensuring arrows don't block future moves.
4. **Randomness in tie-breakers** to avoid predictable patterns.

The policy will:
- First check for any move that captures an opponent's amazon.
- If no captures are possible, prioritize moves that bring the amazon closer to the center.
- If no center-moving moves are available, choose a random legal move.

This ensures the policy is **deterministic** (same input → same output) while still being **adaptive** to the board state.

### Python Implementation
```python
import numpy as np
import random

def policy(board) -> str:
    # Get all possible legal moves
    legal_moves = generate_legal_moves(board)
    if not legal_moves:
        raise ValueError("No legal moves available (should not happen per problem statement)")

    # Priority 1: Capture opponent amazons
    captures = [move for move in legal_moves if is_capture(move, board)]
    if captures:
        # Choose the first capture (or random if multiple)
        return captures[0]

    # Priority 2: Move toward center (2,2 or 3,3)
    center_moves = []
    for move in legal_moves:
        from_row, from_col, to_row, to_col, arrow_row, arrow_col = parse_move(move)
        # Prefer moves that bring the amazon closer to the center
        center_dist = abs(to_row - 2.5) + abs(to_col - 2.5)  # Manhattan distance to (2.5, 2.5)
        center_moves.append((center_dist, move))

    if center_moves:
        # Choose the move with the smallest center distance
        center_moves.sort()
        return center_moves[0][1]

    # Priority 3: Random legal move
    return random.choice(legal_moves)

def generate_legal_moves(board):
    legal_moves = []
    my_amazons = np.argwhere(board == 1)

    for (from_row, from_col) in my_amazons:
        # Generate all possible to positions (queen moves)
        for to_row in range(6):
            for to_col in range(6):
                if board[to_row, to_col] != 0:
                    continue  # to must be empty
                if not is_valid_move((from_row, from_col), (to_row, to_col), board):
                    continue

                # Generate all possible arrow positions from to
                for arrow_row in range(6):
                    for arrow_col in range(6):
                        if board[arrow_row, arrow_col] != 0:
                            continue  # arrow must land on empty
                        if not is_valid_arrow((to_row, to_col), (arrow_row, arrow_col), board, (from_row, from_col)):
                            continue

                        # Construct move string
                        move = f"{from_row},{from_col}:{to_row},{to_col}:{arrow_row},{arrow_col}"
                        legal_moves.append(move)

    return legal_moves

def is_valid_move(from_pos, to_pos, board):
    from_row, from_col = from_pos
    to_row, to_col = to_pos

    # Check if path is clear (queen move)
    dr = to_row - from_row
    dc = to_col - from_col
    step_row = 1 if dr > 0 else (-1 if dr < 0 else 0)
    step_col = 1 if dc > 0 else (-1 if dc < 0 else 0)

    current_row, current_col = from_row + step_row, from_col + step_col
    while (current_row, current_col) != (to_row, to_col):
        if board[current_row, current_col] != 0:
            return False
        current_row += step_row
        current_col += step_col

    return True

def is_valid_arrow(to_pos, arrow_pos, board, from_pos):
    to_row, to_col = to_pos
    arrow_row, arrow_col = arrow_pos

    # Check if path is clear (queen move, ignoring from_pos if it's on the path)
    dr = arrow_row - to_row
    dc = arrow_col - to_col
    step_row = 1 if dr > 0 else (-1 if dr < 0 else 0)
    step_col = 1 if dc > 0 else (-1 if dc < 0 else 0)

    current_row, current_col = to_row + step_row, to_col + step_col
    while (current_row, current_col) != (arrow_row, arrow_col):
        if (current_row, current_col) == from_pos:
            # Allow passing through the vacated from_pos
            pass
        elif board[current_row, current_col] != 0:
            return False
        current_row += step_row
        current_col += step_col

    return True

def is_capture(move, board):
    from_row, from_col, to_row, to_col, _, _ = parse_move(move)
    return board[to_row, to_col] == 2

def parse_move(move):
    parts = move.split(':')
    from_part, to_part, arrow_part = parts
    from_row, from_col = map(int, from_part.split(','))
    to_row, to_col = map(int, to_part.split(','))
    arrow_row, arrow_col = map(int, arrow_part.split(','))
    return from_row, from_col, to_row, to_col, arrow_row, arrow_col
```

---

### Explanation of Key Functions:
1. **`generate_legal_moves`**:
   - Iterates over all your amazons (`board == 1`).
   - For each amazon, checks all possible `to` positions (queen moves).
   - For each valid `to`, checks all possible `arrow` positions (queen moves from `to`, ignoring the vacated `from` if it's on the path).
   - Returns all valid moves as strings.

2. **`is_valid_move`**:
   - Checks if the path from `from` to `to` is clear (no blockers).

3. **`is_valid_arrow`**:
   - Checks if the path from `to` to `arrow` is clear, allowing the arrow to pass through the vacated `from` square.

4. **`is_capture`**:
   - Checks if the `to` position contains an opponent's amazon (`board == 2`).

5. **`parse_move`**:
   - Helper to split a move string into coordinates.

---

### Guarantees:
- **Always returns a legal move**: The policy first checks for legal moves and raises an error if none exist (though the problem states this won't happen).
- **Efficient**: Uses nested loops but is optimized by early termination (e.g., skipping invalid `to` positions).
- **Deterministic**: Same input → same output (no randomness in non-tie-breaker cases).
