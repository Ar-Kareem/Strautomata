The strategy is to evaluate the possible moves for each of my amazons on the 6x6 board. After identifying each possible move, I’ll choose the first legal move found. The criteria for moving include ensuring that the target square is empty and that the path to both the move and arrow target is unobstructed.

Here's how the implementation proceeds:
1. Iterate through all squares on the board.
2. For each amazon found, evaluate all potential destinations it can occupy.
3. For each valid destination, check if it's possible to shoot an arrow to another valid square.
4. Return the first legal move that can be made.

This approach prioritizes straightforward execution and guarantees that I always return a legal move. 

Here’s the Python code implementing this policy:

```python
import numpy as np

def is_path_clear(board, start, end):
    """ Check if the path is clear between start and end points. """
    r1, c1 = start
    r2, c2 = end
    dr = (r2 - r1) // max(1, abs(r2 - r1)) if r1 != r2 else 0
    dc = (c2 - c1) // max(1, abs(c2 - c1)) if c1 != c2 else 0
    r, c = r1 + dr, c1 + dc
    while (r != r2 or c != c2):
        if board[r, c] != 0:  # Not empty
            return False
        r += dr
        c += dc
    return True

def get_possible_moves(board):
    """ Generate all possible moves for all amazons. """
    moves = []
    for r from range(6):
        for c in range(6):
            if board[r, c] == 1:  # Your amazon
                # Check all possible queen-like moves
                for dr in range(-5, 6):
                    for dc in range(-5, 6):
                        if abs(dr) == abs(dc) or dr == 0 or dc == 0:  # Queen move
                            if (dr, dc) != (0, 0):  # Not moving to the same square
                                new_row, new_col = r + dr, c + dc
                                if 0 <= new_row < 6 and 0 <= new_col < 6 and board[new_row, new_col] == 0:
                                    # Now check for valid arrow shots
                                    for ar in range(-5, 6):
                                        for ac in range(-5, 6):
                                            if (ar, ac) != (0, 0) and abs(ar) == abs(ac) or ar == 0 or ac == 0:
                                                arrow_row, arrow_col = new_row + ar, new_col + ac
                                                if 0 <= arrow_row < 6 and 0 <= arrow_col < 6 and board[arrow_row, arrow_col] == 0:
                                                    if is_path_clear(board, (r, c), (new_row, new_col)) and \
                                                       is_path_clear(board, (new_row, new_col), (arrow_row, arrow_col)):
                                                        moves.append(f"{r},{c}:{new_row},{new_col}:{arrow_row},{arrow_col}")
    return moves

def policy(board) -> str:
    moves = get_possible_moves(board)
    if moves:
        return moves[0]  # return the first legal move found
    return "No legal moves available"  # This should not happen per problem description.
```

This code efficiently checks for valid moves and ensures that I always return a legal move string as required.
