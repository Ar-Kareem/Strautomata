To solve this problem, we need to implement a policy for a simplified Blackjack-like game where the target score `T` is given, and the player must decide whether to "HIT" or "STAY" based on their current hand. The goal is to maximize the chance of winning by either reaching the target score without busting or minimizing the probability of busting.

### Approach
1. **Hand Value Calculation**: The hand's value is computed by considering each card's value. Non-face cards (2-10) are valued at their face value, face cards (J, Q, K) are valued at 10, and Aces can be valued at 11 if it doesn't exceed the target score, otherwise, they are valued at 1.
2. **Bust Check**: After each card draw, the hand's value is recalculated to check if it exceeds the target score. If it does, the player busts and loses immediately.
3. **Decision Making**: The policy decides whether to hit or stay based on the current hand's value:
   - **STAY** if the current hand value is already at or above a certain threshold relative to the target score, minimizing the risk of busting.
   - **HIT** if the current value is lower, allowing the player to increase their sum closer to the target score without busting.

### Solution Code
```python
def compute_value(hand, target):
    sum_non_aces = 0
    num_aces = 0
    for card in hand:
        if card == 'A':
            num_aces += 1
        elif card in {'J', 'Q', 'K', '10'}:
            sum_non_aces += 10
        else:
            sum_non_aces += int(card)
    
    sum_max = sum_non_aces + 11 * num_aces
    if sum_max <= target:
        return sum_max
    
    # Calculate the minimal number of aces to convert to 1 to not exceed the target
    required_reduction = sum_max - target
    k = (required_reduction + 9) // 10  # Ceiling division
    k = max(k, 0)
    k = min(k, num_aces)
    
    new_sum = sum_max - 10 * k
    if new_sum <= target:
        return new_sum
    
    # If converting k aces isn't enough, check after converting all to 1
    sum_converted_all = sum_non_aces + num_aces
    if sum_converted_all <= target:
        return sum_converted_all
    else:
        return None, True  # Busted

def policy(hand, target):
    value, busted = compute_value(hand, target)
    if busted:
        return 'STAY'
    
    # Heuristic: Hit if current value is less than half the target
    if value * 2 < target:
        return 'HIT'
    else:
        return 'STAY'
```

### Explanation
1. **Hand Value Calculation**: The `compute_value` function calculates the best possible hand value considering Aces can be 11 or 1. It first calculates the maximum possible sum with all Aces as 11. If this exceeds the target, it converts the necessary number of Aces to 1 to stay within the target.
2. **Bust Check**: If the hand's value exceeds the target even after converting all possible Aces to 1, the player is considered busted.
3. **Policy Decision**: The `policy` function uses a heuristic to decide whether to hit or stay. The heuristic is to hit if the current value is less than half the target score, which allows the player to potentially get closer to the target without busting. If the current value is already high, the player stays to avoid the risk of busting.

This approach balances the risk of busting with the potential to get closer to the target score, leveraging the flexibility of Ace values to optimize the hand's value dynamically.
