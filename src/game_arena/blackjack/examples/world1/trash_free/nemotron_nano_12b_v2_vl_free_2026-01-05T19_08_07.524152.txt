To solve this problem, we need to develop a policy for a simplified Blackjack-like game where the goal is to reach a target score T with a hand of cards. The policy must decide whether to draw a new card (HIT) or stop drawing cards (STAY) on each turn based on the current hand and the target score.

### Approach
1. **Sum Calculation with Ace Adjustment**: Calculate the current sum of the hand, adjusting the value of Aces based on the target score. Aces are considered as 11 if they help reach the target without busting; otherwise, they are treated as 1.
2. **Bust Check**: If the computed sum exceeds the target, the player immediately loses, so we assume the function is only called when the hand is valid (sum ≤ target).
3. **Decision Making**: If the current sum equals the target, the optimal move is to stay. Otherwise, evaluate the average possible new sum if the player draws another card. If the average new sum is better than the current sum, draw a card (HIT); otherwise, stay.

### Explanation
1. **Sum Calculation**: The `compute_sum` function calculates the adjusted sum of the hand by considering all Aces as 11 initially. If this sum exceeds the target, it adjusts the Aces to 1s to minimize the bust probability.
2. **Decision Making**: The `policy` function first checks if the current sum matches the target. If not, it evaluates all possible cards that can be drawn from the remaining deck. For each possible card, it computes the new adjusted sum and averages these values. If the expected new sum is higher than the current sum, the player should HIT; otherwise, stay.

This approach balances the risk of busting against the potential to get closer to the target, allowing the player to make informed decisions based on the expected outcome of drawing new cards.
