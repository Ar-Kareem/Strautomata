To solve this problem, we need to determine the optimal strategy for playinga simplified Blackjack-like game where the goal is to get as close as possible to a target score without exceeding it. The player's decision on whether to draw another card (HIT) or stop (STAY) is based on the current hand and the target score.

### Approach
1. **Calculate Hand Value**: Determine the current value of the player's hand. This involves summing the non-Ace cards and considering the Ace cards as 11 initially, adjusting their value if necessary to avoid exceeding the target score.
2. **Check for Bust**: If the current hand value exceeds the target score, the player must stay (they are bust).
3. **Decide to Hit or Stay**: If the current hand value is less than the target, check if adding the minimum possible card value (2) would keep the player's sum within the target. If it does, the player draws another card (HIT); otherwise, they stay.

### Solution Code
```python
def policy(hand: list[str], target: int) -> str:
    sum_non_ace = 0
    num_aces = 0
    
    for card in hand:
        if card == 'A':
            num_aces += 1
        elif card in {'J', 'Q', 'K'}:
            sum_non_ace += 10
        elif card == '10':
            sum_non_ace += 10
        else:
            sum_non_ace += int(card)
    
    current_sum = sum_non_ace + 11 * num_aces
    is_bust = False
    
    if current_sum > target:
        over = current_sum - target
        ace_converts_needed = (over + 9) // 10
        num_ace_converts = min(ace_converts_needed, num_aces)
        new_sum = current_sum - 10 * num_ace_converts
        
        if new_sum <= target:
            current_sum = new_sum
            is_bust = False
        else:
            # Check if converting all aces to 1 helps
            current_sum = sum_non_ace + num_aces
            is_bust = current_sum > target
    
    if is_bust:
        return 'STAY'
    
    if current_sum == target:
        return 'STAY'
    
    # Decide to hit or stay
    if (current_sum + 2) <= target:
        return 'HIT'
    else:
        return 'STAY'
```

### Explanation
1. **Hand Value Calculation**: The function first calculates the sum of non-Ace cards and counts the number of Aces. It then computes the initial sum by treating all Aces as 11. If this initial sum exceeds the target, it adjusts the value of Aces to 1 until the sum is within the target or all Aces are converted.
2. **Bust Check**: If the adjusted sum still exceeds the target, the player busts and must stay.
3. **Decision Making**: If the player is not bust and their current sum is exactly the target, they stay. If the current sum plus the minimum possible card value (2) is within the target, they hit; otherwise, they stay. This heuristic ensures the player maximizes their chance of reaching the target without busting, based on the minimal card value assumption.
