### Thinking Process:

**Understanding the Game Clobber:**
Clobber is a two-player abstract strategy game where players take turns moving their pieces to capture opponent pieces. The key rules are:
1. A move consists of moving one of your pieces orthogonally (up, down, left, right) onto an opponent's piece, capturing it.
2. The captured piece is removed, and your piece occupies the destination square.
3. The player who cannot make a legal move loses.

**Board Representation:**
- The board is 5 rows x 6 columns.
- `you` and `opponent` are 5x6 arrays where `1` indicates a piece, and `0` indicates an empty cell.
- At most one of `you[row, col]` or `opponent[row, col]` can be `1` at any cell.

**Legal Moves:**
- A legal move must start from a cell with your piece (`you[row, col] == 1`).
- The destination cell must be adjacent (orthogonally) and contain an opponent's piece (`opponent[row, col] == 1`).
- The destination must be within bounds (0-4 for rows, 0-5 for columns).

**Policy Design:**
Since the goal is to implement a move-selection policy, the strategy should aim to maximize the chances of winning. A simple but effective strategy could be:
1. **Prioritize capturing opponent pieces that are adjacent to multiple of your pieces** (to create more future opportunities).
2. **Avoid leaving opponent pieces isolated** (to limit their future moves).
3. **Prefer moves that reduce the opponent's mobility** (e.g., capturing pieces that are blocking their potential moves).
4. **If no such strategic moves are available, pick any legal move** (since the problem guarantees at least one legal move exists).

**Implementation Steps:**
1. Iterate over all your pieces (`you[row, col] == 1`).
2. For each piece, check all four possible directions (U, R, D, L).
3. For each direction, check if the destination is within bounds and contains an opponent's piece.
4. Among all legal moves, select one based on a heuristic (e.g., prioritize moves that capture opponent pieces with fewer adjacent opponent pieces).
5. If no heuristic is applied, return the first legal move found (as a fallback).

**Heuristic Choice:**
A simple heuristic could be to prioritize moves where the opponent's piece being captured has the fewest adjacent opponent pieces. This reduces the opponent's future mobility.

**Edge Cases:**
- If all opponent pieces are isolated (no adjacent opponent pieces), any legal move is fine.
- If multiple moves satisfy the heuristic, pick the first one encountered.

**Code Structure:**
- Use nested loops to iterate over your pieces and directions.
- For each direction, check bounds and opponent presence.
- Collect all legal moves, then select one based on the heuristic.
- Return the move in the required string format.

### Python Implementation:

```python
def policy(you, opponent):
    # Directions: U, R, D, L with corresponding row and column changes
    directions = [(-1, 0, 'U'), (0, 1, 'R'), (1, 0, 'D'), (0, -1, 'L')]

    # List to store all legal moves
    legal_moves = []

    # Iterate over all your pieces
    for row in range(5):
        for col in range(6):
            if you[row][col] == 1:
                # Check all four directions
                for dr, dc, dir in directions:
                    new_row, new_col = row + dr, col + dc
                    # Check if new position is within bounds and has opponent's piece
                    if 0 <= new_row < 5 and 0 <= new_col < 6 and opponent[new_row][new_col] == 1:
                        legal_moves.append((row, col, dir))

    # If no legal moves (shouldn't happen per problem statement)
    if not legal_moves:
        return "0,0,U"  # fallback, but problem says this won't happen

    # Heuristic: prefer moves that capture opponent pieces with fewer adjacent opponent pieces
    # For each legal move, count how many opponent pieces are adjacent to the captured piece
    def count_adjacent_opponent_pieces(row, col, opponent):
        count = 0
        for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
            nr, nc = row + dr, col + dc
            if 0 <= nr < 5 and 0 <= nc < 6 and opponent[nr][nc] == 1:
                count += 1
        return count

    # Evaluate all legal moves and pick the one with the smallest count (most isolated opponent piece)
    best_move = None
    best_score = float('inf')

    for move in legal_moves:
        row, col, dir = move
        # The captured piece is at (row + dr, col + dc) where dr, dc is from the direction
        # So we need to find the direction's dr, dc to get the captured piece's position
        for dr, dc, d in directions:
            if d == dir:
                captured_row, captured_col = row + dr, col + dc
                break
        score = count_adjacent_opponent_pieces(captured_row, captured_col, opponent)
        if score < best_score:
            best_score = score
            best_move = move

    # If no move found (shouldn't happen), pick the first legal move
    if best_move is None:
        best_move = legal_moves[0]

    return f"{best_move[0]},{best_move[1]},{best_move[2]}"
```

### Explanation of the Code:
1. **Directions Handling**: The four possible directions (U, R, D, L) are defined with their corresponding row and column changes.
2. **Legal Moves Collection**: The code iterates over all your pieces and checks all four directions to see if a move is legal (destination in bounds and has opponent's piece).
3. **Heuristic Evaluation**: For each legal move, the code calculates how many opponent pieces are adjacent to the piece being captured. The move that captures the most isolated opponent piece (fewest adjacent opponent pieces) is preferred.
4. **Fallback**: If no move is found (unlikely per problem statement), it defaults to the first legal move.
5. **Output**: The best move is returned in the required string format.

This approach ensures that the policy always returns a legal move while attempting to make strategic captures that limit the opponent's future mobility.
