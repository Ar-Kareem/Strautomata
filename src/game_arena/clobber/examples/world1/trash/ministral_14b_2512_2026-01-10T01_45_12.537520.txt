### Thinking Process:

**Understanding the Game Clobber:**
Clobber is a two-player abstract strategy game where players take turns moving their pieces to capture opponent pieces. The key rules are:
1. A move consists of moving one of your pieces orthogonally (up, down, left, right) onto an opponent's piece, capturing it.
2. The capturing piece moves to the opponent's position, and the opponent's piece is removed.
3. The player who cannot make a legal move loses.

**Objective:**
The goal of the policy function is to select a legal move for the current player ("you") given the current board state. The function must always return a legal move, and the strategy should ideally aim to maximize the chance of winning (though for simplicity, we might start with a basic strategy).

**Approach:**
1. **Identify Legal Moves:** Iterate through all your pieces and check all four possible orthogonal directions to see if moving in that direction would capture an opponent's piece.
2. **Select a Move:** For simplicity, we can use a basic strategy like:
   - Prioritize capturing pieces that are adjacent to multiple opponent pieces (to limit opponent's future moves).
   - Or, prioritize capturing pieces that are in the center (to control the board).
   - Or, just pick the first valid move found (simplest approach).
3. **Return the Move:** Once a legal move is found, return it in the specified format.

**Implementation Details:**
- Use nested loops to iterate over all your pieces.
- For each piece, check all four directions (U, R, D, L) to see if the destination is within bounds and contains an opponent's piece.
- Return the first valid move found (or a more sophisticated move if time allows).

**Edge Cases:**
- Ensure the move is within the 5x6 grid bounds.
- Ensure the destination cell is occupied by the opponent.
- Ensure the starting cell is occupied by you.

**Optimization:**
- For simplicity, we'll use a basic strategy that picks the first valid move found. This is guaranteed to be legal and will not violate the rules.

### Python Code:
```python
def policy(you: list[int], opponent: list[int]) -> str:
    # Convert to numpy arrays for easier manipulation (optional, but helpful)
    import numpy as np
    you_board = np.array(you)
    opponent_board = np.array(opponent)

    # Directions: U, R, D, L (row, col changes)
    directions = {
        'U': (-1, 0),
        'R': (0, 1),
        'D': (1, 0),
        'L': (0, -1)
    }

    # Iterate over all your pieces
    for row in range(5):
        for col in range(6):
            if you_board[row, col] == 1:
                # Check all four directions
                for dir_name, (dr, dc) in directions.items():
                    new_row, new_col = row + dr, col + dc
                    # Check if new position is within bounds and has opponent's piece
                    if 0 <= new_row < 5 and 0 <= new_col < 6:
                        if opponent_board[new_row, new_col] == 1:
                            return f"{row},{col},{dir_name}"

    # This line should theoretically never be reached due to problem constraints
    return "0,0,U"  # fallback (should not happen)
```

### Explanation of the Code:
1. **Board Representation:** The `you` and `opponent` lists are converted to NumPy arrays for easier indexing and manipulation.
2. **Directions:** The four possible directions (U, R, D, L) are defined as coordinate changes (delta row, delta column).
3. **Iterate Over Your Pieces:** For each cell on the board, if it contains your piece (`you_board[row, col] == 1`), check all four directions.
4. **Check Legal Move:** For each direction, calculate the new position. If the new position is within bounds and contains an opponent's piece, return the move in the format `row,col,dir`.
5. **Fallback:** The fallback return is a placeholder and should never be reached because the problem guarantees at least one legal move exists.

This strategy is simple and guarantees a legal move, though it does not implement any advanced tactics. For a more competitive policy, you could add heuristics like prioritizing captures that reduce the opponent's mobility or control central squares. However, this basic version meets the requirement of always returning a legal move.
