To solve this problem, we need to create a move-selection policy for the game of Clobber. The goal is to implement a function that selects the optimal move for the player to make, ensuring that the opponent is left with the fewest possible moves while maximizing our future moves.

### Approach
1. **Generate Possible Moves**: For each of our pieces, check all four orthogonal directions (up, down, left, right) to see if moving in that direction would capture an opponent's piece. Collect all valid moves.
2. **Evaluate Each Move**: For each potential move, simulate the resulting board state and compute two metrics:
   - The number of moves the opponent can make immediately after our move.
   - The number of moves we can make in the new state after the opponent's next move.
3. **Select Optimal Move**: Choose the move that leaves the opponent with the fewest possible moves. If multiple such moves exist, select the one that maximizes our own subsequent moves.

### Solution Code

```python
def policy(you, opponent):
    directions = {'U': (-1, 0), 'D': (1, 0), 'R': (0, 1), 'L': (0, -1)}

    possible_moves = []
    for i in range(5):
        for j in range(6):
            if you[i][j] == 1:
                for d in ['U', 'D', 'R', 'L']:
                    di, dj = directions[d]
                    ni = i + di
                    nj = j + dj
                    if 0 <= ni < 5 and 0 <= nj < 6 and opponent[ni][nj] == 1:
                        possible_moves.append((i, j, d))

    def count_moves(player, enemy):
        cnt = 0
        for x in range(5):
            for y in range(6):
                if player[x][y] == 1:
                    for dx, dy in [(-1, 0), (1, 0), (0, 1), (0, -1)]:
                        nx = x + di
                        ny = j + dj
                        if 0 <= ni < 5 and 0 <= nj < 6:

                                cnt += 1
        return cnt

    evaluated = []
    for move in possible_moves:
        i, j, d = move
        di, dj = directions[d]
        ni = i + di
        nj = j + dj

        new_you = [row.copy() for row in you]
        new_opponent = [row.copy() for row in opponent]
        new_you[i][j] = 0
        new_you[ni][nj] = 1
        new_opponent[ni][nj] = 0

        opp_count = count_moves(new_opponent, new_you)
        my_moves = count_moves(new_you, new_opponent)

        evaluated.append((opp_moves, -my_moves, move))

    evaluated.sort()
    best_move = evaluated[0][2]
    return f"{best_move[0]},{best_move[1]},{best_move[2]}"
```

### Explanation
1. **Generating Moves**: The code iterates over each cell in the 5x6 grid. For each of our pieces, it checks all four possible directions to determine if a valid capture move exists against an opponent's piece.
2. **Evaluating Moves**: For each valid move, the code simulates the resulting board state. It then calculates how many moves the opponent would have and how many moves we would have in the new state. This evaluation helps prioritize moves that minimize the opponent's future options while maximizing our own future options.
3. **Selecting the Best Move**: Moves are ranked based on how poorly they leave the opponent positioned (fewer moves are better) and how favorably they position us for our next turn. The move with the best evaluation is chosen and returned.
