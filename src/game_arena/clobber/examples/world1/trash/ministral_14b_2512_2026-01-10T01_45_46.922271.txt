### Thinking Process:

**Understanding the Game Clobber:**
Clobber is a two-player abstract strategy game where players take turns moving their pieces to capture opponent pieces. The key rules are:
1. A move consists of moving one of your pieces orthogonally (up, down, left, right) onto an opponent's piece, capturing it.
2. The capturing piece replaces the opponent's piece on the destination square, and the starting square becomes empty.
3. The player who cannot make a legal move loses.

**Objective:**
The goal is to implement a move-selection policy (`policy`) that always returns a legal move. The policy should be simple but effective, ensuring that the AI never gets stuck (i.e., always has a legal move when called).

**Approach:**
1. **Legal Moves Generation:** Iterate over all your pieces (`you` board) and check all four possible orthogonal directions (U, R, D, L) to see if moving in that direction would land on an opponent's piece.
2. **Prioritization:** Since the problem doesn't specify a complex strategy (like minimax or evaluation), we can use a simple heuristic:
   - Prefer moves that capture opponent pieces in the center of the board (e.g., rows 2-3, columns 2-3) as these are more strategic.
   - If no such moves exist, pick any legal move.
3. **Fallback:** If no moves are found (though the problem states this won't happen), return a default move (though this is a safeguard).

**Implementation Details:**
- Use nested loops to check all your pieces and all four directions.
- For each direction, check if the destination is within bounds and contains an opponent's piece.
- Collect all legal moves and prioritize them based on the heuristic (e.g., center preference).
- Return the first legal move found (or the highest-priority one).

**Edge Cases:**
- Ensure the destination is within the 5x6 grid (rows 0-4, columns 0-5).
- Ensure the starting cell is your piece and the destination is the opponent's piece.

### Python Code:
```python
def policy(you: list[int], opponent: list[int]) -> str:
    # Directions: U, R, D, L with corresponding row/col deltas
    directions = [('U', -1, 0), ('R', 0, 1), ('D', 1, 0), ('L', 0, -1)]

    # Iterate over all your pieces
    for row in range(5):
        for col in range(6):
            if you[row][col] == 1:
                # Check all four directions
                for dir_char, dr, dc in directions:
                    new_row, new_col = row + dr, col + dc
                    # Check if new position is within bounds and has opponent's piece
                    if 0 <= new_row < 5 and 0 <= new_col < 6:
                        if opponent[new_row][new_col] == 1:
                            # Return the first legal move found (simple heuristic)
                            return f"{row},{col},{dir_char}"

    # Fallback (should never be reached per problem statement)
    return "0,0,R"  # Default move (invalid if no legal moves, but problem says this won't happen)
```

### Explanation of the Code:
1. **Directions:** The `directions` list defines the four possible moves (U, R, D, L) with their corresponding row and column deltas.
2. **Nested Loops:** The outer loops iterate over all cells in the `you` board. For each of your pieces (`you[row][col] == 1`), the inner loop checks all four directions.
3. **Legal Move Check:** For each direction, the code calculates the new position (`new_row`, `new_col`). If this position is within bounds and contains an opponent's piece (`opponent[new_row][new_col] == 1`), it returns the move in the format `row,col,dir`.
4. **Fallback:** The fallback return is a safeguard (though the problem guarantees at least one legal move exists).

### Why This Works:
- The code is simple and guarantees a legal move is returned as soon as one is found.
- It doesn't overcomplicate the strategy, which is sufficient for the problem's constraints.
- The order of checking directions is arbitrary (U, R, D, L), but this doesn't affect correctness.
