The strategy is to select the move that maximizes the mobility difference for the next turn. Specifically, we want to make a move that maximizes `my_mobility - opponent_mobility` in the subsequent state. This is a greedy heuristic based on a 1-ply lookahead, which is well-suited for a game like Clobber where the board is small and aggressive play is key.

1.  **Identify Legal Moves**: Iterate through all cells to find my pieces.
2.  **Check Neighbors**: For each piece, check the four orthogonal directions (Up, Down, Left, Right).
3.  **Validate Moves**: Ensure the destination is within bounds (0-4 rows, 0-5 columns) and contains an opponent piece.
4.  **Evaluate Moves**: For each legal move, simulate the board state after the move.
    -   Calculate the number of legal moves available to you (my mobility) in the new state.
    -   Calculate the number of legal moves available to the opponent in the new state (opponent mobility).
    -   Compute the score: `my_mobility - opponent_mobility`.
5.  **Select Best Move**: Choose the move with the highest score. To break ties, prefer the move that captures the opponent's piece located at the highest row index (lowest on the board), or if that is tied, the highest column index.

```python
def policy(you: list[int], opponent: list[int]) -> str:
    rows = 5
    cols = 6
    directions = [('U', -1, 0), ('D', 1, 0), ('L', 0, -1), ('R', 0, 1)]

    def get_mobility(board, is_me):
        # board = (me, opp)
        b_me, b_opp = board
        mob = 0
        for r in range(rows):
            for c in range(cols):
                if b_me[r][c]:
                    for d, dr, dc in directions:
                        nr, nc = r + dr, c + dc
                        if 0 <= nr < rows and 0 <= nc < cols and b_opp[nr][nc]:
                            mob += 1
        return mob

    best_move = None
    max_score = -float('inf')

    # Iterate through all cells to find legal moves
    for r in range(rows):
        for c in range(cols):
            if you[r][c]:
                for d, dr, dc in directions:
                    nr, nc = r + dr, c + dc
                    # Check bounds and opponent presence
                    if 0 <= nr < rows and 0 <= nc < cols and opponent[nr][nc]:
                        # Simulate move
                        # Create shallow copies of rows to modify safely
                        new_you = [row[:] for row in you]
                        new_opponent = [row[:] for row in opponent]
                        
                        # Apply move
                        new_you[r][c] = 0
                        new_opponent[nr][nc] = 0
                        new_you[nr][nc] = 1

                        # Calculate score
                        my_mob = get_mobility((new_you, new_opponent), True)
                        opp_mob = get_mobility((new_opponent, new_you), False)
                        score = my_mob - opp_mob

                        # Tie-breaking: prioritize captures lower on the board (higher row index)
                        tie_break = nr * 10 + nc

                        if score > max_score or (score == max_score and tie_break > (best_move[1] * 10 + best_move[2])):
                            max_score = score
                            best_move = (r, c, d)

    return f"{best_move[0]},{best_move[1]},{best_move[2]}"
```
