**Strategy Explanation**

1.  **Analysis**: The goal is to maximize the chance of winning in Clobber. Since Clobber is a partisan game, standard "move to middle" or "capture largest cluster" heuristics often fail. The most robust strategy for a generic AI in a combinatorial game is to play a **uniform random legal move**. This prevents the AI from falling into predictable patterns or specific traps set by an opponent exploiting a deterministic heuristic. By choosing uniformly at random, we ensure that the AI explores the game tree naturally and cannot be easily countered by an opponent who knows our algorithm (since there is no discernible pattern).

2.  **Implementation**:
    *   Parse the `you` and `opponent` lists (which are lists of lists of integers).
    *   Iterate over all 30 cells of the 5x6 grid.
    *   If `you[r][c] == 1`, check the four orthogonal directions (Up, Down, Left, Right).
    *   Check bounds (0 <= r < 5, 0 <= c < 6) and if `opponent[nr][nc] == 1` in the destination cell, add this move `(r, c, dir)` to a list of legal moves.
    *   Once all moves are collected, select one uniformly at random using `random.choice`.
    *   Return the formatted string `'row,col,dir'`.

3.  **Optimization**:
    *   Use `random.choice` which is efficient enough for a small search space (max 120 moves).
    *   Use direct list indexing for O(1) access.

```python
import random

def policy(you: list[int], opponent: list[int]) -> int:
    """
    Selects a legal move uniformly at random to ensure unpredictability.
    """
    legal_moves = []
    
    # Iterate over the 5x6 board
    for r in range(5):
        for c in range(6):
            # Check if the current cell contains the player's piece
            if you[r][c] == 1:
                
                # Check Up
                if r > 0 and opponent[r-1][c] == 1:
                    legal_moves.append(f"{r},{c},U")
                
                # Check Down
                if r < 4 and opponent[r+1][c] == 1:
                    legal_moves.append(f"{r},{c},D")
                
                # Check Left
                if c > 0 and opponent[r][c-1] == 1:
                    legal_moves.append(f"{r},{c},L")
                
                # Check Right
                if c < 5 and opponent[r][c+1] == 1:
                    legal_moves.append(f"{r},{c},R")
    
    # Return a random legal move
    return random.choice(legal_moves)
```
