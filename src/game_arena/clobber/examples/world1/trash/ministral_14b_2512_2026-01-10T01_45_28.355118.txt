### Thinking Process:

1. **Understanding the Game Rules**:
   - The game is played on a 5x6 grid.
   - Players take turns moving their pieces to capture opponent pieces.
   - A move consists of moving one of your pieces orthogonally (up, down, left, right) onto an opponent's piece, capturing it.
   - The player who cannot make a move loses.

2. **Legal Move Requirements**:
   - The starting cell must contain your piece (`you[row][col] == 1`).
   - The destination cell must be in bounds and contain an opponent's piece (`opponent[row][col] == 1`).
   - The move must be orthogonal (U, D, L, R).

3. **Policy Design**:
   - Since the goal is to always return a legal move, the simplest approach is to find any valid move. However, to make the policy more strategic, we can prioritize moves that:
     - Capture opponent pieces that are blocking multiple potential moves.
     - Move towards the center or high-value positions (though this is subjective).
     - Avoid leaving the opponent with too many options.
   - For simplicity, I'll implement a greedy policy that picks the first valid move it finds (e.g., leftmost, topmost piece with a valid capture). This ensures legality and is computationally efficient.

4. **Implementation Steps**:
   - Iterate over all your pieces (`you` board).
   - For each piece, check all four orthogonal directions (U, D, L, R).
   - If the destination is in bounds and contains an opponent's piece, return the move.
   - If no move is found (shouldn't happen per problem statement), raise an error.

5. **Edge Cases**:
   - Ensure the move is within bounds (0 <= row < 5, 0 <= col < 6).
   - Handle cases where multiple moves are possible (pick the first one found).

### Python Code:
```python
def policy(you: list[list[int]], opponent: list[list[int]]) -> str:
    # Directions: U, R, D, L (row, col changes)
    directions = [(-1, 0, 'U'), (0, 1, 'R'), (1, 0, 'D'), (0, -1, 'L')]

    # Iterate over all your pieces
    for row in range(5):
        for col in range(6):
            if you[row][col] == 1:
                # Check all four directions
                for dr, dc, dir in directions:
                    new_row, new_col = row + dr, col + dc
                    # Check if new position is in bounds and has opponent's piece
                    if 0 <= new_row < 5 and 0 <= new_col < 6 and opponent[new_row][new_col] == 1:
                        return f"{row},{col},{dir}"

    # Should never reach here per problem statement
    raise ValueError("No legal move found")
```

### Explanation:
- The function iterates over every cell in the `you` board to find your pieces.
- For each piece, it checks all four possible orthogonal directions (U, R, D, L).
- If the destination cell is within bounds and contains an opponent's piece, it returns the move in the format `row,col,dir`.
- The first valid move found is returned, ensuring efficiency and legality.
- The problem guarantees at least one legal move exists, so the `raise` is a safeguard.

This policy is simple but effective for the given constraints. For more advanced play, you could extend it to evaluate moves based on strategic importance (e.g., capturing pieces that block multiple opponent moves).
