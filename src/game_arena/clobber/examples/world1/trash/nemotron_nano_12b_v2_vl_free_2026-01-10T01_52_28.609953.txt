To solve this problem, we need to develop an AI that plays the Clobber game optimally by selecting the best possible move on its turn. The goal is to choose a move that minimizes the number of subsequent legal moves available to the opponent. This approach is based on the minimax principle, where we aim to reduce the opponent's potential moves at each step.

### Approach
1. **Possible Moves Generation**: Iterate through each cell on the board to identify all possible moves for the current player. A move is valid if it starts from a cell occupied by the current player's piece and ends on a cell adjacent orthogonally that contains the opponent's piece.
2. **Evaluate Each Move**: For each potential move, simulate the resulting board state. This involves capturing the opponent's piece and updating the board accordingly.
3. **Opponent's Possible Moves Calculation**: For each simulated post-move board state, calculate how many moves the opponent can make. This is done by checking all the opponent's pieces and their possible orthogonal moves to capture the current player's pieces.
4. **Select the Optimal Move**: Choose the move that results in the fewest possible moves for the opponent. If multiple moves yield the same minimal count of opponent moves, select the first one encountered in the move generation process.

### Solution Code
```python
import numpy as np

def policy(you, opponent) -> str:
    # Convert input lists to numpy arrays for efficient manipulation
    you = np.array(you, dtype=int)
    opponent = np.array(opponent, dtype=int)
    
    # List to store all possible moves (r, c, direction)
    possible_moves = []
    
    # Define direction deltas and their corresponding directions
    directions = {'U': (-1, 0), 'R': (0, 1), 'D': (1, 0), 'L': (0, -1)}
    
    # Generate all possible moves
    for r in range(5):
        for c in range(6):
            if you[r, c] == 1:
                for direction, (dr, dc) in directions.items():
                    new_r = r + dr
                    new_c = c + dc
                    if 0 <= new_r < 5 and 0 <= new_c < 6:
                        if opponent[new_r, new_c] == 1:
                            possible_moves.append((r, c, direction))
    
    # If no moves are found (though problem states it won't happen), handle safely
    if not possible_moves:
        # This should not occur as per problem statement
        return "0,0,U"
    
    # Find the move with the minimal opponent moves after execution
    best_move = None
    min_opponent_moves = float('inf')
    
    for move in possible_moves:
        r, c, direction = move
        dr, dc = directions[direction]
        new_r = r + dr
        new_c = c + dc
        
        # Create new board states after making the move
        new_you = np.zeros_like(you, dtype=int)
        np.copyto(new_you, you)
        new_you[r, c] = 0
        new_you[new_r, new_c] = 1
        
        new_opponent = np.zeros_like(opponent, dtype=int)
        np.copyto(new_opponent, opponent)
        new_opponent[new_r, new_c] = 0  # Opponent's piece is captured
        
        # Calculate how many moves the opponent can make in the new state
        opponent_move_count = 0
        for o_r in range(5):
            for o_c in range(6):
                if new_opponent[o_r, o_c] == 1:
                    # Check all four directions for possible captures
                    for odr, odc in directions.values():
                        new_or = o_r + odr
                        new_oc = o_c + odc
                        if 0 <= new_or < 5 and 0 <= new_oc < 6:
                            if new_you[new_or, new_oc] == 1:
                                opponent_move_count += 1
        
        # Update the best move if this one is better
        if opponent_move_count < min_opponent_moves:
            min_opponent_moves = opponent_move_count
            best_move = move
    
    r, c, direction = best_move
    return f"{r},{c},{direction}"
```

### Explanation
1. **Move Generation**: The code first identifies all valid moves by checking each cell occupied by the current player's piece and determining valid orthogonal moves to capture the opponent's pieces.
2. **Move Evaluation**: For each valid move, the board state is modified to reflect the move, and the number of possible moves the opponent can make is calculated. This helps in estimating the impact of each move on the opponent's future options.
3. **Optimal Move Selection**: The move that results in the fewest subsequent moves for the opponent is selected. This heuristic prioritizes moves that reduce the opponent's options, aiming to limit their opportunities and increase the chances of winning.

This approach ensures that the AI always returns a valid move and strategically selects moves to minimize the opponent's future options, thereby maximizing the player's chances of success in the game.
