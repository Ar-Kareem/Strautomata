The strategy is to iterate through each cell on the board in row-major order (top to bottom, left to right). For each cell containing your piece (`you[row][col] == 1`), check adjacent cells in the order: **Up (U), Right (R), Down (D), Left (L)**. If any adjacent cell is a valid opponent piece (within bounds and `opponent` has a 1 in that cell), the move is returned immediately. This guarantees a legal move as described in the problem, and it prioritizes finding the first valid move in a deterministic manner.

def policy(you: list[list[int]], opponent: list[list[int]]) -> str:
    for row in range(5):
        for col in range(6):
            if you[row][col] == 1:
                # Check Up
                if row > 0 and opponent[row - 1][col] == 1:
                    return f"{row},{col},U"
                # Check Right
                if col < 5 and opponent[row][col + 1] == 1:
                    return f"{row},{col},R"
                # Check Down
                if row < 4 and opponent[row + 1][col] == 1:
                    return f"{row},{col},D"
                # Check Left
                if col > 0 and opponent[row][col - 1] == 1:
                    return f"{row},{col},L"
    return ""
