### Thinking Process:

**Understanding the Game Clobber:**
Clobber is a two-player abstract strategy game where players take turns moving their pieces to capture opponent pieces. The goal is to be the last player with legal moves. The board is 5x6, and pieces move orthogonally (up, down, left, right) to capture opponent pieces.

**Key Observations:**
1. **Legal Moves:** A move is legal if:
   - The starting cell has your piece (`you[row][col] == 1`).
   - The destination cell (adjacent in one of 4 directions) has the opponent's piece (`opponent[row][col] == 1`).
   - The destination cell is within bounds (0-4 for rows, 0-5 for columns).

2. **Objective:** Since the policy is called when it's your turn and there is at least one legal move, the goal is to select a move that maximizes your chances of winning. A simple but effective strategy is to prioritize moves that:
   - Capture opponent pieces in a way that limits their future moves (e.g., capturing pieces that are blocking their own pieces).
   - Avoid creating situations where the opponent can easily capture your pieces in the next move.
   - Prioritize capturing pieces that are adjacent to multiple opponent pieces (to reduce their mobility).

3. **Implementation Approach:**
   - Iterate over all your pieces (`you` board).
   - For each piece, check all 4 adjacent cells (up, down, left, right) to see if they contain an opponent piece.
   - Collect all legal moves.
   - If no legal moves exist (though the problem states this won't happen), return `None` (but the problem guarantees at least one legal move).
   - Select a move based on some heuristic. For simplicity, we can:
     - Prioritize moves that capture opponent pieces that are adjacent to more opponent pieces (to reduce their mobility).
     - If no such preference, pick the first legal move found.

4. **Heuristic for Move Selection:**
   - For each legal move, count how many opponent pieces are adjacent to the destination cell (excluding the piece being captured). This is a simple way to measure how "valuable" the capture is (capturing a piece that is blocking others is better).
   - Choose the move with the highest such count. If multiple moves have the same count, pick the first one encountered.

5. **Edge Cases:**
   - Ensure the destination cell is within bounds.
   - Ensure the starting cell is your piece and the destination is opponent's piece.

### Python Implementation:

```python
def policy(you: list[int], opponent: list[int]) -> str:
    # Convert to numpy arrays for easier manipulation
    import numpy as np
    you_board = np.array(you)
    opponent_board = np.array(opponent)

    # Directions: U, R, D, L (row, col changes)
    directions = {
        'U': (-1, 0),
        'R': (0, 1),
        'D': (1, 0),
        'L': (0, -1)
    }

    legal_moves = []

    # Iterate over all your pieces
    for row in range(5):
        for col in range(6):
            if you_board[row, col] == 1:
                # Check all 4 directions
                for dir_name, (dr, dc) in directions.items():
                    new_row, new_col = row + dr, col + dc
                    # Check if destination is within bounds and has opponent's piece
                    if 0 <= new_row < 5 and 0 <= new_col < 6:
                        if opponent_board[new_row, new_col] == 1:
                            legal_moves.append((row, col, dir_name))

    # If no legal moves (shouldn't happen per problem statement)
    if not legal_moves:
        return None  # This line is theoretically unreachable per problem statement

    # Heuristic: choose move that captures opponent piece adjacent to most opponent pieces
    # For each legal move, count how many opponent pieces are adjacent to the destination
    def score_move(move):
        row, col, dir_name = move
        dr, dc = directions[dir_name]
        dest_row, dest_col = row + dr, col + dc
        # Count opponent pieces adjacent to (dest_row, dest_col)
        count = 0
        for dr2, dc2 in directions.values():
            nr, nc = dest_row + dr2, dest_col + dc2
            if 0 <= nr < 5 and 0 <= nc < 6:
                if opponent_board[nr, nc] == 1:
                    count += 1
        return count

    # Sort legal moves by score (descending) and pick the first one
    legal_moves.sort(key=score_move, reverse=True)
    best_move = legal_moves[0]
    return f"{best_move[0]},{best_move[1]},{best_move[2]}"
```

### Explanation of the Code:
1. **Board Representation:** The `you` and `opponent` lists are converted to NumPy arrays for easier manipulation.
2. **Directions:** The four possible directions (U, R, D, L) are defined with their corresponding row and column changes.
3. **Legal Moves Collection:** For each of your pieces, check all four adjacent cells to see if they contain an opponent's piece. If so, record the move as `(row, col, direction)`.
4. **Move Scoring:** For each legal move, count how many opponent pieces are adjacent to the destination cell (excluding the piece being captured). This score helps prioritize moves that reduce the opponent's mobility.
5. **Move Selection:** The legal moves are sorted by their scores in descending order, and the highest-scoring move is selected. If multiple moves have the same score, the first one encountered is chosen.

This approach ensures that the policy always returns a legal move and prioritizes moves that are strategically advantageous by reducing the opponent's future options.
