1.  **Analyze the Game Rules**:
    *   The game is Clobber on a 5x6 board.
    *   Current player moves one of their pieces (`1`) orthogonally (U, D, L, R) onto an opponent's piece (`1`), capturing it.
    *   The goal is to make a legal move.
    *   The policy must return a string `row,col,dir`.
    *   Constraints: Must be fast (1s limit), but for 5x6, even a complex search is negligible. The most robust approach for abstract games is to perform a depth-limited search (Minimax with Alpha-Beta pruning) to select a move that leads to a winning state or avoids losing immediately.

2.  **Data Representation**:
    *   Input: 2 lists of lists (`you`, `opponent`).
    *   Internal State: To optimize, I will flatten the board into bitmasks (integers). A 5x6 board has 30 squares, which fits easily into a 64-bit integer.
        *   `us_mask`: bit `r*6+c` is 1 if we are there.
        *   `opp_mask`: bit `r*6+c` is 1 if opponent is there.
    *   This allows very fast move generation and state copying using bitwise operations.

3.  **Move Generation**:
    *   For each piece of the current player, check 4 directions.
    *   Bounds checking: must stay within 0 <= r < 5 and 0 <= c < 6.
    *   Target must be occupied by the opponent.
    *   Transitions: `us_mask` loses the start bit and gains the end bit; `opp_mask` loses the end bit.

4.  **Search Strategy (Minimax with Alpha-Beta)**:
    *   **Depth**: 5x6 is small enough for a relatively deep search, but we need to ensure we don't time out. A depth of 6-10 should be sufficient to see immediate blunders and short combinations. I'll start with depth 8.
    *   **Evaluation Function**:

        *   Mobility: Number of legal moves available. Being able to move is crucial.
        *   Heuristic: `score = 10*(my_pieces - opp_pieces) + 0.1*my_moves`.
    *   **Transposition Table**: Since the state space is small (though 2^30 is large, effective states are limited by piece count), a simple dictionary cache for visited states (Zobrist hashing or simple tuple key) will speed up the search significantly.
