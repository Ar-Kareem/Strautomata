The strategy is to prioritize each cell in row-major order and check directions in the order Up, Right, Down, Left. The first valid move encountered is returned, ensuring quick selection and meeting the time constraints.

```python
def policy(you: list[int], opponent: list[int]) -> str:
    dirs = [('U', -1, 0), ('R', 0, 1), ('D', 1, 0), ('L', 0, -1)]
    for row in range(5):
        for col in range(6):
            if you[row][col]:
                for dir_name, dr, dc in dirs:
                    nr, nc = row + dr, col + dc
                    if 0 <= nr < 5 and 0 <= nc < 6:
                        if opponent[nr][nc]:
                            return f"{row},{col},{dir_name}"
    return "0,0,R"  # Fallback, though unreachable per problem statement
```
