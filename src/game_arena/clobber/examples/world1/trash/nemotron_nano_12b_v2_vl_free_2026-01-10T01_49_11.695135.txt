To solve this problem, we need to implement a move-selection policy for the game Clobber. The policy must return a legal move in the format 'row,col,dir' where the move must be valid according to the game's rules. The strategy involves checking each of your pieces in a systematic order and selecting the first valid move found.

### Approach
1. **Systematic Check**: Iterate through each cell in a row-major order (rows from top to bottom, columns from left to right).
2. **Direction Check**: For each of your pieces, check all four possible directions (up, down, left, right) in a fixed order to determine if a valid capture move exists.
3. **Return First Valid Move**: As soon as a valid move is found, return it immediately. This ensures efficiency and simplicity while guaranteeing a valid move according to the problem constraints.

### Solution Code
```python
def policy(you: list[int], opponent: list[int]) -> str:
    for row in range(5):
        for col in range(6):
            if you[row][col] == 1:
                # Check all possible directions in order: up, down, left, right
                if row > 0 and opponent[row-1][col] == 1:
                    return f"{row},{col},U"
                if row < 4 and opponent[row+1][col] == 1:
                    return f"{row},{col},D"
                if col > 0 and opponent[row][col-1] == 1:
                    return f"{row},{col},L"
                if col < 5 and opponent[row][col+1] == 1:
                    return f"{row},{col},R"
    return ""  # This line is theoretically unreachable per problem constraints
```

### Explanation
- **Row-Major Order**: The code iterates through each cell starting from the top-left corner (row 0, column 0) to the bottom-right (row 4, column 5).
- **Direction Check Order**: For each cell, directions are checked in the order of up, down, left, and right. This ensures that the first valid move found in this order is selected.
- **Validation**: Each move is checked to ensure it stays within the board boundaries and captures an opponent's piece. The problem guarantees at least one valid move exists, ensuring the function will return a valid move without needing additional checks.

This approach efficiently finds a valid move by leveraging systematic iteration and immediate return upon finding the first valid option, ensuring both correctness and performance within the given constraints.
