The game is Clobber on a 5x6 board.
I will implement a Minimax algorithm with Alpha-Beta pruning and Quiescence Search to select the best move. I will also use Zobrist hashing for transposition tables to improve efficiency, although the 1-second time limit and single call nature might limit its impact, it's good practice. The evaluation function will be based on piece count and mobility.

    def evaluate(my_board, opp_board):

        my_count = bin(my_board).count('1')

        # Heuristic: Piece count * 100 + Mobility * 10

        return (my_count - opp_count) * 100 + (my_mob - opp_mob) * 10

    return f"{r},{c},{d}"
