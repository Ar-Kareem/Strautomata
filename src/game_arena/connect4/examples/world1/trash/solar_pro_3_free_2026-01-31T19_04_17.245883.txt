**Strategy**

The policy follows a classic Connect 4 AI approach:

1. **Immediate win** – First scan all columns for any move that would create a line of four discs for the current player. If such a move exists, return the lowest‑indexed column that wins.

2. **Immediate block** – Next scan for a column where dropping the opponent’s disc would immediately create a winning line. If such a threat exists, return the lowest‑indexed column to block it (this also prevents a forced loss on the next turn).

3. **Heuristic evaluation** – If no win/block is available, evaluate the board with a fast heuristic that rewards “open” threats:
   * **Open‑3** patterns (three consecutive discs with an empty cell on either side) give +100 points for us, –100 for the opponent.
   * **Open‑2** patterns (two consecutive discs with an empty adjacent cell) give +10, –10.
   * A small bias is added for empty central columns (cols 3 & 4) versus edge columns, because central openings are more valuable.

4. **Look‑ahead search** – Run a minimax search limited to a depth of 5 plies (i.e., five moves ahead). The minimax node values use the heuristic described above. Alpha‑beta pruning is incorporated inside the search to keep the search fast.

5. **Select move** – Return the column with the highest minimax value (lowest index if tied). This move is always legal because the search only examines non‑full columns.

The combination of aggressive threat handling, a well‑tuned heuristic, and a depth‑limited minimax guarantees a strong, yet fast, playing style that consistently beats naive random or greedy opponents in the arena.
