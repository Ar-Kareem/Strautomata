To solve this problem, we need to create a policy function for a Connect 4 game that ensures the AI makes optimal moves to either win immediately, block the opponent from winning, or position itself for future wins. The solution uses a combination of checking for immediate wins, blocking the opponent's potential wins, and a heuristic-based approach to prioritize strategic moves.

### Approach
1. **Immediate Win Check**: The AI first checks if there is any move it can make to win immediately by forming a horizontal, vertical, or diagonal line of four discs.
2. **Block Opponent's Win**: If no immediate win is possible, the AI checks if any move will allow the opponent to win on their next turn. Such moves are blocked.
3. **Heuristic Selection**: If there are no immediate wins or threats, the AI uses a heuristic to choose the best move. For simplicity, it prioritizes columns closest to the center (column 3) as they offer more strategic advantages in forming future lines and maintaining mobility.

### Solution Code
```python
def policy(board: list[list[int]]) -> int:
    def has_win(b, player):
        # Check horizontal lines
        for row in range(6):
            for col in range(4):
                if all(b[row][col + i] == player for i in range(4)):
                    return True
        # Check vertical lines
        for col in range(7):
            for row in range(3):
                if all(b[row + i][col] == player for i in range(4)):
                    return True
        # Check diagonal down-right
        for row in range(3):
            for col in range(4):
                if all(b[row + i][col + i] == player for i in range(4)):
                    return True
        # Check diagonal down-left
        for row in range(3):
            for col in range(3, 7):
                if all(b[row + i][col - i] == player for i in range(4)):
                    return True
        return False

    def get_empty_cell(col):
        for row in reversed(range(6)):
            if board[row][col] == 0:
                return row
        return -1

    # Check for immediate win and identify available columns
    for col in range(7):
        empty_row = get_empty_cell(col)
        if empty_row == -1:
            continue
        new_board = [r.copy() for r in board]
        new_board[empty_row][col] = 1
        if has_win(new_board, 1):
            return col

    # Check for moves that allow opponent to win and exclude them
    bad_columns = set()
    for col in range(7):
        empty_row = get_empty_cell(col)
        if empty_row == -1:
            continue
        new_board = [r.copy() for r in board]
        new_board[empty_row][col] = 1

        # Check if opponent can win after this move
        for opp_col in range(7):
            o_row = get_empty_cell(opp_col)
            if o_row == -1:
                continue
            sim_board = [r.copy() for r in new_board]
            sim_board[o_row][opp_col] = -1
            if has_win(sim_board, -1):
                bad_columns.add(col)
                break

    # Determine safe columns (not in bad_columns)
    available = [col for col in range(7) if get_empty_cell(col) != -1]
    safe_columns = [c for c in available if c not in bad_columns]

    # Choose the best safe column based on proximity to center
    if safe_columns:
        return min(safe_columns, key=lambda c: (abs(c - 3)))
    else:
        return available[0]
```

### Explanation
1. **Immediate Win Check**: The function first checks each column to see if placing a disc there would result in a win for the current player. This is done using the `has_win` helper function.
2. **Opponent Blocking**: The function then checks if placing a disc in any column would allow the opponent to win on their next turn. If such a move is found, that column is marked as unsafe.
3. **Heuristic-Based Selection**: Among the safe columns (those that don't allow the opponent to win immediately), the function selects the column closest to the center (column 3) to maximize future strategic opportunities.

This approach ensures that the AI efficiently checks for immediate threats, defends against opponent moves, and makes strategic moves to position itself for future wins, all within a computationally feasible time.
