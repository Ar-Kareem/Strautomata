To solve thisproblem, we need to create a policy function that determines the next optimal move in a Connect 4 game for the current player. The goal is to either win immediately, block the opponent's potential winning move, or make a strategic move that maximizes future opportunities.

### Approach
1. **Winning Move Check**: First, check all possible columns where the current player can place a disc to immediately win. This involves simulating the placement of the disc in each possible column and checking if it results in a line of four discs in any direction (horizontal, vertical, or either diagonal).

2. **Block Opponent's Winning Move**: If no immediate winning move is found, check if the opponent can win in their next move. This involves simulating the opponent's possible moves and checking if any of them would result in a win. If such a column is found, block it to prevent the opponent from winning.

3. **Heuristic-Based Move Selection**: If neither a winning move nor an immediate threat from the opponent is found, use a heuristic to choose the best possible move. The heuristic prioritizes central columns (closer to column 3) as they offer more opportunities for forming lines in multiple directions.

### Solution Code
```python
def policy(board: list[list[int]]) -> int:
    def check_win(current_board: list[list[int]], player: int, col: int) -> bool:
        row = 0
        while row < 6 and current_board[row][col] != 0:
            row += 1
        if row >= 6:
            return False  # Column is full, which shouldn't happen as we check playable columns
        count = 1
        # Check vertical
        r = row - 1
        while r >= 0 and current_board[r][col] == player:
            count += 1
            r -= 1
        r = row + 1
        while r < 6 and current_board[r][col] == player:
            count += 1
            r += 1
        if count >= 4:
            return True
        # Check horizontal
        c = col - 1
        while c >= 0 and current_board[row][c] == player:
            count += 1
            c -= 1
        c = col + 1
        while c < 7 and current_board[row][c] == player:
            count += 1
            c += 1
        if count >= 4:
            return True
        # Check diagonal (top-left to bottom-right)
        count = 1
        r, c = row - 1, col - 1
        while r >= 0 and c >= 0 and current_board[r][c] == player:
            count += 1
            r -= 1
            c -= 1
        r, c = row + 1, col + 1
        while r < 6 and c < 7 and current_board[r][c] == player:
            count += 1
            r += 1
            c += 1
        if count >= 4:
            return True
        # Check diagonal (top-right to bottom-left)
        count = 1
        r, c = row - 1, col + 1
        while r >= 0 and c < 7 and current_board[r][c] == player:
            count += 1
            r -= 1
            c += 1
        r, c = row + 1, col - 1
        while r < 6 and c >= 0 and current_board[r][c] == player:
            count += 1
            r += 1
            c -= 1
        if count >= 4:
            return True
        return False

    player = 1  # Our disc
    opponent = -1  # Opponent's disc

    # Generate all possible columns where we can place a disc
    possible_columns = [c for c in range(7) if board[0][c] == 0]

    # Check for a winning move for the current player
    for c in possible_columns:
        if check_win(board, player, c):
            return c

    # Check if opponent has a winning move in their next turn; block it
    opponent_win_columns = []
    for d in possible_columns:
        if check_win(board, opponent, d):
            opponent_win_columns.append(d)
    if opponent_win_columns:
        # Block the leftmost opponent's winning move
        return min(opponent_win_columns)

    # Heuristic: prioritize columns closer to the center (3) for higher chances of creating lines
    possible_columns.sort(key=lambda x: abs(x - 3))
    return possible_columns[0] if possible_columns else -1  # -1 is invalid, but possible_columns should not be empty

```

### Explanation
1. **check_win Function**: This helper function determines if placing a disc in a specific column results in a win. It checks all four directions (vertical, horizontal, and both diagonals) for four consecutive discs of the same player.

2. **Generating Possible Moves**: The code first identifies all columns that are not full by checking the top row (row 0) as a proxy for column availability.

3. **Winning Move Check**: Iterate through each possible column and use `check_win` to determine if placing a disc there results in a win. If found, that column is chosen immediately.

4. **Blocking Opponent's Win**: If no winning move is found, check if the opponent can win next turn by simulating their move in each possible column. If such a column is found, block it to prevent the opponent from winning.

5. **Heuristic-Based Selection**: If no immediate threats are found, prioritize columns closer to the center (column 3) to maximize future winning opportunities. Columns are sorted by their distance from the center and the leftmost column is chosen if distances are equal.

This approach ensures that the policy efficiently handles immediate threats and strategically places discs to maximize future winning potential.
