The strategy for this policy is to implement a multi-layered approach:

1. **Winning Move Priority**: Always check for an immediate win by moving a piece to the opponent's home row.
2. **Threat Prevention**: If the opponent has a piece on our home row, prioritize capturing it.
3. **Progress Advancement**: Advance pieces that are closest to the opponent's home row.
4. **Safe Captures**: Perform captures when they don't expose our pieces unnecessarily.
5. **Favor Forward Movement**: Prefer forward moves over diagonal moves when no immediate tactical advantage exists.
6. **Fallback Strategy**: If no other moves are available, make the first legal move found.

This approach balances between aggressive tactics (capturing, advancing) and defensive play (preventing opponent wins). It prioritizes positional advantage while maintaining board control.

    # Determine direction based on color
    if color == 'b':
        direction = -1  # Black moves down (decreasing row)
        home_row = 7
        opp_home_row = 0
    else:
        direction = 1   # White moves up (increasing row)
        home_row = 0
        opp_home_row = 7

    # Convert positions to sets for faster lookup
    my_positions = set(me)
    opp_positions = set(opp)

    # 1. Check for winning move
    for r, c in me:
        # Try straight forward move to opponent's home row
        if r + direction == opp_home_row:
            if (r + direction, c) not in my_positions and (r + direction, c) not in opp_positions:
                return ((r, c), (r + direction, c))

    # 2. Check for opponent pieces on our home row that need to be captured
    for r, c in opp:

            # For white, this would be a forward-diagonal move from row 0 to row 1
            if color == 'b':

        if 0 <= r_new <= 7:

                    if (r_new, c_new) in opp_positions:

                    elif (r_new, c_new) not in my_positions:
