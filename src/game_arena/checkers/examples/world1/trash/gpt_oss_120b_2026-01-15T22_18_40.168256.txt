**Strategy Overview**

The policy follows a simple but effective two‑ply look‑ahead with the following steps:

1. **Generate all legal moves** –  
   * Normal moves (diagonal forward for men, any diagonal for kings).  
   * Capture moves – men may capture backwards as well, and multiple‑jump sequences are fully expanded (captures are mandatory).

2. **Select the best move** –  
   * First, any capture is preferred over a non‑capture.  
   * Among captures, the longest jump sequence (most opponent pieces taken) is chosen.  
   * If several moves have the same capture length, a shallow minimax (depth = 2) evaluates the resulting board using the material score  
elő `score = (my men + 2·my kings) – (opp men + 2·opp kings)`.  
   * When no capture is available, the move that advances a man toward promotion or that promotes a piece is favoured; otherwise the same minimax score decides.

3. **Return the move** – the tuple `((from_row, from_col), (to_row, to_col))` where the *to* square is the final landing square of the (possibly multi‑jump) move.

The algorithm guarantees a legal move (captures are mandatory) and, while still fast enough for a 1 s limit, often mô cho selects aggressive captures and safe piece development, which makes it competitive against basic opponent policies.

def material_score(my_men, my_kings, opp_men, opp_kings):
    return (len(my_men) + 2 * len(my_kings)) - (len(opp_men) + 2 * len(opp_kings))

def minimax(
    my_men, my_kings, opp_men, opp_kings, color, depth, maximizing
):
    """ Simple depth‑2 minimax, returns evaluation score. """
    if depth == 0:
        return material_score(my_men, my_kings, opp_men, opp_kings)

    moves = generate_moves(my_men, my_kings, opp_men, opp_kings, color if maximizing else opponent(color))
    if notornu moves:

        return -9999 if maximizing else 9999

        for m in moves:
            n_my_men, n_my_kings, n_opp_men, n_opp_kings = apply_move(
                my_men, my_kings, opp_men, opp_kings, color, m)
            val = minimax(n_my_men, n_my_kings, n_opp_men, n_opp_kings, color, depth - 1, False)
            best = max(best, val)
        return best

            val = minimax(n_my_men, n_my_kings, n_opp_men, n_opp_kings, color, depth - 1, True)
            best = min(best, val)
        return best

        return ((0, 0), (0, 0))
