To solve the 3D Tic Tac Toe problem, the goal is to create a policy function that selects the next optimal move. The strategy involves checking for immediate winning moves, blocking the opponent's potential wins, and then making strategic placements.

### Approach
1. **Identify Winning Moves**: Check if placing the player's mark in any empty cell creates a line of three. This is done by iterating through all possible lines (axes, face diagonals, and space diagonals) in the 3D cube and checking if two of the three cells are already occupied by the player.
2. **Block Opponent's Winning Moves**: If no winning move is found, check if the opponent can win in their next turn and block by placing a mark in that cell.
3. **Strategic Placement**: If no immediate winning or blocking moves are found, prioritize placing the mark in the center for maximum control, followed by corners, and then edges or random positions if necessary.

### Solution Code
```python
import random

# Precompute all possible lines in the cube
all_lines = []
# Axis-aligned lines
for y in range(3):
    for z in range(3):
        all_lines.append([(0, y, z), (1, y, z), (2, y, z)])
for x in range(3):
    for z in range(3):
        all_lines.append([(x, 0, z), (x, 1, z), (x, 2, z)])
for x in range(3):
    for y in range(3):
        all_lines.append([(x, y, 0), (x, y, 1), (x, y, 2)])

# Face diagonals
all_lines.extend([
    # Front/Back faces (z=0/z=2)
    [(0, 0, 0), (1, 1, 0), (2, 2, 0)],
    [(0, 2, 0), (1, 1, 0), (2, 0, 0)],
    [(0, 0, 2), (1, 1, 2), (2, 2, 2)],
    [(0, 2, 2), (1, 1, 2), (2, 0, 2)],
    # Top/Bottom faces (y=2/y=0)
    [(0, 2, 0), (1, 2, 1), (2, 2, 2)],
    [(0, 2, 2), (1, 2, 1), (2, 2, 0)],
    [(0, 0, 0), (1, 0, 1), (2, 0, 2)],
    [(0, 0, 2), (1, 0, 1), (2, 0, 0)],
    # Left/Right faces (x=0/x=2)
    [(0, 0, 0), (0, 1, 1), (0, 2, 2)],
    [(0, 2, 0), (0, 1, 1), (0, 0, 2)],
    [(2, 0, 0), (2, 1, 1), (2, 2, 2)],
    [(2, 2, 0), (2, 1, 1), (2, 0, 2)],
])

# Space diagonals
all_lines.extend([
    [(0, 0, 0), (1, 1, 1), (2, 2, 2)],
    [(0, 0, 2), (1, 1, 1), (2, 2, 0)],
    [(0, 2, 0), (1, 1, 1), (2, 0, 2)],
    [(0, 2, 2), (1, 1, 1), (2, 0, 0)],
])

def policy(board: list[list[list[int]]]) -> tuple[int, int, int]:
    # Helper function to check if placing 'player' at (x,y,z) wins
    def is_winning(x, y, z, player):
        for line in all_lines:
            if (x, y, z) in line:
                # Count existing player marks in the line (excluding current cell)
                count = 0
                for (i, j, k) in line:
                    if i == x and j == y and k == z:
                        continue  # Skip current cell as it's empty
                    if board[i][j][k] == player:
                        count += 1
                # After placing player here, total in line would be count + 1
                if count + 1 == 3:
                    return True
        return False

    # Find all empty cells
    empty_cells = []
    for x in range(3):
        for y in range(3):
            for z in range(3):
                if board[x][y][z] == 0:
                    empty_cells.append((x, y, z))

    # Check for immediate winning moves
    winning_moves = []
    for cell in empty_cells:
        x, y, z = cell
        if is_winning(x, y, z, 1):
            winning_moves.append(cell)
    if winning_moves:
        return winning_moves[0]  # Prioritize any winning move

    # Check for opponent's winning moves to block
    blocking_moves = []
    for cell in empty_cells:
        x, y, z = cell
        if is_winning(x, y, z, -1):
            blocking_moves.append(cell)
    if blocking_moves:
        return blocking_moves[0]  # Block opponent's win

    # Strategic placements: center, corners, etc.
    # Center has the most potential lines
    if board[1][1][1] == 0:
        return (1, 1, 1)

    # Available corners (higher strategic value than edges)
    corners = [
        (0, 0, 0), (0, 0, 2), (0, 2, 0), (0, 2, 2),
        (2, 0, 0), (2, 0, 2), (2, 2, 0), (2, 2, 2)
    ]
    available_corners = [c for c in corners if board[c[0]][c[1]][c[2]] == 0]
    if available_corners:
        return random.choice(available_corners)

    # Finally, choose any remaining empty cell
    return random.choice(empty_cells)
```

### Explanation
- **Line Precomputation**: The `all_lines` list contains all 49 possible winning lines in a 3D Tic Tac Toe game, including axis-aligned lines, face diagonals, and space diagonals.
- **Winning Move Check**: For each empty cell, check if placing the player's mark there completes a line of three.
- **Blocking Move Check**: Check if the opponent can win next turn and block it by taking that cell.
- **Strategic Placement**: Prioritize the center for maximum potential lines, followed by corners, ensuring edges or random cells are chosen last if no other options are optimal. This balances between offensive and defensive strategies while maintaining flexibility.
