To solve this problem, we need to implement an AI that plays a 3D Tic Tac Toe game with optimal strategy. The goal is to determine the best next move given the current state of the game board. The strategy should prioritize winning moves, blocking the opponent's winning moves, and choosing strategic positions to maximize future winning potential.

### Approach
1. **Winning Move Check**: The AI first checks if there is any empty cell where it can place its marker to immediately win the game. If such a move exists, it is chosen.
2. **Blocking Opponent's Winning Move**: If no immediate winning move is found, the AI checks if the opponent has a move that would result in a win on their next turn. If such a move exists, the AI blocks it to prevent the opponent from winning.
3. **Strategic Move**: If neither a winning move nor a blocking move is available, the AI uses a heuristic based on strategic positions. The priority order is:
   - **Center Cell**: (1,1,1) as it is part of the most lines.
   - **Corners**: Cells where all coordinates are 0 or 2.
   - **Edge Centers**: Cells in the middle of the edges of the cube.
   - **Face Centers**: Centers of each face of the cube.
   - **Remaining Cells**: Any other empty cells following the above order.

```python
def check_win(b, player):
    # Check rows along the x-axis
    for y in range(3):
        for z in range(3):
            if all(b[x][y][z] == player for x in range(3)):
                return True
    # Check columns along the y-axis
    for x in range(3):
        for z in range(3):
            if all(b[x][y][z] == player for y in range(3)):
                return True
    # Check pillars along the z-axis
    for x in range(3):
        for y in range(3):
            if all(b[x][y][z] == player for z in range(3)):
                return True
    # Check face diagonals in x-y planes (fixed z)
    for z in range(3):
        # Diagonal from (0,0,z) to (2,2,z)
        if (b[0][0][z] == player and b[1][1][z] == player and b[2][2][z] == player):
            return True
        # Diagonal from (0,2,z) to (2,0,z)
        if (b[0][2][z] == player and b[1][1][z] == player and b[2][0][z] == player):
            return True
    # Check face diagonals in x-z planes (fixed y)
    for y in range(3):
        # Diagonal from (x, y, 0) to (x, y, 2) with varying x and z
        if (b[0][y][0] == player and b[1][y][1] == player and b[2][y][2] == player):
            return True
        # Diagonal from (2,y,0) to (0,y,2)
        if (b[2][y][0] == player and b[1][y][1] == player and b[0][y][2] == player):
            return True
    # Check face diagonals in y-z planes (fixed x)
    for x in range(3):
        # Diagonal from (x, 0,0) to (x, 2,2)
        if (b[x][0][0] == player and b[x][1][1] == player and b[x][2][2] == player):
            return True
        # Diagonal from (x, 2,0) to (x, 0,2)
        if (b[x][2][0] == player and b[x][1][1] == player and b[x][0][2] == player):
            return True
    # Check space diagonals
    if (b[0][0][0] == player and b[1][1][1] == player and b[2][2][2] == player):
        return True
    if (b[0][0][2] == player and b[1][1][1] == player and b[2][2][0] == player):
        return True
    if (b[0][2][0] == player and b[1][1][1] == player and b[2][0][2] == player):
        return True
    if (b[2][0][0] == player and b[1][1][1] == player and b[0][2][2] == player):
        return True
    return False

def policy(board: list[list[list[int]]]) -> tuple[int, int, int]:
    # Define priority order for selecting cells
    priority = [
        # Center
        (1, 1, 1),
        # Corners
        (0,0,0), (0,0,2), (0,2,0), (0,2,2),
        (2,0,0), (2,0,2), (2,2,0), (2,2,2),
        # Edge centers (12 cells)
        (1,0,0), (1,0,2), (1,2,0), (1,2,2),
        (0,1,0), (2,1,0), (0,1,2), (2,1,2),
        (0,0,1), (2,0,1), (0,2,1), (2,2,1),
        # Face centers (6 cells)
        (0,1,1), (2,1,1), (1,0,1), (1,2,1),
        (1,1,0), (1,1,2)
    ]
    
    # Check for immediate winning move
    for i, j, k in priority:
        if board[i][j][k] != 0:
            continue
        # Create a deep copy of the board
        temp = [[[cell for cell in row] for row in layer] for layer in board]
        temp[i][j][k] = 1  # Simulate placing a 1
        if check_win(temp, 1):
            return (i, j, k)
    
    # Check for opponent's winning move to block
    for i, j, k in priority:
        if board[i][j][k] != 0:
            continue
        # Create a deep copy of the board
        temp = [[[cell for cell in row] for row in layer] for layer in board]
        temp[i][j][k] = -1  # Simulate opponent placing a -1
        if check_win(temp, -1):
            return (i, j, k)
    
    # Select the first available cell in the priority list
    for i, j, k in priority:
        if board[i][j][k] == 0:
            return (i, j, k)
    
    return (0, 0, 0)  # Fallback (should not reach here)
```

### Explanation
1. **check_win Function**: This helper function checks if a player has won by examining all possible lines (rows, columns, pillars, face diagonals, and space diagonals) in the 3D cube. If any line is fully occupied by the player's marks, the player wins.
2. **policy Function**: 
   - **Prioritized Moves**: The function first checks each cell in the predefined priority order to see if placing a marker there results in a win. If found, it returns that cell.
   - **Blocking Moves**: It then checks if the opponent can win on their next move. If such a move exists, it is blocked by placing the AI's marker there.
   - **Strategic Move**: If no immediate wins or blocks are needed, the AI selects the first available cell according to the predefined priority order, ensuring optimal positioning for future moves.

This approach ensures that the AI prioritizes winning moves, blocks the opponent effectively, and uses a strategic heuristic to maximize its chances of winning the game.
