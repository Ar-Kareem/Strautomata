To solve the 3D Tic Tac Toe problem, we need to create an AI that can determine the next optimal move on a 3x3x3 board. The AI should prioritize winning moves, blocking the opponent's winning moves, and fall back to a heuristic strategy when neither is possible.

### Approach
1. **Generate All Possible Lines**: In 3D Tic Tac Toe, a line can be along any axis or diagonal in any plane. We generate all possible lines (49 in total) that could form a winning condition.
2. **Check for Winning Move**: The AI first checks if it can win in the next move by finding any line where two of its symbols are present and the third is empty. If such a move exists, it is chosen immediately.
3. **Check for Blocking Move**: If the AI cannot win in the next move, it checks if the opponent can win. If the opponent has two symbols in a line with one empty cell, that cell is chosen to block the opponent.
4. **Heuristic Strategy**: If there are no immediate winning or blocking moves, the AI uses a heuristic to choose the best move. The heuristic prioritizes the center cell, then corners, and finally other cells.

### Solution Code
```python
def policy(board):
    # Generate all possible winning lines in 3x3x3 cube
    all_lines = []
    
    # Axis-aligned lines
    for y in range(3):
        for z in range(3):
            all_lines.append([(0, y, z), (1, y, z), (2, y, z)])  # x-axis lines
    for x in range(3):
        for z in range(3):
            all_lines.append([(x, 0, z), (x, 1, z), (x, 2, z)])  # y-axis lines
    for x in range(3):
        for y in range(3):
            all_lines.append([(x, y, 0), (x, y, 1), (x, y, 2)])  # z-axis lines
    
    # Face diagonals (XY, XZ, YZ planes)
    for z in range(3):
        all_lines.append([(0, 0, z), (1, 1, z), (2, 2, z)])
        all_lines.append([(0, 2, z), (1, 1, z), (2, 0, z)])
    for y in range(3):
        all_lines.append([(0, y, 0), (1, y, 1), (2, y, 2)])
        all_lines.append([(0, y, 2), (1, y, 1), (2, y, 0)])
    for x in range(3):
        all_lines.append([(x, 0, 0), (x, 1, 1), (x, 2, 2)])
        all_lines.append([(x, 0, 2), (x, 1, 1), (x, 2, 0)])
    
    # Space diagonals
    all_lines += [
        [(0, 0, 0), (1, 1, 1), (2, 2, 2)],
        [(0, 0, 2), (1, 1, 1), (2, 2, 0)],
        [(0, 2, 0), (1, 1, 1), (2, 0, 2)],
        [(0, 2, 2), (1, 1, 1), (2, 0, 0)]
    ]
    
    # Check for AI's winning move (1)
    for line in all_lines:
        cells = [board[i][j][k] for i, j, k in line]
        if cells.count(1) == 2 and cells.count(0) == 1:
            for i, j, k in line:
                if board[i][j][k] == 0:
                    return (i, j, k)
    
    # Check for opponent's winning move (-1) and block
    for line in all_lines:
        cells = [board[i][j][k] for i, j, k in line]
        if cells.count(-1) == 2 and cells.count(0) == 1:
            for i, j, k in line:
                if board[i][j][k] == 0:
                    return (i, j, k)
    
    # Heuristic play: prioritize center, then corners, then edges
    empty_positions = []
    for i in range(3):
        for j in range(3):
            for k in range(3):
                if board[i][j][k] == 0:
                    empty_positions.append((i, j, k))
    
    priority_order = []
    # Prioritize center
    if (1, 1, 1) in empty_positions:
        priority_order.append((1, 1, 1))
        empty_positions.remove((1, 1, 1))
    
    # Prioritize corners
    corners = [pos for pos in empty_positions if all(c in {0, 2} for c in pos)]
    priority_order.extend(corners)
    empty_positions = [pos for pos in empty_positions if pos not in corners]
    
    # Add remaining edges and other positions
    priority_order.extend(empty_positions)
    
    return priority_order[0]
```

### Explanation
1. **Generating Lines**: The code first generates all possible lines (49 lines) in the 3x3x3 cube, including axis-aligned, face diagonals, and space diagonals.
2. **Winning Move Check**: The AI checks each line to see if it can complete a line of three of its symbols by identifying if two cells are already its symbol (1) and the third is empty (0). If found, it returns that empty cell.
3. **Blocking Move Check**: Similarly, the AI checks for lines where the opponent has two symbols and one empty cell, returning the empty cell to block the opponent.
4. **Heuristic Strategy**: If no immediate winning or blocking moves are found, the AI uses a heuristic to prioritize moves: it first tries to take the center cell (1,1,1), then the corners of the cube, and finally other available cells.

This approach ensures the AI makes optimal moves to win, block, or strategically position itself on the board.
