Here's a Python implementation for a 3D Tic Tac Toe (3x3x3) policy function that uses a simple heuristic to choose the next move. This solution prioritizes winning moves, then blocks opponent winning moves, and finally falls back to a basic center preference strategy.

```python
import numpy as np
from typing import List, Tuple

def policy(board: List[List[List[int]]]) -> Tuple[int, int, int]:
    """
    Determines the next move for a 3D Tic Tac Toe game using a simple heuristic.

    Args:
        board: A 3x3x3 board represented as a list of lists of lists.
              0: empty, 1: player, -1: opponent

    Returns:
        A tuple (x, y, z) representing the coordinates of the next move (0-2).
    """
    board_np = np.array(board)
    player = 1
    opponent = -1

    # Check all possible winning moves for the player
    winning_move = find_winning_move(board_np, player)
    if winning_move is not None:
        return winning_move

    # Check all possible winning moves for the opponent and block them
    blocking_move = find_winning_move(board_np, opponent)
    if blocking_move is not None:
        return blocking_move

    # If no immediate winning/blocking move, prefer the center
    if board_np[1, 1, 1] == 0:
        return (1, 1, 1)

    # Otherwise, choose a random empty cell
    empty_cells = np.argwhere(board_np == 0)
    if len(empty_cells) > 0:
        return tuple(empty_cells[np.random.randint(0, len(empty_cells))])

    # No empty cells left (shouldn't happen in valid game)
    return (0, 0, 0)

def find_winning_move(board: np.ndarray, player: int) -> Tuple[int, int, int] | None:
    """
    Checks if the player can win in the next move by examining all possible lines.

    Args:
        board: The game board as a numpy array
        player: The player to check (1 or -1)

    Returns:
        A tuple of coordinates if a winning move is found, None otherwise
    """
    # All possible lines in 3D Tic Tac Toe
    lines = []

    # Rows in each layer
    for z in range(3):
        for y in range(3):
            lines.append([(x, y, z) for x in range(3)])

    # Columns in each layer
    for z in range(3):
        for x in range(3):
            lines.append([(x, y, z) for y in range(3)])

    # Diagonals in each layer (horizontal and vertical)
    for z in range(3):
        lines.append([(x, x, z) for x in range(3)])  # top-left to bottom-right
        lines.append([(x, 2 - x, z) for x in range(3)])  # top-right to bottom-left

    # Layers (3x3 planes)
    for z in range(3):
        lines.append([(x, y, z) for y in range(3) for x in range(3)])

    # 3D rows (fixed y and x, varying z)
    for y in range(3):
        for x in range(3):
            lines.append([(x, y, z) for z in range(3)])

    # 3D columns (fixed x and z, varying y)
    for x in range(3):
        for z in range(3):
            lines.append([(x, y, z) for y in range(3)])

    # 3D diagonals (space diagonals)
    lines.append([(x, x, x) for x in range(3)])  # main space diagonal
    lines.append([(x, x, 2 - x) for x in range(3)])  # anti space diagonal

    # Check each line for a winning move
    for line in lines:
        # Get the current state of the line
        line_state = [board[x, y, z] for (x, y, z) in line]

        # Count how many of the player's marks are in the line
        player_count = line_state.count(player)

        # If the player already has 3 in a line, they win (shouldn't happen)
        if player_count == 3:
            return None

        # If the player has 2 in a line and there's an empty spot, choose that
        if player_count == 2:
            empty_spots = [i for i, val in enumerate(line_state) if val == 0]
            if empty_spots:
                # Choose the first empty spot (could be randomized)
                chosen_index = empty_spots[0]
                return line[chosen_index]

    return None
```

### Explanation:
1. **`policy` function**:
   - First converts the input board to a NumPy array for easier manipulation.
   - Checks if the player can win in the next move using `find_winning_move`.
   - If no winning move, checks if the opponent can win and blocks them.
   - If no immediate winning/blocking move, prefers the center cell `(1, 1, 1)`.
   - If no center is available, chooses a random empty cell.

2. **`find_winning_move` function**:
   - Defines all possible winning lines in 3D Tic Tac Toe:
     - Rows, columns, and diagonals in each of the 3 layers.
     - 3D rows (fixed `y` and `x`, varying `z`).
     - 3D columns (fixed `x` and `z`, varying `y`).
     - Space diagonals (main and anti).
   - For each line, checks if the player has 2 marks and an empty spot. If so, returns the empty spot's coordinates.

### How to Use:
- Call `policy(board)` with the current game state as a 3x3x3 list.
- The function returns the next move as a tuple `(x, y, z)` where `x`, `y`, and `z` are integers between `0` and `2`.

### Example:
```python
board = [
    [[0, 0, 1], [0, 1, -1], [0, 0, 0]],  # Layer 0 (front)
    [[0, 0, 0], [0, 0, 0], [0, 0, 0]],  # Layer 1 (middle)
    [[0, 0, 0], [0, 0, 0], [0, 0, 0]]   # Layer 2 (back)
]
print(policy(board))  # Output might be (1, 1, 0) if the player has two in a row in layer 0
```

This is a basic implementation. For a more advanced AI, you could replace the random move selection with a minimax algorithm or other heuristics.
