Here's a Python implementation for a 3D Tic Tac Toe (3x3x3) game that uses a simple heuristic-based policy to determine the next move. This solution prioritizes winning moves, then blocks opponent winning moves, then looks for strategic positions (center or corners), and finally falls back to a random empty position.

```python
import numpy as np
from random import choice

def policy(board: list[list[list[int]]]) -> tuple[int, int, int]:
    """
    Determines the next move for a 3D Tic Tac Toe game (3x3x3) using a heuristic-based approach.

    Args:
        board: A 3x3x3 list of lists where:
            - 0 represents an empty cell
            - 1 represents the player's cell
            - -1 represents the opponent's cell

    Returns:
        A tuple (x, y, z) representing the coordinates of the next move (0-2 for each dimension).
    """
    # Convert to numpy array for easier manipulation
    np_board = np.array(board)

    # Check all possible moves for winning conditions
    for move in get_all_empty_moves(np_board):
        # Try the move
        temp_board = np_board.copy()
        temp_board[move] = 1

        # Check if this move wins the game
        if check_win(temp_board, 1):
            return tuple(move)

    # Block opponent's winning moves if any
    for move in get_all_empty_moves(np_board):
        # Try opponent's move
        temp_board = np_board.copy()
        temp_board[move] = -1

        # Check if opponent wins with this move
        if check_win(temp_board, -1):
            return tuple(move)

    # Prioritize center (1,1,1) if empty
    if np_board[1,1,1] == 0:
        return (1, 1, 1)

    # Prioritize corners (0,0,0), (0,2,2), (2,0,2), (2,2,0), etc.)
    corners = [(0,0,0), (0,0,2), (0,2,0), (0,2,2),
               (2,0,0), (2,0,2), (2,2,0), (2,2,2)]
    for corner in corners:
        if np_board[corner] == 0:
            return corner

    # Fallback: choose a random empty move
    empty_moves = get_all_empty_moves(np_board)
    return tuple(choice(empty_moves))

def get_all_empty_moves(board: np.ndarray) -> list[tuple[int, int, int]]:
    """Returns all empty (0) positions on the board as (x,y,z) tuples."""
    return list(zip(np.where(board == 0)[0], np.where(board == 0)[1], np.where(board == 0)[2]))

def check_win(board: np.ndarray, player: int) -> bool:
    """
    Checks if the specified player has won the game on the given board.
    Returns True if the player has a winning line, False otherwise.
    """
    # Check all rows in each layer
    for z in range(3):
        for y in range(3):
            if all(board[x,y,z] == player for x in range(3)):
                return True

    # Check all columns in each layer
    for z in range(3):
        for x in range(3):
            if all(board[x,y,z] == player for y in range(3)):
                return True

    # Check all diagonals in each layer
    for z in range(3):
        if all(board[i,i,z] == player for i in range(3)):
            return True
        if all(board[i,2-i,z] == player for i in range(3)):
            return True

    # Check all vertical lines (through z-axis)
    for x in range(3):
        for y in range(3):
            if all(board[x,y,z] == player for z in range(3)):
                return True

    # Check all horizontal lines (through x-axis)
    for y in range(3):
        for z in range(3):
            if all(board[x,y,z] == player for x in range(3)):
                return True

    # Check all horizontal lines (through y-axis)
    for x in range(3):
        for z in range(3):
            if all(board[x,y,z] == player for y in range(3)):
                return True

    # Check all space diagonals (4 main diagonals)
    if all(board[i,i,i] == player for i in range(3)):
        return True
    if all(board[i,i,2-i] == player for i in range(3)):
        return True
    if all(board[i,2-i,i] == player for i in range(3)):
        return True
    if all(board[2-i,i,i] == player for i in range(3)):
        return True

    # Check all face diagonals (12 face diagonals)
    # Front face (z=0)
    if all(board[i,i,0] == player for i in range(3)):
        return True
    if all(board[i,2-i,0] == player for i in range(3)):
        return True
    # Back face (z=2)
    if all(board[i,i,2] == player for i in range(3)):
        return True
    if all(board[i,2-i,2] == player for i in range(3)):
        return True
    # Left face (x=0)
    if all(board[0,i,i] == player for i in range(3)):
        return True
    if all(board[0,i,2-i] == player for i in range(3)):
        return True
    # Right face (x=2)
    if all(board[2,i,i] == player for i in range(3)):
        return True
    if all(board[2,i,2-i] == player for i in range(3)):
        return True
    # Top face (y=0)
    if all(board[i,0,i] == player for i in range(3)):
        return True
    if all(board[i,0,2-i] == player for i in range(3)):
        return True
    # Bottom face (y=2)
    if all(board[i,2,i] == player for i in range(3)):
        return True
    if all(board[i,2,2-i] == player for i in range(3)):
        return True

    return False
```

### Explanation:
1. **`policy` function**:
   - First checks if any move leads to an immediate win.
   - Then checks if any move can block the opponent from winning.
   - If no winning/blocking moves, prioritizes the center (1,1,1) if empty.
   - If the center is taken, prioritizes corners (positions with all coordinates 0 or 2).
   - Finally, chooses a random empty position if no strategic move is available.

2. **`get_all_empty_moves` function**:
   - Uses numpy to find all positions where the board is empty (0).

3. **`check_win` function**:
   - Checks all possible winning lines in 3D Tic Tac Toe:
     - Rows, columns, and diagonals in each of the 3 layers (z=0, z=1, z=2).
     - Vertical lines (through z-axis), horizontal lines (through x or y-axis).
     - Space diagonals (4 main diagonals connecting opposite corners).
     - Face diagonals (12 diagonals on each face of the cube).

This implementation ensures the AI will always win if possible, block the opponent if they are about to win, and otherwise play strategically by targeting the center and corners. If no strategic move is available, it defaults to a random empty position.
