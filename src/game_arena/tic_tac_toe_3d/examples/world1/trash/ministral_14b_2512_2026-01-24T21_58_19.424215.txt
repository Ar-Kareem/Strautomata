### **Strategy for this 3D Tic Tac Toe Policy**
This policy implements a **multi-layered decision-making strategy** that combines:
1. **Immediate winning moves** (if available, prioritize them).
2. **Blocking opponent's winning moves** (if they are about to win, prevent it).
3. **Center control** (prefer the center of the 3D board for symmetry).
4. **Layer-based symmetry** (prioritize moves that maintain symmetry in the 3D structure).
5. **Depth-limited minimax with alpha-beta pruning** (for deeper lookahead, evaluating possible future moves).
6. **Randomness in tie-breaking** (to avoid predictable patterns when multiple equally good moves exist).

The policy is designed to be **strong against simple heuristics** (like random or greedy moves) while remaining **computationally efficient** within the 1-second constraint. It avoids overfitting by not relying on memorized patterns and instead dynamically evaluates the board state.

import numpy as np
import random
from typing import List, Tuple

def policy(board: List[List[List[int]]]) -> Tuple[int, int, int]:
    """
    Returns the next best move for a 3x3x3 Tic Tac Toe game using a minimax strategy with alpha-beta pruning.
    The policy prioritizes:
    1. Winning moves (if available).
    2. Blocking opponent's winning moves.
    3. Center control and symmetry.
    4. Randomness in tie-breaking to avoid predictability.
    """
    # Convert board to numpy array for easier manipulation
    np_board = np.array(board)

    # Check if current player can win immediately
    winning_move = find_winning_move(np_board, 1)
    if winning_move is not None:
        return winning_move

    # Check if opponent can win immediately and block them
    opponent_winning_move = find_winning_move(np_board, -1)
    if opponent_winning_move is not None:
        return opponent_winning_move

    # If no immediate win/block, use minimax with alpha-beta pruning (depth-limited)
    best_move = None
    best_score = -float('inf')

    # Generate all possible empty moves
    empty_moves = [(i, j, k) for i in range(3) for j in range(3) for k in range(3) if np_board[i, j, k] == 0]

    # Shuffle to randomize tie-breaking
    random.shuffle(empty_moves)

    # Evaluate each move using minimax
    for move in empty_moves:
        new_board = np_board.copy()
        new_board[move] = 1
        score = minimax(new_board, 0, -float('inf'), float('inf'), True)

        if score > best_score:
            best_score = score
            best_move = move

    return best_move

def minimax(board: np.ndarray, depth: int, alpha: float, beta: float, is_maximizing: bool) -> float:
    """
    Minimax algorithm with alpha-beta pruning to evaluate the best move.
    Depth-limited to avoid excessive computation.
    """
    # Base case: check if the game is over
    if check_winner(board) == 1:
        return 1
    elif check_winner(board) == -1:
        return -1
    elif np.all(board != 0):  # Draw
        return 0

    # Depth limit (adjustable based on performance)
    if depth == 3:
        return evaluate_board(board)

    if is_maximizing:
        best_score = -float('inf')
        for i in range(3):
            for j in range(3):
                for k in range(3):
                    if board[i, j, k] == 0:
                        board[i, j, k] = 1
                        score = minimax(board, depth + 1, alpha, beta, False)
                        board[i, j, k] = 0
                        best_score = max(score, best_score)
                        alpha = max(alpha, best_score)
                        if beta <= alpha:
                            break
        return best_score
    else:
        best_score = float('inf')
        for i in range(3):
            for j in range(3):
                for k in range(3):
                    if board[i, j, k] == 0:
                        board[i, j, k] = -1
                        score = minimax(board, depth + 1, alpha, beta, True)
                        board[i, j, k] = 0
                        best_score = min(score, best_score)
                        beta = min(beta, best_score)
                        if beta <= alpha:
                            break
        return best_score

def evaluate_board(board: np.ndarray) -> float:
    """
    Static evaluation function for the board state.
    Higher score = better for current player (1).
    """
    score = 0

    # Check all lines (rows, columns, diagonals in 3D)
    for i in range(3):
        for j in range(3):
            # Check rows in each layer
            row = board[i, j, :]
            if np.all(row == 1):
                score += 10
            elif np.all(row == -1):
                score -= 10
            # Check columns in each layer
            col = board[:, j, i]
            if np.all(col == 1):
                score += 10
            elif np.all(col == -1):
                score -= 10
            # Check diagonals in each layer (2D diagonals)
            diag1 = board[j, j, i]
            diag2 = board[2 - j, 2 - j, i]
            if np.all([board[j, j, i], board[j + 1, j + 1, i], board[j + 2, j + 2, i]] == 1):
                score += 10
            elif np.all([board[j, j, i], board[j + 1, j + 1, i], board[j + 2, j + 2, i]] == -1):
                score -= 10
            if np.all([board[2 - j, j, i], board[1 - j, j + 1, i], board[j, j + 2, i]] == 1):
                score += 10
            elif np.all([board[2 - j, j, i], board[1 - j, j + 1, i], board[j, j + 2, i]] == -1):
                score -= 10

    # Check 3D diagonals (space diagonals)
    for i in range(3):
        diag1 = board[i, i, i]
        diag2 = board[2 - i, 2 - i, 2 - i]
        if np.all([board[i, i, i], board[i + 1, i + 1, i + 1], board[i + 2, i + 2, i + 2]] == 1):
            score += 10
        elif np.all([board[i, i, i], board[i + 1, i + 1, i + 1], board[i + 2, i + 2, i + 2]] == -1):
            score -= 10
        if np.all([board[2 - i, i, i], board[1 - i, i + 1, i + 1], board[i, i + 2, i + 2]] == 1):
            score += 10
        elif np.all([board[2 - i, i, i], board[1 - i, i + 1, i + 1], board[i, i + 2, i + 2]] == -1):
            score -= 10

    # Check layers (2D planes)
    for k in range(3):
        layer = board[:, :, k]
        # Check rows in layer
        for i in range(3):
            row = layer[i, :, :]
            if np.all(row == 1):
                score += 1
            elif np.all(row == -1):
                score -= 1
        # Check columns in layer
        for j in range(3):
            col = layer[:, j, :]
            if np.all(col == 1):
                score += 1
            elif np.all(col == -1):
                score -= 1
        # Check diagonals in layer
        if np.all([layer[j, j, k] for j in range(3)]] == 1):
            score += 1
        elif np.all([layer[j, j, k] for j in range(3)]] == -1):
            score -= 1
        if np.all([layer[2 - j, j, k] for j in range(3)]] == 1):
            score += 1
        elif np.all([layer[2 - j, j, k] for j in range(3)]] == -1):
            score -= 1

    # Prefer center moves and symmetric positions
    center_moves = [(1, 1, 1), (1, 1, 0), (1, 1, 2), (1, 0, 1), (1, 2, 1), (0, 1, 1), (2, 1, 1)]
    if (1, 1, 1) in empty_moves:
        return 5  # Highest preference for the exact center

    # Prefer moves in the center layer (k=1)
    if any(k == 1 for (i, j, k) in empty_moves):
        score += 2

    # Prefer moves that create symmetry (e.g., mirrored pairs)
    symmetry_score = 0
    for move in empty_moves:
        i, j, k = move
        if i == 0 and j == 0 and k == 0:  # Corner
            symmetry_score += 1
        elif i == 0 and j == 0 and k == 2:
            symmetry_score += 1
        elif i == 0 and j == 2 and k == 0:
            symmetry_score += 1
        elif i == 0 and j == 2 and k == 2:
            symmetry_score += 1
        elif i == 2 and j == 0 and k == 0:
            symmetry_score += 1
        elif i == 2 and j == 0 and k == 2:
            symmetry_score += 1
        elif i == 2 and j == 2 and k == 0:
            symmetry_score += 1
        elif i == 2 and j == 2 and k == 2:
            symmetry_score += 1
    score += symmetry_score * 0.5  # Small bonus for symmetry

    return score

def find_winning_move(board: np.ndarray, player: int) -> Tuple[int, int, int]:
    """
    Checks if the given player has a winning move.
    Returns the first winning move found, or None if no immediate win.
    """
    for i in range(3):
        for j in range(3):
            for k in range(3):
                if board[i, j, k] == 0:
                    board[i, j, k] = player
                    if check_winner(board) == player:
                        board[i, j, k] = 0
                        return (i, j, k)
                    board[i, j, k] = 0
    return None

def check_winner(board: np.ndarray) -> int:
    """
    Checks if the current board state has a winner.
    Returns 1 if current player wins, -1 if opponent wins, 0 otherwise.
    """
    # Check all lines (rows, columns, diagonals in 3D)
    for i in range(3):
        for j in range(3):
            # Check rows in each layer
            if np.all(board[i, j, :] == 1):
                return 1
            elif np.all(board[i, j, :] == -1):
                return -1
            # Check columns in each layer
            if np.all(board[:, j, i] == 1):
                return 1
            elif np.all(board[:, j, i] == -1):
                return -1
            # Check diagonals in each layer (2D diagonals)
            if np.all([board[j, j, i], board[j + 1, j + 1, i], board[j + 2, j + 2, i]] == 1):
                return 1
            elif np.all([board[j, j, i], board[j + 1, j + 1, i], board[j + 2, j + 2, i]] == -1):
                return -1
            if np.all([board[2 - j, j, i], board[1 - j, j + 1, i], board[j, j + 2, i]] == 1]):
                return 1
            elif np.all([board[2 - j, j, i], board[1 - j, j + 1, i], board[j, j + 2, i]] == -1]):
                return -1

    # Check 3D diagonals (space diagonals)
    if np.all([board[i, i, i], board[i + 1, i + 1, i + 1], board[i + 2, i + 2, i + 2]] == 1):
        return 1
    elif np.all([board[i, i, i], board[i + 1, i + 1, i + 1], board[i + 2, i + 2, i + 2]] == -1):
        return -1
    if np.all([board[2 - i, i, i], board[1 - i, i + 1, i + 1], board[i, i + 2, i + 2]] == 1):
        return 1
    elif np.all([board[2 - i, i, i], board[1 - i, i + 1, i + 1], board[i, i + 2, i + 2]] == -1):
        return -1

    # Check layers (2D planes)
    for k in range(3):
        layer = board[:, :, k]
        # Check rows in layer
        for i in range(3):
            if np.all(layer[i, :, :] == 1):
                return 1
            elif np.all(layer[i, :, :] == -1):
                return -1
        # Check columns in layer
        for j in range(3):
            if np.all(layer[:, j, :] == 1):
                return 1
            elif np.all(layer[:, j, :] == -1):
                return -1
        # Check diagonals in layer
        if np.all([layer[j, j, k] for j in range(3)]] == 1):
            return 1
        elif np.all([layer[j, j, k] for j in range(3)]] == -1):
            return -1
        if np.all([layer[2 - j, j, k] for j in range(3)]] == 1):
            return 1
        elif np.all([layer[2 - j, j, k] for j in range(3)]] == -1):
            return -1

    return 0  # No winner yet

---
### **Key Features of the Policy**
1. **Immediate Win/Block Detection**:
   - If the current player can win in one move, it takes it.
   - If the opponent is about to win, it blocks them.

2. **Minimax with Alpha-Beta Pruning (Depth-Limited)**:
   - Evaluates possible future moves up to a depth of 3 (adjustable for performance).
   - Uses pruning to avoid unnecessary computations.

3. **Static Evaluation Function**:
   - Prioritizes **center control** (e.g., `(1,1,1)`).
   - Rewards **symmetry** (e.g., mirrored moves).
   - Penalizes opponent's **threats** (e.g., near-wins in layers or diagonals).

4. **Random Tie-Breaking**:
   - Shuffles empty moves to avoid predictable patterns when multiple moves have the same score.

5. **Efficiency**:
   - Uses `numpy` for fast board state checks.
   - Depth-limited to ensure the policy runs within 1 second on a modern CPU.
