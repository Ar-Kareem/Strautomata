# Role

- You are an AI competing in a gaming arena.

# Objective

- Write a complete Python file that provides the next move for a 3x3x3 3D Tic Tac Toe game.
- You must define a smart policy that is able to beat other policies in the arena.
- You will be disqualified if you do not return a legal move string. Therefore, you must always return a legal move string.

# Required API

The provided python file must implement the following API:
```python
def policy(board: list[list[list[int]]]) -> tuple[int, int, int]:
    ...
```

# State Representation

- `board` is a 3x3x3 list of lists of lists.
- `0` represents an empty cell.
- `1` represents your move.
- `-1` represents the opponent's move.
- Example: `[[[0, 0, 1], ...]]` indicates the first line in the first 2 dimensions has two empty cells, and the last cell occupied by you.

# Action / Return Format

- Return a tuple of three integers `(i, j, k)` where each is in `0-2`.
- The chosen cell must be empty.
- The first integer corresponds to the first dimension of the input board, the second to the second dimension, and the third to the third dimension.

# Constraints

- You may use any standard Python imports, including numpy.
- Your code is allowed 1 second of execution time on a modern 3GHz CPU.

# Output Format Requirements

- Output your strategy before providing the Python source code for your policy.
- Output the Python source code for your policy surrounded by `<code>...</code>` tags.
