# Role

- You are an AI competing in a gaming arena.

# Objective

- Write a complete Python file that provides the next move for a Stanford GameMaster game "minorities".
- You must define a smart policy that is able to beat other policies in the arena.
- You will be disqualified if you do not return a legal move string. Therefore, you must always return a legal move string.

# Required API

The provided python file must implement the following API:
```python
def policy(state: list[list[object]], role: str) -> str:
    ...
```

# State Representation

- `state` is the raw Stanford GameMaster list of currently true propositions.
- Each proposition is a term-like Python list, for example `["cell", "1", "1", "white"]`.
- `role` is the role whose move your policy must choose in the current state.
- You are not given the legal-action list during normal play.

# Action / Return Format

- Return exactly one legal action string in Stanford syntax.
- Example action syntax: `place(a,5)`.
- If the state contains a control fact, your returned action must be legal for that role.

# Detailed Game Reference

You are preparing to act as a player for the Stanford GameMaster game "minorities".

Roles in the game
- All roles in the game: red, blue

What you will receive at runtime
- Inputs: `state`, `role`
- `state` is the complete list of currently true Stanford propositions for the current position.
- `role` is the role whose move you must choose for in the current position.
- Each proposition is encoded as a term-like JSON/Python list such as `["line_count", "a", "red", "0"]`.
- If a proposition is absent from `state`, treat it as false.
- In multi-player turn-based games, a fact such as `["control", "white"]` usually matches the current `role` input.

What you must output
- Output exactly one legal action in Stanford syntax for the provided `role`, for example `place(a,5)`.
- You will NOT be given the legal-action list at runtime.
- You must infer legality and strategy from the state format, game description, and the examples below.
- Optimize for winning and high final score.

Game overview
- Description: Minorities is played on a made of hexagonal cells.  The board is initially empty, except for six unusable cells. The first player places a stone on any unoccupied cell, then players take turns placing pieces on empty cells.  A majority of stones in a line wins that line.  A majority of parallel lines in a direction wins that direction.  A majority of directions wins the game.  The value for any state is the number of lines in which it has a majority until it achieves majorities in two directions, at which point the value is 100.
- The sampled states below come from one deterministic legal trajectory.
- For each sampled state, the displayed action is one legal action from that state, chosen to expose action patterns that actually occur in the game.
- The displayed actions are examples of legal moves, not guaranteed to be optimal moves or the exact moves used to generate later sampled states.
- The policy should work for any role in the game, not just one fixed role.
