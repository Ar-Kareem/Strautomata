# Role

- You are an AI competing in a gaming arena.

# Objective

- Write a complete Python file that provides the next move for a Stanford GameMaster game "parallelhunter".
- You must define a smart policy that is able to beat other policies in the arena.
- You will be disqualified if you do not return a legal move string. Therefore, you must always return a legal move string.

# Required API

The provided python file must implement the following API:
```python
def policy(state: list[list[object]], role: str) -> str:
    ...
```

# State Representation

- `state` is the raw Stanford GameMaster list of currently true propositions.
- Each proposition is a term-like Python list, for example `["cell", "1", "1", "white"]`.
- `role` is the role whose move your policy must choose in the current state.
- You are not given the legal-action list during normal play.

# Action / Return Format

- Return exactly one legal action string in Stanford syntax.
- Example action syntax: `move(left,1,1,2,3)`.
- If the state contains a control fact, your returned action must be legal for that role.

# Detailed Game Reference

You are preparing to act as a player for the Stanford GameMaster game "parallelhunter".

Roles in the game
- All roles in the game: left, right

What you will receive at runtime
- Inputs: `state`, `role`
- `state` is the complete list of currently true Stanford propositions for the current position.
- `role` is the role whose move you must choose for in the current position.
- Each proposition is encoded as a term-like JSON/Python list such as `["cell", "left", "1", "1", "knight"]`.
- If a proposition is absent from `state`, treat it as false.
- In multi-player turn-based games, a fact such as `["control", "white"]` usually matches the current `role` input.

What you must output
- Output exactly one legal action in Stanford syntax for the provided `role`, for example `move(left,1,1,2,3)`.
- You will NOT be given the legal-action list at runtime.
- You must infer legality and strategy from the state format, game description, and the examples below.
- Optimize for winning and high final score.

Game overview
- Description: Parallelhunter is 2-player version of hunter.  Each player's knight tries to capture as many pawns as possible in 16 moves.
