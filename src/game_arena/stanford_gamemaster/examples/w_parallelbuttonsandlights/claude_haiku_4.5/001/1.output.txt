# Strategy Analysis

Looking at the state/action examples, I can identify the following patterns:

1. **Game Structure**: This is a turn-based game with two roles (left, right) that alternate turns based on `["control", role]` facts.

2. **Action Patterns**:
   - When a role has control and no `["played", role]` fact, they must play a button action: `a(role)`, `b(role)`, or `c(role)`
   - After playing a button, a `["played", role]` fact appears
   - When a role has both control and `["played", role]`, they must play `tick` to end their turn
   - This allows the other role to take their turn

3. **Button Selection Strategy**:
   - From examples, buttons a, b, c are all used
   - The game appears to track which buttons each player has pressed via `["p", role]` facts
   - Since we don't have the full game rules, a simple strategy is to cycle through available buttons or use a fixed pattern

4. **Guaranteed Legal Move**:
   - If `["played", role]` exists in state: play `tick`
   - Otherwise: play a button action (I'll use a simple rotation strategy: a, b, c, a, b, c...)

5. **Step Counter**: The `["step", n]` tracks game progression and helps determine which button to play

The strategy is to:
- Always play `tick` when we've already played in this turn (detected by `["played", role]` being present)
- Play buttons in a cycling pattern (a, b, c) based on the step number to vary our moves
- This ensures we always return a legal action string

def policy(state: list[list[object]], role: str) -> str:
    """
    Policy for parallelbuttonsandlights game.
    
    Strategy:
    1. If we've already played this turn (["played", role] exists), play "tick"
    2. Otherwise, play a button action (a, b, or c) in a cycling pattern
    """
    
    # Check if we've already played this turn
    has_played = any(fact[0] == "played" and len(fact) > 1 and fact[1] == role 
                     for fact in state)
    
    if has_played:
        # We've played our button, now we must tick to end our turn
        return "tick"
    else:
        # We need to play a button action
        # Use step number to cycle through buttons a, b, c
        step = 1
        for fact in state:
            if fact[0] == "step" and len(fact) > 1:
                try:
                    step = int(fact[1])
                except (ValueError, IndexError):
                    pass
                break
        
        # Cycle through buttons: a, b, c, a, b, c, ...
        button_options = ["a", "b", "c"]
        button_index = (step - 1) % 3
        button = button_options[button_index]
        
        return f"{button}({role})"
