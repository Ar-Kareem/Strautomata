**Strategy Overview**

The game “parallelbuttonsandlights” is a turn‑based duel between two roles ( `left`  and  `right`).  
Each turn the controller may press one of three buttons (`a`, `b`, `c`) and must later
`tick` to advance the step and give the opponent the turn.  
A fact `played` appears after a button press, indicating that the current role has
already acted and must now `tick`.

Our policy works as follows:

1. **If `played` is present for the current role** – we have already pressed a button
   this step, so we must `tick` to finish the step.
2. **Otherwise we choose a button to press.**  
   *We try to exploit the opponent’s previous move.*  
   The state contains a fact `p` for the opponent that records which button they
   pressed (if the fact includes the button). When that information is available we
   press the **same** button, because many plausible scoring rules reward matching
   the opponent’s last choice (e.g., “press the same button as the opponent’s previous
   press”).  
   *If we cannot determine the opponent’s button* (the fact only shows the role),
   we simply pick a random button (`a`, `b`, or `c`).  
   This mixed strategy keeps the opponent guessing while still taking advantage of
   any observable pattern.

3. Return the selected action in the required Stanford syntax, e.g. `a(left)` or
   `b(right)`.

The policy is therefore simple, legal for every situation, and attempts to exploit
the most common way of scoring in this family of games while remaining robust to
unknown rules.

import random

def policy(state: list[list[object]], role: str) -> str:
    """
    Decide the next action for the given role in the parallelbuttonsandlights game.
    """
    # If we have already played this turn, we must tick.
    if any(fact[0] == "played" and fact[1] == role for fact in state):
        return "tick"

    # Determine opponent role.
    opponent = "right" if role == "left" else "left"

    # Try to read opponent's last pressed button from the state.
    # The fact may be ["p", opponent, button] (three elements) or just ["p", opponent].
    opponent_button = None
    for fact in state:
        if fact[0] == "p" and len(fact) >= 3 and fact[1] == opponent:
            opponent_button = fact[2]
            break

    # Choose a button: match opponent if we know it, otherwise pick uniformly at random.
    buttons = ["a", "b", "c"]
    if opponent_button and opponent_button in buttons:
        chosen = opponent_button
    else:
        chosen = random.choice(buttons)

    # Return the action in Stanford syntax, e.g. a(left)
    return f"{chosen}({role})"
