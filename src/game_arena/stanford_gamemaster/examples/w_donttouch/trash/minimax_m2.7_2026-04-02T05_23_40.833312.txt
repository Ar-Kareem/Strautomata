**Strategy**

The game “donttouch’’ is a two‑player perfect‑information zero‑sum game.  
* Players take turns marking empty cells of a 4 × 4 board with their own symbol (`x` or `o`).  
* A move is **legal** iff the chosen cell is empty **and** none of its four orthogonal neighbours already contain a mark of the same player.  
* If a player has no legal move (or makes an illegal adjacency), that player loses immediately.

We can therefore treat the position as a game tree where the terminal nodes are
* “no legal moves for the player to move’’ → the opponent wins.

Because the board has only 16 cells, the whole state space can be explored
and solved exactly with a minimax search and memoisation (transposition table).

**State representation**

* Two 16‑bit masks, `x_mask` and `o_mask`, indicate which cells are already occupied by each player.
* The current player (`role`) is passed to the search routine.
* For each cell we pre‑compute the mask of its four orthogonal neighbours; a move to cell `i` is legal for the mover iff `neighbour_mask[i] & own_mask == 0`.

**Search**

`solve(x_mask, o_mask, role)` returns the winner (`'x'` or `'o'`) assuming optimal play from this position:

```
if role has no legal moves:
    winner = opponent          # current player loses
else:
    for each legal move:
        make the move (update the appropriate mask)
        if solve(new_x, new_o, opponent) != opponent:
            winner = role       # current player can force a win
            break
    if no winning move found:
        winner = opponent       # opponent can force a win
```

The results are cached in a dictionary, so each state is evaluated only once.

**Policy**

The exported `policy(state, role)` function:

1. Parses the incoming Stanford facts into the two bit masks and the current role.
2. Generates the list of legal moves (empty cells whose neighbours do not contain the mover’s own marks).
3. Searches for a winning move (one that makes the opponent lose).  
   If such a move exists it is returned; otherwise any legal move is returned.
4. Formats the chosen cell as `mark(row,col)` (1‑indexed) and returns it.

Because the search explores the complete game tree, the policy plays optimally for both roles and will never return an illegal move.

import sys
import functools

# ----------------------------------------------------------------------
# Pre‑compute orthogonal neighbour masks for the 4×4 board (indices 0‑15)
# ----------------------------------------------------------------------
NEIGHBOUR_MASK = [0] * 16
for idx in range(16):
    r, c = divmod(idx, 4)
    mask = 0
    if r > 0:
        mask |= 1 << ((r - 1) * 4 + c)
    if r < 3:
        mask |= 1 << ((r + 1) * 4 + c)
    if c > 0:
        mask |= 1 << (r * 4 + (c - 1))
    if c < 3:
        mask |= 1 << (r * 4 + (c + 1))
    NEIGHBOUR_MASK[idx] = mask

# ------------------------------------------------------------
# Memoised minimax solver (transposition table)
# ------------------------------------------------------------
@memo = {}

def solve(x_mask: int, o_mask: int, role: str) -> str:
    """Return the winning player ('x' or 'o') assuming optimal play from the given position."""
    key = (x_mask, o_mask, role)
    if key in memo:
        return memo[key]

    own_mask = x_mask if role == 'x' else o_mask
    opp_mask = o_mask if role == 'x' else x_mask
    opponent = 'o' if role == 'x' else 'x'

    # All empty cells
    empty = ~(x_mask | o_mask) & 0xFFFF

    # Enumerate legal moves for the current player
    legal = []
    e = empty
    while e:
        lsb = e & -e
        idx = (lsb.bit_length() - 1)
        if (NEIGHBOUR_MASK[idx] & own_mask) == 0:
            legal.append(idx)
        e ^= lsb

    # Terminal condition: no legal move → current player loses
    if not legal:
        memo[key] = opponent
        return opponent

    # Try to find a move that forces the opponent to lose
    for idx in legal:
        if role == 'x':
            new_x = x_mask | (1 << idx)
            new_o = o_mask
        else:
            new_x = x_mask
            new_o = o_mask | (1 << idx)

        if solve(new_x, new_o, opponent) != opponent:
            memo[key] = role
            return role

    # All moves lead to the opponent winning
    memo[key] = opponent
    return opponent

# ------------------------------------------------------------
# Policy interface required by the arena
# ------------------------------------------------------------
def policy(state: list, role: str) -> str:
    """
    Convert the Stanford state representation into bit masks,
    choose the best legal move (or any legal move if none is winning),
    and return the move in Stanford syntax: mark(row,col)
    """
    # Parse the state into masks
    x_mask = 0
    o_mask = 0
    for fact in state:
        if fact[0] == 'cell':
            r = int(fact[1]) - 1
            c = int(fact[2]) - 1
            idx = r * 4 + c
            val = fact[3]
            if val == 'x':
                x_mask |= (1 << idx)
            elif val == 'o':
                o_mask |= (1 << idx)
            # 'b' (blank) → nothing to set

    # Determine legal moves for the current player
    own_mask = x_mask if role == 'x' else o_mask
    empty = ~(x_mask | o_mask) & 0xFFFF
    legal = []
    e = empty
    while e:
        lsb = e & -e
        idx = (lsb.bit_length() - 1)
        if (NEIGHBOUR_MASK[idx] & own_mask) == 0:
            legal.append(idx)
        e ^= lsb

    # If somehow no legal move exists (should not happen in a normal game),
    # fall back to any empty cell; the game will be lost anyway.
    if not legal:
        # pick any empty cell (if any)
        if empty:
            idx = (empty & -empty).bit_length() - 1
        else:
            idx = 0  # board full – arbitrary
        r, c = divmod(idx, 4)
        return f"mark({r + 1},{c + 1})"

    opponent = 'o' if role == 'x' else 'x'

    # Search for a winning move
    best_move = None
    for idx in legal:
        if role == 'x':
            new_x = x_mask | (1 << idx)
            new_o = o_mask
        else:
            new_x = x_mask
            new_o = o_mask | (1 << idx)

        if solve(new_x, new_o, opponent) != opponent:
            best_move = idx
            break

    # If no forced win, pick any legal move (first one)
    if best_move is None:
        best_move = legal[0]

    r, c = divmod(best_move, 4)
    return f"mark({r + 1},{c + 1})"

# ------------------------------------------------------------
# Increase recursion limit for safety (depth ≤ 16)
# ------------------------------------------------------------
sys.setrecursionlimit(10000)

# ------------------------------------------------------------
# Optional: quick self‑test when run as a script
# ------------------------------------------------------------
if __name__ == "__main__":

        ["cell", "2", "1", "b"], ["cell", "2", "2", "b"],
        ["cell", "2", "3", "b"], ["cell", "2", "4", "b"],
        ["cell", "3", "1", "b"], ["cell", "3", "2", "b"],
        ["cell", "3", "3", "b"], ["cell", "3", "4", "b"],
        ["cell", "4", "1", "b"], ["cell", "4", "2", "b"],

    ]
    print(policy(example_state, "x"))  # Expected: a legal move, e.g., mark(1,1)
