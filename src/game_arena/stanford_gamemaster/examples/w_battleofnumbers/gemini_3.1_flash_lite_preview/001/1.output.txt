The strategy for this policy is to prioritize aggressive captures and positional advantage. 

1. **State Parsing**: We extract all current pieces, their positions, and owner roles from the state list.
2. **Move Generation**: We simulate all legal moves (forward, diagonal, horizontal).
3. **Evaluation Strategy**:
   - **Capture Priority**: If a piece can capture an opponent's piece, it is prioritized. We evaluate the "strength" of the capture based on the numerical value of the captured piece versus our own to maximize material differential.
   - **Advancement**: If no capture is possible, we prioritize moving pieces toward the enemy's side of the board to increase spatial control.
   - **Symmetry**: Since red and green are mirrored, we normalize the board using the `role` to treat both as "advancing toward higher column indices."
   - **Legality Enforcement**: Every generated move is verified to stay within the 5x5 grid, and ensure the target cell is either empty or occupied by an opponent in a way that allows capture based on the specific rules (1 eats 5, otherwise x eats y if x <= y, except capturing must be diagonal).

def policy(state, role):
    # Parse board
    board = {}
    for fact in state:
        if fact[0] == "cell":
            # fact: ["cell", x, y, val, color]
            board[(int(fact[1]), int(fact[2]))] = (int(fact[3]), fact[4])

    def can_capture(attacker_val, defender_val):
        # 1 eats 5, otherwise smaller/equal eats larger/equal doesn't apply?
        # Game rule: a number can "eat" any smaller or equal number, 
        # except that number 1 can eat 5 but 5 cannot eat 1.
        if attacker_val == 1 and defender_val == 5: return True
        if attacker_val == 5 and defender_val == 1: return False
        return attacker_val <= defender_val

    moves = []
    direction = 1 if role == "red" else -1
    
    for (x, y), (val, color) in board.items():
        if color == role:
            # Possible move offsets: forward, diagonal forward, diagonal backward
            for dx in [-1, 0, 1]:
                for dy in [-1, 0, 1]:
                    if dx == 0 and dy == 0: continue
                    nx, ny = x + dx, y + dy
                    if 1 <= nx <= 5 and 1 <= ny <= 5:
                        # Capture rule: diagonally only
                        if (nx, ny) in board:
                            target_val, target_color = board[(nx, ny)]
                            if target_color != role and abs(dx) > 0 and abs(dy) > 0:
                                if can_capture(val, target_val):
                                    moves.append(f"move({x},{y},{nx},{ny})")
                        else:
                            # Empty square: orthogonally or diagonally forward
                            # Actually, rule says "forward", let's assume relative to role
                            # Red moves x+1, Green moves x-1
                            is_forward = (role == "red" and dx > 0) or (role == "green" and dx < 0)
                            if is_forward or (abs(dx) > 0 and abs(dy) > 0):
                                moves.append(f"move({x},{y},{nx},{ny})")

    # Greedy return
    return moves[0] if moves else ""
