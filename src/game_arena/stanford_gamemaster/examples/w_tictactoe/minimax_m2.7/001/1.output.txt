**Strategy**

We treat the 3 × 3 board as a list of nine cells.  
From the supplied `state` we rebuild the board, keeping the pieces of the two
players (`'x'` and `'o'`) and empty cells (`' '`).  
The goal is to return a move that is optimal for the current player (`role`).

Because the game tree is tiny (at most 9 moves) we can explore the whole
game with a classic minimax algorithm:

* a win for the player whose turn we are analyzing scores **+10**,
* a win for the opponent scores **‑10**,
* a completely filled board (draw) scores **0**.

The algorithm recursively alternates between the maximizing player and the
opponent, pruning impossible branches, and finally selects the move that
produces the maximal minimax score.  If several moves are equally good we
pick the first one encountered.

This gives a *perfect‑play* policy: against any sub‑optimal opponent it will
either win or force a draw, guaranteeing the highest possible score.

**Python implementation**

```python
def policy(state, role):
    """
    Returns a legal move for the given role in the current Tic‑Tac‑Toe state.
    The move is chosen by a full‑depth minimax search, i.e. optimal play.
    """
    # ------------------------------------------------------------------
    # 1. Build a 9‑cell board from the state representation.
    #    board indices: 0..8 correspond to (row, col) = (i//3+1, i%3+1)
    # ------------------------------------------------------------------
    board = [' '] * 9  # ' ' means empty, 'x' or 'o' are filled
    for prop in state:
        if prop[0] == 'cell':
            r = int(prop[1])      # row 1..3
            c = int(prop[2])      # col 1..3
            val = prop[3]         # 'x', 'o' or 'b' (blank)
            idx = (r - 1) * 3 + (c - 1)
            if val == 'x':
                board[idx] = 'x'
            elif val == 'o':
                board[idx] = 'o'
            else:  # 'b' or any other blank marker
                board[idx] = ' '

    # Current player is exactly the supplied role
    player = role
    opponent = 'o' if player == 'x' else 'x'

    # ------------------------------------------------------------------
    # 2. Helper: check for a winner.
    # ------------------------------------------------------------------
    WIN_PATTERNS = [(0, 1, 2), (3, 4, 5), (6, 7, 8),
                    (0, 3, 6), (1, 4, 7), (2, 5, 8),
                    (0, 4, 8), (2, 4, 6)]

    def winner(b):
        for a, b_, c in WIN_PATTERNS:
            if b[a] == b_ == c and b[a] != ' ':
                return b[a]
        return None

    # ------------------------------------------------------------------
    # 3. Minimax implementation.
    # ------------------------------------------------------------------
    from math import inf

    def empty_cells(b):
        return [i for i, v in enumerate(b) if v == ' ']

    def minimax(b, is_maximizing):
        """Return the minimax score of board `b` from the perspective of `player`."""
        w = winner(b)
        if w == player:
            return 10
        if w == opponent:
            return -10
        empties = empty_cells(b)
        if not empties:          # draw
            return 0

        if is_maximizing:
            best = -inf
            for idx in empties:
                b[idx] = player
                best = max(best, minimax(b, False))
                b[idx] = ' '
                if best == 10:   # early cutoff – cannot do better
                    return best
            return best
        else:  # opponent's turn (minimizing)
            best = inf
            for idx in empties:
                b[idx] = opponent
                best = min(best, minimax(b, True))
                b[idx] = ' '
                if best == -10: # early cutoff – opponent cannot do better
                    return best
            return best

    # ------------------------------------------------------------------
    # 4. Choose the best move for the current player.
    # ------------------------------------------------------------------
    best_score = -inf
    best_move = None
    for idx in empty_cells(board):
        board[idx] = player
        score = minimax(board, False)   # opponent's turn after this move
        board[idx] = ' '
        if score > best_score:
            best_score = score
            best_move = idx

    # In the (theoretical) case of no legal move, fall back to the first empty.
    if best_move is None:
        best_move = empty_cells(board)[0]

    row = best_move // 3 + 1
    col = best_move % 3 + 1
    return f"mark({row},{col})"
```
