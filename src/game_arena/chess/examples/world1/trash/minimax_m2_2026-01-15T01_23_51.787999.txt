To create a strong chess policy, I will implement a greedy material-focused approach that prioritizes moves capturing high-value pieces, with castling given a moderate score for king safety. If no captures are available, the policy will fall back to castling or any other legal move. This strategy balances immediate gains with king safety while ensuring all moves are legal.

The policy works by evaluating each legal move to determine if it captures a piece (using regex to parse the move string for the target square) and assigning a score based on the captured piece's value. Castling moves receive a fixed score of 5, while non-capturing moves score 0. The move with the highest score is selected. This approach efficiently leverages piece values while adhering to the 1-second execution constraint.

```python
import re

piece_values = {'P': 1, 'N': 3, 'B': 3, 'R': 5, 'Q': 9, 'K': 10}

best_move = None
best_score = -1

for move in legal_moves:
    # Check for castling moves
    if move == 'O-O' or move == 'O-O-O':
        score = 5  # Castling score for king safety
    else:
        # Find all squares in the move string using regex
        pattern = re.compile(r'[a-h][1-8]')
        squares = pattern.findall(move)
        if squares:
            to_square = squares[-1]  # Last square is the target
            # Check if there's a piece on the target square (capture)
            if to_square in pieces:
                captured_piece = pieces[to_square]
                captured_type = captured_piece[1]  # Piece type is second character
                score = piece_values.get(captured_type, 0)
            else:
                score = 0  # No capture
        else:
            score = 0  # No valid square found
    
    # Update best move if current score is higher
    if score > best_score:
        best_score = score
        best_move = move

# Fallback: choose first legal move if no move found
if best_move is None:
    best_move = legal_moves[0]

return best_move
```
