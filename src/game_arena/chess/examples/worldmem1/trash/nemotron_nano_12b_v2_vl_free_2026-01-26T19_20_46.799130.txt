To address the challenge of selecting the best move in a chess game, we implement a policy that evaluates each move based on a set of well-defined heuristics. These heuristics are designed to simulate a human-like decision-making process, focusing on the most impactful game events: checkmate, promotions, and captures of high-value pieces. The goal is to make decisions that are strategically sound and can compete effectively within the time constraints of the environment.

---

### ✅ **Key Evaluation Priorities (in order of importance)**

1. **Queen Promotions**  
   Promoting a pawn to a queen is the most powerful long-term move. Queen promotions are prioritized over other promotions due to their unmatched mobility and power in both attack and defense.

2. **Captures of High-Value Pieces**  
   Capturing opponent's pieces of high value (Queen > Rook > Bishop/Knight) is next in priority. This reflects the relative material advantage in chess.

3. **Castling**  
   Castling is a crucial move for improving king safety and should be prioritized if available, especially early in the game or when the king is under threat.

4. **Other Legal Moves**  
   If no promotions, captures, or castling are available, we default to the first legal move in the list. This is a fallback to ensure we always return a legal move.

---

### 🧠 **Strategy Explanation**

- **Queen Promotions** are the best long-term decision, so we always prioritize them.
- **Capturing high-value pieces** (especially queens and rooks) can quickly shift the balance of the game.
- **Castling** is included to protect the king and initiate development.
- If none of the above are present, we return the first legal move to ensure the function always returns a valid move.

### 🧾 **Python Implementation**

```python
PIECE_VALUES_PRIO = {'Q': 10, 'R': 8, 'B': 3, 'N': 3, 'P': 1}

def policy(pieces, to_play, legal_moves, memory):
    # Check for queen promotions first
    queen_promotions = [move for move in legal_moves if move.endswith('=Q')]
    if queen_promotions:
        return (queen_promotions[0], {})

    # Try to capture opponent's queen first
    queen_captures = []
    for move in legal_moves:
        if 'x' in move:
            dest_sq = move.split('x', 1)[-1]
            if len(dest_sq) != 2:
                continue
            captured = pieces.get(dest_sq, '')
            if captured and captured[1] == 'Q':
                return (move, {})

    # Try castle kingside or queenside
    castling = ['O-O', 'O-O-O'] if to_play == 'white' else ['o-o', 'o-o-o']
    castling_moves = [m for m in legal_moves if m in castling]
    if castling_moves:
        return (castling_moves[0], {})

    # If none of the above, pick the first move
    if legal_moves:
        return (legal_moves[0], memory)
    else:
        return ('', memory)
```
