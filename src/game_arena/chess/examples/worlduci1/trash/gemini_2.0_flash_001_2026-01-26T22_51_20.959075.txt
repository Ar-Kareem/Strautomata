The strategy for this policy is to prioritize moves based on the following criteria:

1.  **Checkmate:** If a move results in checkmate, immediately return that move.
2.  **Captures:** If a move captures an opponent's piece, evaluate the relative value of the captured piece (Q > R > B > N > P). Prioritize captures that result in a material advantage.  Also prioritize captures of pieces attacking the King.
3.  **Checks:** If a move results in a check, evaluate the position. Checks can disrupt the opponent's plans and potentially lead to a tactical advantage.
4.  **King Safety:** Prioritize moves that improve the king's safety, such as moving the king away from threats, castling, or developing pieces to defend the king.
5.  **Piece Development:** Develop pieces to active squares where they control important squares and contribute to the overall strategy.
6.  **Pawn Structure:** Consider the pawn structure and make moves that improve it, such as creating pawn chains or avoiding isolated pawns.
7.  **Random Move:** If no other criteria apply, select a random legal move to ensure the policy always returns a valid move.

This strategy aims to balance tactical opportunities with long-term strategic considerations, providing a strong and reliable policy for playing chess.

  """Assigns a numerical value to a chess piece type."""
  if piece_type == 'Q':
    return 9
  elif piece_type == 'R':
    return 5
  elif piece_type == 'B':
    return 3
  elif piece_type == 'N':
    return 3
  elif piece_type == 'P':
    return 1

        board.turn = chess.WHITE

    legal_moves = [move.uci() for move in board.legal_moves]
