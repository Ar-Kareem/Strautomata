To solve this problem, we need to create a policy function that selects the best possible move for a given chess board state. The function must prioritize checkmate moves if available, otherwise, it should select moves based on material gain and other positional factors.

### Approach
1. **Board Representation**: Convert the given dictionary of pieces into a chess board using the `chess` library. This library helps in generating legal moves and evaluating board positions efficiently.
2. **Check for Checkmate Moves**: If any move leads to an immediate checkmate, it should be selected immediately as checkmate moves are the highest priority.
3. **Move Evaluation**: If no checkmate moves are available, evaluate each legal move based on material gain. The evaluation function calculates the difference in material value between the current player and the opponent to prioritize moves that result in a more favorable material balance.

### Solution Code
```python
import chess

def evaluate(board, color):
    score = 0
    for square in chess.SQUARES:
        piece = board.piece_at(square)
        if piece:
            if piece.color == color:
                score += chess.PIECE_VALUES[piece.piece]
            else:
                score -= chess.PIECE_VALUES[piece.piece]
    return score

def policy(pieces: dict[str, str], to_play: str) -> str:
    board = chess.Board()
    
    # Populate the board with the given pieces
    for square_str, piece_code in pieces.items():
        color_char = piece_code[0]
        piece_type = piece_code[1]
        
        color = chess.WHITE if color_char == 'w' else chess.BLACK
        
        if piece_type == 'K':
            piece_piece = chess.KING
        elif piece_type == 'Q':
            piece_piece = chess.QUEEN
        elif piece_type == 'R':
            piece_piece = chess.ROOK
        elif piece_type == 'B':
            piece_piece = chess.BISHOP
        elif piece_type == 'N':
            piece_piece = chess.KNIGHT
        elif piece_type == 'P':
            piece_piece = chess.PAWN
        else:
            raise ValueError("Invalid piece type")
        
        square = chess.parse_square(square_str)
        board.set_piece_at(square, chess.Piece(piece_piece, color))
    
    # Generate all legal moves for the current player
    current_color = chess.WHITE if to_play == 'white' else chess.BLACK
    moves = list(board.legal_moves)
    
    # Check for checkmate moves
    for move in moves:
        temp_board = board.copy()
        temp_board.push(move)
        if temp_board.is_checkmate():
            return move.uci()
    
    # Evaluate other moves based on material balance
    best_move = None
    best_score = -float('inf')
    
    for move in moves:
        temp = board.copy()
        temp.push(move)
        score = evaluate(temp, current_color)
        
        if score > best_score:
            best_score = score
            best_move = move
    
    return best_move.uci()
```

### Explanation
1. **Board Representation**: The input dictionary representing the board is converted into a `chess.Board` object. Each piece is parsed and placed on the board according to its position and type.
2. **Checkmate Moves Check**: The code iterates through all legal moves generated by `chess.Board.legal_moves`. For each move, a temporary board is created and the move is played. If the resulting board state is a checkmate, the move is returned immediately.
3. **Move Evaluation**: If no checkmate moves are found, each move is evaluated based on the material balance. The evaluation function calculates the difference in material value between the current player and the opponent. The move that results in the highest material advantage is selected as the best move.

This approach ensures that the code efficiently prioritizes checkmate moves and uses a material-based evaluation to select the best move when checkmates are not possible, within the given execution time constraints.
