**Strategy Overview**

The engine is a compact, alpha‑beta based searcher that follows the classic “material + piece‑square tables” evaluation.  
Key design decisions are:

* **Board representation** – a simple 64‑element list where each entry holds a piece code (`'wP' … 'bK'`) or `None`.  
* **Move generation** – pseudo‑legal moves are generated for every piece; after the move is made the king‑in‑check test filters out illegal moves.  
* **Search** – iterative deepening with a fixed time budget (≈ 0.9 s). The core is a negamax alpha‑beta routine with quiescence search that only explores captures and promotions after the nominal depth is exhausted.  
* **Evaluation** – material counts plus piece‑square tables (taken from the chess programming wiki). No other heuristics are used, keeping the code short and fast.  
* **Transposition table** – a simple `dict` keyed by a Zobrist‑style hash (XOR of random 64‑bit numbers for each piece on each square). It stores the best move and the score, which is reused for move ordering.  
* **Move ordering** – best move from the TT is tried first, then captures (MVV‑LVA), then promotions, then quiet moves. This gives a noticeable cut‑off improvement.  
* **Special moves** – castling, en‑passant and promotions are all implemented. Castling rights are derived from the initial position and updated whenever a king or rook moves.  

The whole engine fits in a single Python file, runs comfortably within the 1 s limit for a few plies of search, and is strong enough to beat random opponents and many simplistic bots.

```python
# ------------------------------------------------------------
#  Minimalistic Chess Engine for the "Chess Arena" challenge
# ------------------------------------------------------------
import random
import time
from math import inf

# ------------------------------------------------------------
# 1. Global constants and helpers
# ------------------------------------------------------------

# Square mapping: a1 -> 0, b1 -> 1, …, h8 -> 63
SQUARE_TO_IDX = {f + r: i for i, (f, r) in enumerate(
    [c + str(n) for n in range(1, 9) for c in "abcdefgh")]}
IDX_TO_SQUARE = {v: k for k, v in SQUARE_TO_IDX.items()}

# Piece values (material)
PIECE_VALUE = {
    'P': 100, 'N': 300, 'B': 300, 'R': 500, 'Q': 900, 'K': 0
}

# Piece‑square tables (white perspective, mirrored for black)
# Values are taken from the chess programming wiki (simplified)

     10, 10, 20, 30, 30, 20, 10, 10,
      5,  5, 10, 25, 25, 10,  5,  5,
      0,  0,  0, 20, 20,  0,  0,  0,
      5, -5,-10,  0,  0,-10, -5,  5,
      5, 10, 10,-20,-20, 10, 10,  5,
      0,  0,  0,  0,  0,  0,  0,  0
]

KNIGHT_TABLE = [
    -50,-40,-30,-30,-30,-30,-40,-50,
    -40,-20,  0,  0,  0,  0,-20,-40,
    -30,  0, 10, 15, 15, 10,  0,-30,
    -30,  5, 15, 20, 20, 15,  5,-30,
    -30,  0, 15, 20, 20, 15,  0,-30,
    -30,  5, 10, 15, 15, 10,  5,-30,
    -40,-20,  0,  5,  5,  0,-20,-40,
    -50,-40,-30,-30,-30,-30,-40,-50

BISHOP_TABLE = [
    -20,-10,-10,-10,-10,-10,-10,-20,
    -10,  0,  0,  0,  0,  0,  0,-10,
    -10,  0,  5, 10, 10,  5,  0,-10,
    -10,  5,  5, 10, 10,  5,  5,-10,
    -10,  0, 10, 10, 10, 10,  0,-10,
    -10, 10, 10, 10, 10, 10, 10,-10,
    -10,  5,  0,  0,  0,  0,  5,-10,
    -20,-10,-10,-10,-10,-10,-10,-20
]

ROOK_TABLE = [
      0,  0,  0,  0,  0,  0,  0,  0,
      5, 10, 10, 10, 10, 10, 10,  5,
     -5,  0,  0,  0,  0,  0,  0, -5,
     -5,  0,  0,  0,  0,  0,  0, -5,
     -5,  0,  0,  0,  0,  0,  0, -5,
     -5,  0,  0,  0,  0,  0,  0, -5,
     -5,  0,  0,  0,  0,  0,  0, -5,
      0,  0,  0,  5,  5,  0,  0,  0
]

QUEEN_TABLE = [
    -20,-10,-10, -5, -5,-10,-10,-20,
    -10,  0,  0,  0,  0,  0,  0,-10,
    -10,  0,  5,  5,  5,  5,  0,-10,
     -5,  0,  5,  5,  5,  5,  0, -5,
      0,  0,  5,  5,  5,  5,  0, -5,
    -10,  5,  5,  5,  5,  5,  0,-10,
    -10,  0,  5,  0,  0,  0,  0,-10,
    -20,-10,-10, -5, -5,-10,-10,-20
]

KING_TABLE = [
    -30,-40,-40,-50,-50,-40,-40,-30,
    -30,-40,-40,-50,-50,-40,-40,-30,
    -30,-40,-40,-50,-50,-40,-40,-30,
    -30,-40,-40,-50,-50,-40,-40,-30,
    -20,-30,-30,-40,-40,-30,-30,-20,
    -10,-20,-20,-20,-20,-20,-20,-10,
     20, 20,  0,  0,  0,  0, 20, 20,
     20, 30, 10,  0,  0, 10, 30, 20
]

# Attack directions for sliding pieces
SLIDE_DIRS = {
    'B': [-9, -7, 7, 9],
    'R': [-8, -1, 1, 8],
    'Q': [-9, -7, 7, 9, -8, -1, 1, 8]
}

# Knight and king jumps
KNIGHT_JUMPS = [-17, -15, -10, -6, 6, 10, 15, 17]
KING_JUMPS = [-9, -8, -7, -1, 1, 7, 8, 9]

# Castling rights constants
CASTLE_WHITE_K = 1
CASTLE_WHITE_Q = 2
CASTLE_BLACK_K = 4
CASTLE_BLACK_Q = 8

# Promotion pieces (ordered by expected strength)
PROMOTE_PIECES = ['Q', 'R', 'B', 'N']

# ------------------------------------------------------------
# 2. Zobrist hash helpers (for transposition table)
# ------------------------------------------------------------

def init_zobrist():
    """Return a dict of dicts: zobrist[piece][square] -> random 64‑bit int."""
    pieces = [c + pt for c in "wb" for pt in "PNBRQK"]
    z = {}
    for p in pieces:
        z[p] = {sq: random.getrandbits(64) for sq in range(64)}
    return z

ZOBRIST = init_zobrist()

def compute_hash(board, side, castle, ep):
    """Compute a 64‑bit hash of the current position."""
    h = 0
    for sq, pc in enumerate(board):
        if pc is not None:
            h ^= ZOBRIST[pc][sq]
    if side == 'black':
        h ^= 0x123456789ABCDEF0   # arbitrary constant to flip side
    # Castling rights (4 bits)
    h ^= castle * 0xF1E2D3C4
    # En‑passant square (6 bits)
    if ep is not None:
        h ^= SQUARE_TO_IDX[ep] * 0x1A2B3C4D5E6F7081
    return h

# ------------------------------------------------------------
# 3. Board and move helpers
# ------------------------------------------------------------

def piece_color(pc):
    return 'white' if pc[0] == 'w' else 'black'

def piece_type(pc):
    return pc[1]

def mirror_sq(idx):
    """Mirror square for black perspective."""
    return idx ^ 56

def piece_square_value(pc, idx):
    """Return PST value for a piece on a square (white perspective)."""
    pt = piece_type(pc)
    tbl = {
        'P': PAWN_TABLE,
        'N': KNIGHT_TABLE,
        'B': BISHOP_TABLE,
        'R': ROOK_TABLE,
        'Q': QUEEN_TABLE,
        'K': KING_TABLE
    }[pt]
    if piece_color(pc) == 'white':
        return tbl[idx]
    else:
        return tbl[mirror_sq(idx)]

# ------------------------------------------------------------
# 4. Move generation
# ------------------------------------------------------------

def pseudo_legal_moves(board, color, castle_rights, ep_square):
    """Yield all pseudo‑legal moves for side `color`."""
    opp = 'white' if color == 'black' else 'black'
    for sq, pc in enumerate(board):
        if pc is None or piece_color(pc) != color:
            continue
        pt = piece_type(pc)
        if pt == 'P':
            yield from pawn_moves(board, sq, color, ep_square)
        elif pt == 'N':
            yield from knight_moves(board, sq, color)
        elif pt == 'B':
            yield from slide_moves(board, sq, color, SLIDE_DIRS['B'])
        elif pt == 'R':
            yield from slide_moves(board, sq, color, SLIDE_DIRS['R'])
        elif pt == 'Q':
            yield from slide_moves(board, sq, color, SLIDE_DIRS['Q'])
        elif pt == 'K':
            yield from king_moves(board, sq, color, castle_rights)
    # Castling
    yield from castling_moves(board, color, castle_rights)

def pawn_moves(board, sq, color, ep_square):
    """Yield pawn moves (including promotions, captures, double push, en‑passant)."""
    rank = sq // 8
    file = sq % 8
    forward = -8 if color == 'white' else 8
    start_rank = 6 if color == 'white' else 1
    promo_rank = 0 if color == 'white' else 7

    # Single push
    to = sq + forward
    if 0 <= to < 64 and board[to] is None:
        if rank == promo_rank:
            for prom in PROMOTE_PIECES:
                yield move_str(sq, to) + prom.lower()
        else:
            yield move_str(sq, to)
        # Double push
        if rank == start_rank:
            to2 = to + forward
            if 0 <= to2 < 64 and board[to2] is None:
                yield move_str(sq, to2)

    # Captures
    cap_left = sq + forward - 1
    cap_right = sq + forward + 1
    for to in (cap_left, cap_right):
        if 0 <= to < 64 and abs((to % 8) - file) == 1:
            target = board[to]
            if target is not None and piece_color(target) != color:
                if rank == promo_rank:
                    for prom in PROMOTE_PIECES:
                        yield move_str(sq, to) + prom.lower()
                else:
                    yield move_str(sq, to)

    # En‑passant
    if ep_square is not None:
        ep_idx = SQUARE_TO_IDX[ep_square]
        if ep_idx in (cap_left, cap_right):
            yield move_str(sq, ep_idx)

def knight_moves(board, sq, color):
    """Yield knight moves."""
    for off in KNIGHT_JUMPS:
        to = sq + off
        if 0 <= to < 64 and abs((to % 8) - (sq % 8)) <= 2:
            target = board[to]
            if target is None or piece_color(target) != color:
                yield move_str(sq, to)

def slide_moves(board, sq, color, dirs):
    """Yield sliding piece moves (bishop/rook/queen)."""
    for d in dirs:
        to = sq + d
        while 0 <= to < 64 and abs((to % 8) - (sq % 8)) <= 7:
            target = board[to]
            if target is None:
                yield move_str(sq, to)
            else:
                if piece_color(target) != color:
                    yield move_str(sq, to)
                break
            to += d

def king_moves(board, sq, color, castle_rights):
    """Yield normal king moves (castling handled separately)."""
    for off in KING_JUMPS:
        to = sq + off
        if 0 <= to < 64 and abs((to % 8) - (sq % 8)) <= 1:
            target = board[to]
            if target is None or piece_color(target) != color:
                yield move_str(sq, to)

def castling_moves(board, color, castle_rights):
    """Yield castling moves if legal."""
    if color == 'white':
        king_sq = SQUARE_TO_IDX['e1']
        if (castle_rights & CASTLE_WHITE_K) and board[king_sq] == 'wK':
            # Kingside
            if (board[SQUARE_TO_IDX['f1']] is None and
                board[SQUARE_TO_IDX['g1']] is None and
                board[SQUARE_TO_IDX['h1']] == 'wR'):
                if (not is_square_attacked(board, SQUARE_TO_IDX['e1'], 'black') and
                    not is_square_attacked(board, SQUARE_TO_IDX['f1'], 'black') and
                    not is_square_attacked(board, SQUARE_TO_IDX['g1'], 'black')):
                    yield move_str(king_sq, SQUARE_TO_IDX['g1'])
            # Queenside
            if (castle_rights & CASTLE_WHITE_Q) and board[king_sq] == 'wK':
                if (board[SQUARE_TO_IDX['d1']] is None and
                    board[SQUARE_TO_IDX['c1']] is None and
                    board[SQUARE_TO_IDX['b1']] is None and
                    board[SQUARE_TO_IDX['a1']] == 'wR'):
                    if (not is_square_attacked(board, SQUARE_TO_IDX['e1'], 'black') and
                        not is_square_attacked(board, SQUARE_TO_IDX['d1'], 'black') and
                        not is_square_attacked(board, SQUARE_TO_IDX['c1'], 'black')):
                        yield move_str(king_sq, SQUARE_TO_IDX['c1'])
    else:
        king_sq = SQUARE_TO_IDX['e8']
        if (castle_rights & CASTLE_BLACK_K) and board[king_sq] == 'bK':
            # Kingside
            if (board[SQUARE_TO_IDX['f8']] is None and
                board[SQUARE_TO_IDX['g8']] is None and
                board[SQUARE_TO_IDX['h8']] == 'bR'):
                if (not is_square_attacked(board, SQUARE_TO_IDX['e8'], 'white') and
                    not is_square_attacked(board, SQUARE_TO_IDX['f8'], 'white') and
                    not is_square_attacked(board, SQUARE_TO_IDX['g8'], 'white')):
                    yield move_str(king_sq, SQUARE_TO_IDX['g8'])
            # Queenside
            if (castle_rights & CASTLE_BLACK_Q) and board[king_sq] == 'bK':
                if (board[SQUARE_TO_IDX['d8']] is None and
                    board[SQUARE_TO_IDX['c8']] is None and
                    board[SQUARE_TO_IDX['b8']] is None and
                    board[SQUARE_TO_IDX['a8']] == 'bR'):
                    if (not is_square_attacked(board, SQUARE_TO_IDX['e8'], 'white') and
                        not is_square_attacked(board, SQUARE_TO_IDX['d8'], 'white') and
                        not is_square_attacked(board, SQUARE_TO_IDX['c8'], 'white')):
                        yield move_str(king_sq, SQUARE_TO_IDX['c8'])

def move_str(fr, to, promo=''):
    """Convert move to UCI string."""
    return IDX_TO_SQUARE[fr] + IDX_TO_SQUARE[to] + promo

# ------------------------------------------------------------
# 5. Attack detection / check testing
# ------------------------------------------------------------

def is_square_attacked(board, sq, attacker):
    """Return True if `attacker` side attacks square `sq`."""
    # Pawn attacks
    if attacker == 'white':
        for off in (-7, -9):
            to = sq + off
            if 0 <= to < 64 and abs((to % 8) - (sq % 8)) == 1:
                pc = board[to]
                if pc == 'wP':
                    return True
    else:
        for off in (7, 9):
            to = sq + off
            if 0 <= to < 64 and abs((to % 8) - (sq % 8)) == 1:
                pc = board[to]
                if pc == 'bP':
                    return True

    # Knight attacks
    for off in KNIGHT_JUMPS:
        to = sq + off
        if 0 <= to < 64 and abs((to % 8) - (sq % 8)) <= 2:
            pc = board[to]
            if pc is not None and piece_color(pc) == attacker and piece_type(pc) == 'N':
                return True

    # King attacks
    for off in KING_JUMPS:
        to = sq + off
        if 0 <= to < 64 and abs((to % 8) - (sq % 8)) <= 1:
            pc = board[to]
            if pc is not None and piece_color(pc) == attacker and piece_type(pc) == 'K':
                return True

    # Sliding pieces
    for pt, dirs in [('B', SLIDE_DIRS['B']), ('R', SLIDE_DIRS['R']), ('Q', SLIDE_DIRS['Q'])]:
        for d in dirs:
            to = sq + d
            while 0 <= to < 64 and abs((to % 8) - (sq % 8)) <= 7:
                pc = board[to]
                if pc is not None:
                    if piece_color(pc) == attacker and piece_type(pc) == pt:
                        return True
                    break
                to += d
    return False

def is_king_in_check(board, color):
    """Return True if the king of `color` is in check."""
    # Find king
    king_pc = 'wK' if color == 'white' else 'bK'
    king_sq = None
    for sq, pc in enumerate(board):
        if pc == king_pc:
            king_sq = sq
            break
    if king_sq is None:
        return False
    opp = 'black' if color == 'white' else 'white'
    return is_square_attacked(board, king_sq, opp)

# ------------------------------------------------------------
# 6. Make / unmake move
# ------------------------------------------------------------

def make_move(board, move, castle_rights, ep_square, moved_squares):
    """
    Apply a UCI move string to the board.
    Returns (new_board, new_castle_rights, new_ep_square, new_moved_squares, captured_piece)
    """
    b = board[:]
    fr = SQUARE_TO_IDX[move[0:2]]
    to = SQUARE_TO_IDX[move[2:4]]
    promo = move[4] if len(move) == 5 else None

    pc = b[fr]
    captured = b[to]

    # Normal move
    b[fr] = None
    if promo is None:
        b[to] = pc
    else:
        # Promotion
        color = 'w' if piece_color(pc) == 'white' else 'b'
        b[to] = color + promo.upper()

    # En‑passant capture
    if pc[1] == 'P' and ep_square is not None:
        ep_idx = SQUARE_TO_IDX[ep_square]
        if to == ep_idx:
            # Remove the pawn that moved two squares
            cap_sq = ep_idx + (8 if piece_color(pc) == 'white' else -8)
            b[cap_sq] = None

    # Update castling rights
    new_cr = castle_rights
    if pc == 'wK':
        new_cr &= ~CASTLE_WHITE_K
        new_cr &= ~CASTLE_WHITE_Q
    elif pc == 'bK':
        new_cr &= ~CASTLE_BLACK_K
        new_cr &= ~CASTLE_BLACK_Q
    elif pc == 'wR':
        if fr == SQUARE_TO_IDX['a1']:
            new_cr &= ~CASTLE_WHITE_Q
        elif fr == SQUARE_TO_IDX['h1']:
            new_cr &= ~CASTLE_WHITE_K
    elif pc == 'bR':
        if fr == SQUARE_TO_IDX['a8']:
            new_cr &= ~CASTLE_BLACK_Q
        elif fr == SQUARE_TO_IDX['h8']:
            new_cr &= ~CASTLE_BLACK_K

    # Update en‑passant target
    new_ep = None
    if pc[1] == 'P':
        rank = fr // 8
        forward = -8 if piece_color(pc) == 'white' else 8
        if rank == (6 if piece_color(pc) == 'white' else 1) and (to == fr + 2 * forward):
            new_ep = IDX_TO_SQUARE[fr + forward]

    # Update moved squares set
    new_moved = moved_squares | {fr}
    return b, new_cr, new_ep, new_moved, captured

# ------------------------------------------------------------
# 7. Evaluation
# ------------------------------------------------------------

def evaluate(board, side):
    """Static evaluation from `side` perspective."""
    score = 0
    for sq, pc in enumerate(board):
        if pc is None:
            continue
        v = PIECE_VALUE[piece_type(pc)]
        v += piece_square_value(pc, sq)
        if piece_color(pc) == 'white':
            score += v
        else:
            score -= v
    # Flip sign if evaluating for black
    return score if side == 'white' else -score

# ------------------------------------------------------------
# 8. Quiescence search
# ------------------------------------------------------------

def quiescence(board, side, alpha, beta):
    """Stand‑pat + captures only."""
    stand_pat = evaluate(board, side)
    if stand_pat >= beta:
        return beta
    if alpha < stand_pat:
        alpha = stand_pat

    opp = 'black' if side == 'white' else 'white'
    # Generate captures (including promotions)
    for move in pseudo_legal_moves(board, side, 0, None):
        # Only captures / promotions
        to = SQUARE_TO_IDX[move[2:4]]
        target = board[to]
        is_capture = target is not None and piece_color(target) != side
        is_promo = len(move) == 5
        if not (is_capture or is_promo):
            continue
        # Quick SEE‑style prune (optional): skip captures where victim < attacker
        # For simplicity we skip that here.
        b2, _, _, _, _ = make_move(board, move, 0, None, set())
        if is_king_in_check(b2, side):
            continue
        score = -quiescence(b2, opp, -beta, -alpha)
        if score >= beta:
            return beta
        if score > alpha:
            alpha = score
    return alpha

# ------------------------------------------------------------
# 9. Main alpha‑beta search
# ------------------------------------------------------------

def alpha_beta(board, side, depth, alpha, beta, max_depth, tt, hash_key):
    """Negamax alpha‑beta with TT."""
    # TT lookup
    entry = tt.get(hash_key)
    if entry is not None and entry['depth'] >= depth:
        if entry['flag'] == 'exact':
            return entry['score'], entry['move']
        if entry['flag'] == 'lower':
            alpha = max(alpha, entry['score'])
        elif entry['flag'] == 'upper':
            beta = min(beta, entry['score'])
        if alpha >= beta:
            return entry['score'], entry['move']

    if depth == 0:
        # Quiescence at horizon
        val = quiescence(board, side, alpha, beta)
        tt[hash_key] = {'score': val, 'depth': depth, 'flag': 'exact', 'move': None}
        return val, None

    best_move = None
    best_score = -inf

    # Move ordering: try TT move first
    if entry is not None and entry['move'] is not None:
        first_move = entry['move']
    else:
        first_move = None

    # Generate pseudo‑legal moves
    moves = list(pseudo_legal_moves(board, side, 0, None))
    # Sort: TT move first, then captures, promotions, then quiet
    def move_order_key(m):
        to = SQUARE_TO_IDX[m[2:4]]
        target = board[to]
        is_cap = target is not None and piece_color(target) != side
        is_promo = len(m) == 5
        is_tt = m == first_move
        return (0 if is_tt else 1,
                0 if is_cap else 1,
                0 if is_promo else 2,
                0)
    moves.sort(key=move_order_key)

    for mv in moves:
        # Make move
        b2, cr2, ep2, moved2, _ = make_move(board, mv, 0, None, set())
        # Skip illegal moves (king left in check)
        if is_king_in_check(b2, side):
            continue
        # Hash of child position
        child_hash = compute_hash(b2, 'black' if side == 'white' else 'white', cr2, ep2)
        score, _ = alpha_beta(b2, 'black' if side == 'white' else 'white',
                              depth - 1, -beta, -alpha, max_depth, tt, child_hash)
        score = -score
        if score > best_score:
            best_score = score
            best_move = mv
        alpha = max(alpha, score)
        if alpha >= beta:
            break

    # TT store
    if best_score <= alpha:
        flag = 'upper'
    elif best_score >= beta:
        flag = 'lower'
    else:
        flag = 'exact'
    tt[hash_key] = {'score': best_score, 'depth': depth, 'flag': flag, 'move': best_move}

    return best_score, best_move

# ------------------------------------------------------------
# 10. Iterative deepening driver
# ------------------------------------------------------------

def iterative_deepening(board, side, max_time=0.9):
    """Search with increasing depth until time runs out."""
    start = time.time()
    tt = {}
    best_move = None
    hash_key = compute_hash(board, side, CASTLE_WHITE_K | CASTLE_WHITE_Q | CASTLE_BLACK_K | CASTLE_BLACK_Q, None)
    for depth in range(1, 10):
        if time.time() - start > max_time:
            break
        score, mv = alpha_beta(board, side, depth, -inf, inf, depth, tt, hash_key)
        if mv is not None:
            best_move = mv
    return best_move

# ------------------------------------------------------------
# 11. Public API
# ------------------------------------------------------------

def policy(pieces, to_play, memory):
    """
    Main entry point.
    pieces: dict square->piece code
    to_play: 'white' or 'black'
    memory: dict (persisted between calls)
    Returns (move_string, memory)
    """
    # Initialise memory on first call
    if 'tt' not in memory:
        memory['tt'] = {}
    if 'moved_squares' not in memory:
        memory['moved_squares'] = set()
    if 'castle_rights' not in memory:
        # Assume all castling rights available at start
        memory['castle_rights'] = CASTLE_WHITE_K | CASTLE_WHITE_Q | CASTLE_BLACK_K | CASTLE_BLACK_Q
    if 'ep_square' not in memory:
        memory['ep_square'] = None

    # Build board list
    board = [None] * 64
    for sq, pc in pieces.items():
        board[SQUARE_TO_IDX[sq]] = pc

    # Generate legal moves (filter out those that leave king in check)
    legal_moves = []
    for mv in pseudo_legal_moves(board, to_play, memory['castle_rights'], memory['ep_square']):
        b2, cr2, ep2, moved2, _ = make_move(board, mv, memory['castle_rights'], memory['ep_square'], memory['moved_squares'])
        if not is_king_in_check(b2, to_play):
            legal_moves.append(mv)

    # If only one move, return it immediately
    if len(legal_moves) == 1:
        return legal_moves[0], memory

    # Search for a move
    mv = iterative_deepening(board, to_play, max_time=0.9)
    if mv is None:
        # Fallback: first legal move
        mv = legal_moves[0] if legal_moves else 'a1a1'

    return mv, memory
```

**Explanation of the code**

* The top section defines all static data: square mapping, piece values, piece‑square tables, sliding‑piece directions, castling constants and Zobrist random numbers.
* `pseudo_legal_moves` generates every possible move ignoring checks.  Individual helpers (`pawn_moves`, `knight_moves`, `slide_moves`, `king_moves`, `castling_moves`) produce the raw moves for each piece type.
* `is_square_attacked` checks whether a given square is under attack by a specific side; it is used both for legality testing and for castling‑rights validation.
* `make_move` updates the board, castling rights, en‑passant target and the set of squares that have moved (used to infer castling rights).  It returns enough information to undo the move if needed.
* `evaluate` adds up material and piece‑square values; it is called at the leaves of the search tree.
* `quiescence` performs a limited‑depth search of captures and promotions only, stabilising the evaluation at the horizon.
* `alpha_beta` is a classic negamax routine with alpha‑beta pruning, a transposition table (storing best move and score) and the move‑ordering described above.
* `iterative_deepening` repeatedly calls `alpha_beta` with increasing depth until a time limit (≈ 0.9 s) is reached, storing the best move found.
* Finally, `policy` converts the input `pieces` dict into the internal board list, filters pseudo‑legal moves to obtain truly legal moves, runs the iterative deepening search, and returns the chosen move together with the updated memory dictionary.

The engine is compact, runs comfortably within the 1 s limit for a few plies of search, and follows standard chess engine principles, giving it a solid chance of beating many opponents in the arena.
