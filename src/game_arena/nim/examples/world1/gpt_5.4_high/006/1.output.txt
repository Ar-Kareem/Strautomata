The strategy is exact misère Nim play, which is optimal for the “take the last object and lose” rule.

Core idea:
1. If every nonempty pile has size 1, then the game is just “how many 1-heaps are left”.
   - An odd number of 1-heaps is losing for the player to move.
   - So if possible, leave an odd number of 1-heaps to the opponent.
   - In practice, the only legal move is to remove one whole 1-heap.

2. If exactly one pile is larger than 1, then the correct move is to make all remaining nonzero piles be 1-heaps, with an odd count left for the opponent:
   - If the current number of 1-heaps is even, reduce the large pile to 1.
   - If the current number of 1-heaps is odd, remove the large pile entirely.

3. If at least two piles are larger than 1, play like normal Nim:
   - Compute the xor of the pile sizes.
   - If xor ≠ 0, make a move that leaves xor = 0.

4. If the position is already theoretically losing, there is no winning move under perfect play, but the policy still returns a legal move deterministically.

This runs in O(4) time and always returns a legal move for any non-terminal state.

def policy(piles: list[int]) -> str:
    """
    Optimal policy for 4-pile misère Nim.
    Return format: 'pile,take'
    """

    def legal_move(i: int, take: int) -> str:
        if 0 <= i < len(piles) and 1 <= take <= piles[i]:
            return f"{i},{take}"
        # Emergency fallback for unexpected inputs / terminal states.
        for j, p in enumerate(piles):
            if p > 0:
                return f"{j},1"
        return "0,1"

    ones = sum(1 for p in piles if p == 1)
    big_indices = [i for i, p in enumerate(piles) if p > 1]
    big_count = len(big_indices)

    # Case 1: all nonzero heaps are size 1
    # Optimal rule: odd count is losing, even count is winning by removing one.
    if big_count == 0:
        for i, p in enumerate(piles):
            if p == 1:
                return legal_move(i, 1)
        # Terminal fallback (should normally never be queried)
        return "0,1"

    # Case 2: exactly one heap > 1
    # Make all remaining nonzero heaps be 1-heaps, leaving an odd count to opponent.
    if big_count == 1:
        i = big_indices[0]
        if ones % 2 == 0:
            # Leave this heap as 1
            return legal_move(i, piles[i] - 1)
        else:
            # Remove this heap completely
            return legal_move(i, piles[i])

    # Case 3: at least two heaps > 1
    # Play normal Nim: move to xor = 0 when possible.
    x = 0
    for p in piles:
        x ^= p

    if x != 0:
        for i, p in enumerate(piles):
            target = p ^ x
            if target < p:
                return legal_move(i, p - target)

    # Case 4: theoretically losing position under perfect play.
    # No winning move exists, but return a legal move.
    # Heuristic: reduce a large pile to 1 to create a tricky misère endgame.
    for i, p in enumerate(piles):
        if p > 1:
            return legal_move(i, p - 1)

    for i, p in enumerate(piles):
        if p > 0:
            return legal_move(i, 1)

    return "0,1"
