An optimal policy for Misère Nim (where the player forced to take the last object loses) follows Bouton's nim-sum theorem with a critical modification in the endgame:

### Strategy:
1. **Endgame ($\le 1$ pile with size $> 1$):**
   - **Exactly one pile $> 1$:** We can completely control the game. We reduce the large pile so that the total number of remaining piles of size $1$ is **odd**. 
     - If the count of other piles of size $1$ is even, reduce the large pile to size $1$.
     - If the count of other piles of size $1$ is odd, reduce the large pile to size $0$.
     This forces the opponent into a sequence of single-object takes, eventually forcing them to take the last object.
   - **All piles $\le 1$:** Take $1$ from any remaining pile of size $1$.
2. **Normal Play ($\ge 2$ piles with size $> 1$):**
   - Play the standard Nim strategy: compute the XOR sum (nim-sum) across all piles.
   - If the nim-sum is non-zero, reduce a pile so the resulting nim-sum becomes $0$. A move achieving nim-sum $0$ from $\ge 2$ piles of size $> 1$ will always leave $\ge 2$ piles of size $> 1$, ensuring safe play without prematurely triggering the endgame rule.
   - If the nim-sum is already $0$ (a losing position against optimal play), make a legal move (e.g., take 1 from the largest pile) and wait for an opponent mistake.

def policy(piles: list[int]) -> str:
    # Count piles strictly greater than 1 and piles equal to 1
    greater_than_one = [i for i, p in enumerate(piles) if p > 1]
    ones = [i for i, p in enumerate(piles) if p == 1]
    
    # Endgame Case 1: Exactly one pile with size > 1
    if len(greater_than_one) == 1:
        target_pile = greater_than_one[0]
        count_ones = len(ones)
        # We want to leave an odd number of piles of size 1
        if count_ones % 2 == 0:
            # Leave 1 in the target pile
            take = piles[target_pile] - 1
        else:
            # Leave 0 in the target pile
            take = piles[target_pile]
        return f"{target_pile},{take}"

    # Endgame Case 2: All piles have size <= 1
    if len(greater_than_one) == 0:
        target_pile = ones[0] if ones else 0
        return f"{target_pile},1"

    # Normal Play: At least two piles with size > 1
    # Standard Nim strategy: make the nim-sum (XOR sum) equal to 0
    nim_sum = 0
    for p in piles:
        nim_sum ^= p

    if nim_sum != 0:
        for i, p in enumerate(piles):
            target_size = p ^ nim_sum
            if target_size < p:
                take = p - target_size
                return f"{i},{take}"

    # If already in a nim-sum 0 position, make any legal move (take 1 from the largest pile)
    largest_pile = max(range(len(piles)), key=lambda i: piles[i])
    return f"{largest_pile},1"
