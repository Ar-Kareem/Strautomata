An optimal strategy for misère Nim (where the player taking the last object loses) is derived from Bouton's theorem with an endgame adjustment:

1. **Endgame Condition (At most one pile with size $> 1$):**
   - If exactly one pile has size $> 1$ (and all other non-empty piles have size $1$), we transition the board into having an odd number of piles of size $1$.
     - If the count of size-1 piles is even, reduce the large pile to size $1$.
     - If the count of size-1 piles is odd, reduce the large pile to size $0$.
   - If all non-empty piles already have size $1$, take $1$ from any non-empty pile.

2. **Normal Play Condition (More than one pile with size $> 1$):**
   - The game behaves identically to standard Nim: calculate the XOR sum (nim-sum) across all piles.
   - If the XOR sum is non-zero, choose a pile $i$ where $piles[i] \oplus \text{XOR sum} < piles[i]$ and reduce it to $piles[i] \oplus \text{XOR sum}$.
   - If the XOR sum is zero, the position is technically losing under perfect play; make the minimal stalling move (take 1 object from the largest pile).

def policy(piles: list[int]) -> str:
    # Count piles of size > 1 and piles of size == 1
    gt1_indices = [i for i, p in enumerate(piles) if p > 1]
    eq1_indices = [i for i, p in enumerate(piles) if p == 1]
    
    # Case 1: Exactly one pile of size > 1
    if len(gt1_indices) == 1:
        target_pile = gt1_indices[0]
        size = piles[target_pile]
        num_ones = len(eq1_indices)
        
        # We want to leave an ODD number of 1s
        if num_ones % 2 == 0:
            # Leave 1 in the target pile (num_ones + 1 is odd)
            take = size - 1
        else:
            # Clear the target pile completely (num_ones is odd)
            take = size
        return f"{target_pile},{take}"
        
    # Case 2: Zero piles of size > 1 (all non-empty piles are of size 1)
    if len(gt1_indices) == 0:
        for i, p in enumerate(piles):
            if p > 0:
                return f"{i},1"

    # Case 3: More than one pile of size > 1 (play standard Nim)
    xor_sum = 0
    for p in piles:
        xor_sum ^= p

    if xor_sum != 0:
        for i, p in enumerate(piles):
            target_size = p ^ xor_sum
            if target_size < p:
                take = p - target_size
                return f"{i},{take}"

    # If xor_sum is 0 (losing position), make a valid fallback move (take 1 from the largest pile)
    largest_pile = max(range(len(piles)), key=lambda i: piles[i])
    return f"{largest_pile},1"
