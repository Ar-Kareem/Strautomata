An optimal strategy for Misère Nim (where the player who takes the last object loses) is based on the classical Bouton analysis with the misère endgame adjustment:

1. **Endgame Transition (At most one pile $> 1$):**
   - If exactly one pile has size $> 1$: reduce this pile to either size $0$ or size $1$ such that an **odd** number of piles of size $1$ remain. The opponent will then be forced into a chain of single-object moves and ultimately must take the last object.
   - If all piles have size $\le 1$: simply remove an object from any pile of size $1$ (if the number of $1$s is even, this leaves an odd number of $1$s, securing a win).

2. **Midgame (Two or more piles $> 1$):**
   - Play the standard Nim strategy by computing the XOR sum (nim-sum) $S = \bigoplus_{i=0}^3 \text{piles}[i]$.
   - If $S \neq 0$, find a pile $i$ such that $\text{piles}[i] \oplus S < \text{piles}[i]$ and reduce it to $\text{piles}[i] \oplus S$. This forces $S = 0$ for the opponent.
   - If $S = 0$ (a theoretical second-player win state), play a prolonging move (take $1$ from the largest pile) and wait for the opponent to make a mistake.

def policy(piles: list[int]) -> str:
    # Count piles of size > 1 and size == 1
    piles_gt_1 = [i for i, p in enumerate(piles) if p > 1]
    piles_eq_1 = [i for i, p in enumerate(piles) if p == 1]

    # Case 1: Exactly one pile has size > 1
    if len(piles_gt_1) == 1:
        target_idx = piles_gt_1[0]
        num_ones = len(piles_eq_1)
        # We want to leave an ODD number of 1s after our move.
        # If the current number of 1s is odd, reduce this pile to 0.
        # If the current number of 1s is even, reduce this pile to 1.
        if num_ones % 2 == 1:
            take = piles[target_idx]
        else:
            take = piles[target_idx] - 1
        return f"{target_idx},{take}"

    # Case 2: All piles have size <= 1
    if len(piles_gt_1) == 0:
        if piles_eq_1:
            return f"{piles_eq_1[0]},1"
        # Fallback for empty state (should not occur)
        return "0,1"

    # Case 3: Two or more piles have size > 1 (standard Nim-sum play)
    xor_sum = 0
    for p in piles:
        xor_sum ^= p

    if xor_sum != 0:
        for i, p in enumerate(piles):
            target_size = p ^ xor_sum
            if target_size < p:
                take = p - target_size
                return f"{i},{take}"

    # If xor_sum is 0, we are in a losing position; take 1 from the largest pile
    max_idx = max(range(len(piles)), key=lambda i: piles[i])
    return f"{max_idx},1"
