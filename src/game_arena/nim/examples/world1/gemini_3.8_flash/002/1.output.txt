An optimal policy for 4-pile **Misère Nim** (where the player forced to take the last object loses) follows Bouton's theorem:

1. **Endgame Transition (Exactly one pile $> 1$):**
   - If there is only one pile of size $> 1$, we can decide the exact number of piles of size $1$ left to the opponent.
   - We reduce this pile to either $0$ or $1$ such that the opponent is left with an **odd number of piles of size 1** (and zero piles $> 1$). Facing an odd number of $1$s is an unavoidable loss for the opponent.
2. **All piles $\le 1$:**
   - Any legal move takes $1$ from an available pile of size $1$.
3. **General Play ($\ge 2$ piles $> 1$):**
   - The game behaves identically to standard Nim: calculate the XOR sum (nim-sum) of all pile sizes.
   - If the nim-sum is non-zero, choose a pile to reduce so that the new nim-sum becomes $0$.
   - If already at nim-sum $0$ (a defensive position), make a minimal legal move (e.g., take $1$ from the largest pile) while waiting for an opponent mistake.

<code>
def policy(piles: list[int]) -> str:
    greater_than_one = [i for i, p in enumerate(piles) if p > 1]
    
    # Case 1: Exactly one pile has size > 1.
    # We can directly force a win by leaving an odd number of piles of size 1.
    if len(greater_than_one) == 1:
        idx = greater_than_one[0]
        ones_count = sum(1 for i, p in enumerate(piles) if i != idx and p == 1)
        if ones_count % 2 == 1:
            # Leave ones_count ones by clearing this pile entirely.
            take = piles[idx]
        else:
            # Leave ones_count + 1 ones by reducing this pile to 1.
            take = piles[idx] - 1
        return f"{idx},{take}"

    # Case 2: All piles have size <= 1.
    if len(greater_than_one) == 0:
        for i, p in enumerate(piles):
            if p == 1:
                return f"{i},1"
        return "0,0"

    # Case 3: At least two piles have size > 1.
    # Standard Nim XOR-sum strategy.
    xor_sum = 0
    for p in piles:
        xor_sum ^= p

    if xor_sum != 0:
        for i, p in enumerate(piles):
            target = p ^ xor_sum
            if target < p:
                return f"{i},{p - target}"

    # Fallback if xor_sum == 0 (defensive move: take 1 from the largest pile)
    max_idx = max(range(len(piles)), key=lambda i: piles[i])
    return f"{max_idx},1"
