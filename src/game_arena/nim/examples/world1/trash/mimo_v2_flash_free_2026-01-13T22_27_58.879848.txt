The game described is a variation of Nim. However, there is a critical distinction in the winning condition compared to the standard game. The problem states: "The game ends when all piles are zero. The player who takes the last object loses." This is the **misère** (or anti-Nim) convention.

In the standard misère Nim:
1.  If there are multiple piles with more than 1 object (and possibly piles with 1), the strategy is the same as normal Nim: you should make a move that results in a zero Nim-sum (XOR sum of pile sizes).
2.  If all piles have size 1 (an even number of piles), the current player is forced to take the last object (losing position).
3.  If all piles have size 1 (an odd number of piles), the current player can take one object, leaving an even number for the opponent (winning position).
4.  If there is exactly one pile with more than 1 object (and the rest are 1s or 0s), the winning strategy involves adjusting that pile to a specific size (0 or 1) to force the opponent into a losing state based on the count of 1s.

def policy(piles: list[int]) -> str:
    # 1. Identify piles with size > 1
    big_indices = [i for i, x in enumerate(piles) if x > 1]
    big_count = len(big_indices)
    
    # 2. Case: All piles are 0 or 1
    if big_count == 0:
        # Count ones
        ones = sum(piles)
        # Always take 1. 
        # If ones is odd: You win by taking one (leaving even ones, opponent loses).
        # If ones is even: You are forced to lose, but must make a move.
        # Pick the first pile with 1.
        for i in range(4):
            if piles[i] > 0:
                return f"{i},1"
                
    # 3. Case: Multiple piles > 1
    if big_count >= 2:
        # Standard Nim strategy: Make XOR sum 0
        xor_sum = 0
        for p in piles:
            xor_sum ^= p
            
        if xor_sum != 0:
            # Find a pile where (p ^ xor) < p
            for i in range(4):
                target = piles[i] ^ xor_sum
                if target < piles[i]:
                    take = piles[i] - target
                    return f"{i},{take}"
        
        # If xor_sum == 0 (should not happen with perfect play previously, but valid state)
        # Just take 1 from the first big pile.
        i = big_indices[0]
        return f"{i},1"
        
    # 4. Case: Exactly one pile > 1
    if big_count == 1:
        i = big_indices[0]
        # Count ones
        ones = sum(1 for x in piles if x == 1)
        
        if ones % 2 == 0:
            # Reduce to 1
            take = piles[i] - 1
            return f"{i},{take}"
        else:
            # Reduce to 0
            take = piles[i]
            return f"{i},{take}"

def policy(piles: list[int]) -> str:
    big_indices = [i for i, x in enumerate(piles) if x > 1]
    big_count = len(big_indices)

    # Case 1: All piles are 0 or 1 (Misère Nim endgame)
    if big_count == 0:
        ones = sum(piles)
        # Find the first pile with an item and take 1.
        for i in range(4):
            if piles[i] > 0:
                return f"{i},1"
    
    # Case 2: Multiple piles > 1 (Standard Nim strategy applies)
    if big_count >= 2:
        xor_sum = 0
        for p in piles:
            xor_sum ^= p
        
        if xor_sum != 0:
            # Find a move that makes the XOR sum zero
            for i in range(4):
                target = piles[i] ^ xor_sum
                if target < piles[i]:
                    take = piles[i] - target
                    return f"{i},{take}"
        
        # If XOR sum is already zero (losing position), take 1 from any big pile
        i = big_indices[0]
        return f"{i},1"

    # Case 3: Exactly one pile > 1
    if big_count == 1:

            # Even number of 1s: Reduce the big pile to 1

            return f"{i},{take}"
        else:
